Appendix A

Remote Access Setup

This appendix covers three methods for accessing your AI development environment remotely — Tailscale VPN, NoMachine, and Windows RDP.

What This Appendix Covers
  • Why remote access is needed
  • Tailscale VPN setup
  • NoMachine setup
  • Windows RDP setup
  • Comparison and selection guide
  • Troubleshooting

Why Remote Access?

AI development environments require significant computing power — fast CPUs, ample RAM, and dedicated GPUs. For most people, the most powerful computer sits on a desk at home or in the office. But sometimes you need to work from elsewhere: a laptop at a coffee shop, a tablet while traveling, or a workstation in another room.

Remote access lets you connect to your powerful desktop from any device, so you can run Claude Code, manage projects, and let AI agents work — all without being physically present at the machine.

You do not need to set up all three methods covered in this appendix. Choose the one that best fits your situation — the Comparison & Selection Guide at the end will help you decide.

Tailscale VPN Setup

Tailscale is a mesh VPN service built on WireGuard, a modern, high-performance VPN protocol. It creates a secure, private network between your devices — even behind routers and firewalls — without requiring complex network configuration.

What is Tailscale?

Think of Tailscale as a private network that connects your devices over the internet. Once installed on both your laptop and your desktop, you can access the desktop as if it were on the same local network. No port forwarding, no static IP addresses, and no router configuration required.

How Tailscale works: Each device you install Tailscale on joins a virtual private network. Every device gets its own Tailscale IP address. Devices can reach each other directly using these IPs, regardless of their physical location.
Create a Tailscale account — Visit tailscale.com/signup and sign up using your Google, Microsoft, GitHub, or email account. The free plan supports up to 100 devices, which is more than enough for personal use.
Install Tailscale on your AI Dev Desktop — Download and install Tailscale from the download page.
Windows

Download the Windows installer and run it. Tailscale will appear in the system tray after installation.

MacOS

Download the MacOS app or install via Homebrew: brew install --cask tailscale

Log in to Tailscale on the desktop — Open Tailscale and click "Log in". A browser window will open — authorize the device using the account you created in Step 1. After authorization, Tailscale will display your device's Tailscale IP address (e.g., 100.x.x.x).
Install Tailscale on your remote device — Repeat the installation on your laptop, tablet, or phone. Tailscale supports Windows, MacOS, Linux, iOS, and Android.
Log in on the remote device — Use the same account to log in on the remote device. Both devices will now appear in your Tailscale admin console at login.tailscale.com.
Verify connectivity — On your remote device, open a terminal or command prompt and ping the desktop using its Tailscale IP. 
ping 100.x.x.x
Replace 100.x.x.x with your desktop's Tailscale IP. If you receive replies, the VPN connection is working.
Tailscale's free plan is generous — it supports up to 100 devices, subnet routing, and MagicDNS (automatic name resolution). You do not need to pay anything to use Tailscale for personal remote access. Visit tailscale.com/pricing for plan details.

NoMachine Setup

NoMachine is a free remote desktop application that provides a full graphical desktop experience. Unlike Tailscale (which creates a network tunnel), NoMachine gives you a complete visual remote desktop session — you see the exact same screen, windows, and applications as if you were sitting in front of the machine.

What is NoMachine?

NoMachine uses the NX protocol to deliver high-performance remote desktop sessions. It is known for being fast, responsive, and easy to set up. Both the sending (host) and receiving (client) sides need NoMachine installed.

When to use NoMachine: When you need a full visual desktop experience — for example, running Claude Desktop App GUI, managing multiple windows, or using applications that require a display.
Download NoMachine on the host (AI Dev Desktop) — Visit nomachine.com/download and download the version for your operating system.
Windows

Download NoMachine for Windows and run the installer. Accept the default settings.

MacOS

Download NoMachine for macOS and drag it to your Applications folder.

Install and configure the host — After installation, NoMachine starts automatically as a service. Open the NoMachine application and go to Settings → Server → Security. Make sure "Allow connections from other computers" is enabled.
Note the host's IP address — In the NoMachine main window, you will see the local IP address of the host machine (e.g., 192.168.1.100). If you are connecting over the internet, you will need the public IP address or use Tailscale's IP address instead.
Download NoMachine on the client (your device) — On the device you will use to connect remotely, download and install NoMachine from the same download page. NoMachine client software is available for Windows, MacOS, Linux, iOS, and Android.
Connect to the host — Open NoMachine on the client device. Click "New connection" and enter the host's IP address. If you are using Tailscale, enter the Tailscale IP (e.g., 100.x.x.x). Click "Connect" and enter the host machine's username and password when prompted.
Adjust display settings — Once connected, you can adjust the quality and resolution from the NoMachine menu. For slow connections, reduce the resolution or enable "Low bandwidth mode" in the session settings.
If your internet connection is unstable, NoMachine can become laggy. In that case, try reducing the display resolution in session settings or consider using Tailscale combined with command-line access (SSH or Claude Code CLI) instead of a full graphical session.

Windows RDP Setup

Remote Desktop Protocol (RDP) is built into Windows Professional, Enterprise, and Education editions. It allows you to connect to a Windows computer remotely using the built-in Remote Desktop Connection tool — no additional software required on the client side.

What is Windows RDP?

Windows RDP is Microsoft's proprietary remote desktop protocol. It provides a full graphical remote session and is built directly into Windows, so you do not need to install third-party software on the host machine. The client side (the device you connect from) can be Windows, Mac, iOS, or Android using the free Microsoft Remote Desktop app.

Windows Home edition does NOT support RDP hosting. You need Windows Professional, Enterprise, or Education to act as an RDP host. If you have Windows Home, use NoMachine instead.
Enable Remote Desktop on the host — On the AI Dev Desktop (Windows), press Win + S, type "Remote Desktop Settings", and press Enter. Toggle "Enable Remote Desktop" to On. Windows may prompt you to confirm — click Confirm.
Configure Windows Firewall — When you enable Remote Desktop, Windows automatically creates a firewall rule to allow RDP connections on port 3389. Verify this by opening Windows Defender Firewall → Allow an app or feature through Windows Defender Firewall and confirming that Remote Desktop is checked.
Set up port forwarding on your router (for internet access) — To connect from outside your local network, you need to forward port 3389 on your router to the host machine's local IP.
  1. Log in to your router's admin panel (usually 192.168.1.1 or 192.168.0.1).
  2. Find the Port Forwarding (or NAT) section.
  3. Create a new rule: External port 3389, Internal port 3389, Internal IP address = your desktop's local IP (e.g., 192.168.1.100), Protocol = TCP.
  4. Save and apply the rule.
Find the host's public IP address — On the host machine, visit whatismyipaddress.com or search "What is my IP" in a browser. Note this address — you will use it to connect from the client.
Connect from the client device — On your remote device, open the Remote Desktop Connection tool.
Windows Client

Press Win + R, type mstsc, and press Enter. Enter the host's public IP address and click Connect.

Mac / iOS / Android

Download the free Microsoft Remote Desktop app from the App Store or Google Play. Add a new connection with the host's public IP address.

Security exposure warning: Exposing RDP directly to the internet is risky. Automated bots constantly scan for open RDP ports. To reduce risk: (1) use a strong, unique password for the host Windows account, (2) enable Network Level Authentication (NLA) in Remote Desktop settings, and (3) consider using Tailscale VPN instead of port forwarding so RDP is only accessible within your private network.

Comparison & Selection Guide

Each remote access method has its strengths and weaknesses. Use this comparison to find the best option for your situation.

Tailscale VPN

  • Encrypted mesh VPN (WireGuard)
  • No port forwarding required
  • Works behind NAT / firewalls
  • Free for up to 100 devices
  • Command-line access
  • Best for CLI / SSH workflows
  • Minimal bandwidth overhead

NoMachine

  • Full graphical remote desktop
  • High performance (NX protocol)
  • Free for personal use
  • Cross-platform (Win/Mac/Linux)
  • Easy installation
  • Best for GUI workflows
  • Adjustable quality settings

Windows RDP

  • Built into Windows Pro+
  • No extra host software
  • Full desktop experience
  • Requires port forwarding for internet
  • Security risk if exposed directly
  • Best for pure Windows environments
  • Microsoft Remote Desktop client

Recommended Combinations

Scenario Recommended Setup Why
Command-line only (Claude Code CLI, SSH, terminal) Tailscale alone Lightweight, secure, no GUI overhead
Need Claude Desktop App GUI remotely Tailscale + NoMachine Tailscale provides the secure tunnel; NoMachine provides the graphical session
Windows-only environment, no third-party software Windows RDP Built-in, no extra installation on the host
Windows Pro + want maximum security Tailscale + Windows RDP Tailscale replaces port forwarding; RDP stays within the private VPN network
For beginners: The easiest combination to start with is Tailscale + NoMachine. Install Tailscale on both machines to create a secure network, then use NoMachine for a full graphical remote desktop session. This combination works on both Windows and MacOS, does not require any router configuration, and keeps your connection secure.

Troubleshooting

Here are solutions to the most common remote access issues.

Cannot connect to the host machine — First, verify that the host machine is powered on and connected to the internet. Then check the following:
  • Tailscale: Both devices must show as online in the Tailscale admin console. Try restarting the Tailscale service.
  • NoMachine: Verify that NoMachine is running on the host and that "Allow connections" is enabled in Server settings.
  • RDP: Confirm Remote Desktop is enabled in Windows Settings and that port 3389 is not blocked by your router or ISP.
Connection is very slow or laggy — Remote desktop performance depends on your internet connection speed. Try these fixes:
  • Reduce display resolution in the remote desktop client settings.
  • Close unnecessary applications on the host machine to free up resources.
  • In NoMachine, enable "Low bandwidth mode" or reduce the display quality in session settings.
  • If using RDP, adjust the display settings in the connection options (lower color depth, disable wallpaper, disable font smoothing).
  • Connect via Tailscale (local VPN path) instead of going through port forwarding over the public internet.
Authentication or login fails — If you cannot log in:
  • Double-check your username and password. For Windows RDP, you must use the Windows account credentials on the host machine.
  • For Tailscale, make sure both devices are logged into the same Tailscale account.
  • For NoMachine, check that you are entering the host machine's OS username and password (not a NoMachine-specific password, unless you configured one).
  • If you recently changed your password on the host, the remote client may cache old credentials. Clear saved passwords and try again.
Audio or clipboard not working in remote session — These features are commonly affected:
  • Audio: In NoMachine, go to Settings → Audio and ensure "Audio playback" and "Audio recording" are enabled. In RDP, check "Record from this computer" in the Local Resources tab of the connection options.
  • Clipboard: Both NoMachine and RDP support clipboard sharing, but it must be enabled in the session settings. In NoMachine, check the "Copy and paste" option in the input settings panel.
Tailscale devices show as offline — If a device appears offline in the Tailscale admin console but you know it is running:
  • Check that the Tailscale service is running. On Windows, look for the Tailscale icon in the system tray. On MacOS, check the menu bar icon.
  • Try restarting the Tailscale service. On Windows: open Services, find "Tailscale," right-click, and select Restart. On MacOS: quit and reopen the Tailscale app.
  • Verify that the device has internet access (Tailscale cannot function without an internet connection).
  • If using a corporate or school network, the firewall may block WireGuard traffic. Contact your network administrator or try a different network.
Still stuck? If none of the above solutions resolve your issue, check the official documentation for each tool: Tailscale Knowledge Base, NoMachine Support, or Microsoft RDP Documentation.
