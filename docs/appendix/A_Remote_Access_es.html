Configuración de acceso remoto

Este apéndice explica tres métodos para acceder a tu entorno de desarrollo de IA desde fuera — Tailscale VPN, NoMachine y Windows RDP.

Lo que cubre este apéndice
  • Por qué es necesario el acceso remoto
  • Configuración de Tailscale VPN (desde cualquier lugar del mundo)
  • Configuración de NoMachine (escritorio remoto de alto rendimiento)
  • Configuración de Windows RDP (función integrada de Windows)
  • Guía de comparación y selección
  • Solución de problemas

¿Por qué necesitas acceso remoto?

Los entornos de desarrollo de IA suelen montarse sobre un potente equipo de escritorio, porque necesitan una CPU rápida, RAM abundante y GPU dedicada. Pero no siempre puedes estar sentado frente a ese equipo. A veces quieres trabajar con el portátil en una cafetería, consultar algo con la tableta durante un viaje o conectarte desde otra habitación.

Una vez configurado el acceso remoto, puedes conectarte a tu potente equipo de escritorio desde cualquier lugar. Ejecutar Claude Code, gestionar proyectos y hacer que los agentes de IA trabajen son cosas que puedes hacer sin estar físicamente frente a la máquina.

El acceso remoto equivale a "usar el ordenador de tu casa desde fuera". Igual que usas el mando a distancia del televisor, puedes manejar tal cual el potente ordenador que tienes en casa desde una cafetería o la oficina.
No necesitas configurar los tres métodos que explica este apéndice. Elige el que encaje con tu situación. La guía de comparación y selección del final te ayudará a decidir.

Configuración de Tailscale VPN

Tailscale es un servicio VPN mesh basado en WireGuard. Crea una red privada segura entre tus dispositivos aunque estén detrás de routers y cortafuegos. Sin configuraciones de red complejas, con unos pocos clics puedes acceder a tu ordenador desde fuera.

¿Qué es Tailscale?

Tailscale es una red privada que conecta tus dispositivos a través de internet. Instálalo en el portátil y en el escritorio, y podrás acceder al escritorio como si estuviera en la misma red local. No hace falta reenvío de puertos, ni IP fija, ni configuración del router.

Cómo funciona Tailscale: Todos los dispositivos con Tailscale instalado se unen a una red privada virtual. Cada dispositivo recibe su propia dirección IP de Tailscale, y los dispositivos pueden comunicarse directamente mediante esas direcciones sin importar su ubicación física.

Ventajas principales

  • Configuración sencilla — instalación y activación completadas en minutos
  • Atraviesa NAT — no hay que cambiar la configuración del router
  • Cifrado automático — cifrado extremo a extremo mediante el protocolo WireGuard
  • Gratis — hasta 100 dispositivos sin coste para uso personal
  • Multiplataforma — compatible con Windows, macOS, Linux, iOS y Android

Pasos de instalación

1. Regístrate en Tailscale — Accede a tailscale.com y regístrate con una cuenta de Google, Microsoft, GitHub o correo electrónico. El plan gratuito permite conectar hasta 100 dispositivos, más que suficiente para uso personal.
2. Instala Tailscale en el PC anfitrión — Instala la versión correspondiente a tu sistema operativo desde la página de descargas.
Windows

Descarga el instalador de Windows y ejecútalo. Al terminar la instalación, aparecerá el icono de Tailscale en la bandeja del sistema.

macOS

Descarga la app de macOS o instálala con Homebrew:

brew install --cask tailscale
3. Inicia sesión y activa — Abre la aplicación de Tailscale y haz clic en "Log in". Cuando se abra el navegador, autentícate con la cuenta creada en el paso 1. Tras la autenticación, Tailscale mostrará la dirección IP de Tailscale del dispositivo (por ejemplo, 100.x.x.x).
4. Instala Tailscale en el PC cliente — Instala también Tailscale en los dispositivos desde los que te conectarás (portátil, tableta, teléfono). Se admiten Windows, macOS, Linux, iOS y Android.
5. Inicia sesión con la misma cuenta — Inicia sesión en el dispositivo cliente con la misma cuenta. Ambos dispositivos aparecerán en la consola de administración de Tailscale.
6. Comprueba la IP del anfitrión — En el dispositivo cliente, abre un terminal o símbolo del sistema y comprueba la IP del anfitrión con el siguiente comando: 
tailscale ip

También puedes comprobarla directamente en el PC anfitrión:

Windows

Haz clic en el icono de Tailscale de la bandeja del sistema para ver la dirección IP.

macOS

Haz clic en el icono de Tailscale de la barra de menús para ver la dirección IP.

7. Prueba la conexión — Desde el dispositivo cliente, ejecuta una prueba de ping contra el anfitrión: 
ping 100.x.x.x

Sustituye 100.x.x.x por la IP de Tailscale real del anfitrión. Si llegan respuestas, la conexión VPN funciona correctamente.

El plan gratuito de Tailscale es muy generoso. Permite conectar hasta 100 dispositivos e incluye enrutamiento de subred y MagicDNS (resolución automática de nombres). El acceso remoto personal no cuesta nada. Para más detalles, consulta tailscale.com/pricing.

Configuración de NoMachine

NoMachine es una aplicación gratuita de escritorio remoto que ofrece un entorno de escritorio gráfico completo. A diferencia de Tailscale, que crea el túnel de red, NoMachine entrega una sesión remota visual completa — ves la pantalla, las ventanas y las aplicaciones exactamente como si estuvieras sentado frente a ese ordenador.

¿Qué es NoMachine?

NoMachine usa el protocolo NX para entregar sesiones remotas de alto rendimiento. Es conocido por ser rápido, reactivo y fácil de configurar. Tanto el lado emisor (anfitrión) como el receptor (cliente) deben tener NoMachine instalado.

¿Cuándo usar NoMachine?: Cuando quieras ejecutar la GUI de Claude Desktop App en remoto, gestionar varias ventanas o usar aplicaciones que necesitan pantalla. En resumen, es la opción adecuada cuando necesitas un entorno de escritorio completo con pantalla visible.

Ventajas principales

  • Baja latencia — sesiones rápidas y reactivas gracias al protocolo NX
  • Alta calidad de imagen — transmisión nítida de pantalla
  • Gratis — completamente gratis para uso personal
  • Multiplataforma — compatible con Windows, macOS, Linux, iOS y Android
  • Resistente a conexiones inestables — la sesión se mantiene incluso si cae internet

Pasos de instalación

1. Descarga NoMachine — Descarga desde nomachine.com/download la versión correspondiente a tu sistema operativo.
Windows

Descarga e instala NoMachine for Windows. Mantén la configuración predeterminada.

macOS

Descarga NoMachine for macOS y arrástralo a la carpeta Aplicaciones.

Linux

Descarga el paquete .deb, .rpm o .tar.gz que corresponda a tu distribución.

2. Instálalo en el PC anfitrión — Instala NoMachine en el escritorio de desarrollo de IA (anfitrión). Tras la instalación, NoMachine arranca automáticamente como servicio.
3. Activa el servicio — Abre la aplicación de NoMachine y ve a Configuración → Servidor → Seguridad. Comprueba que "Permitir conexiones desde otros equipos" esté activado.
4. Comprueba la IP del anfitrión — En la ventana principal de NoMachine verás la dirección IP local del equipo anfitrión (por ejemplo, 192.168.1.100). Para conectarte por internet necesitas una dirección IP pública, o bien usar la dirección IP de Tailscale. 
# Comprobar la IP local (Windows)
ipconfig

# Comprobar la IP local (macOS / Linux)
ifconfig
5. Instálalo en el PC cliente — Descarga e instala NoMachine en el dispositivo desde el que te conectarás. Se admiten clientes Windows, macOS, Linux, iOS y Android.
6. Conéctate al anfitrión — Abre NoMachine en el dispositivo cliente y pulsa "Nueva conexión". Introduce la dirección IP del anfitrión. Si usas Tailscale, introduce la IP de Tailscale (por ejemplo, 100.x.x.x). Pulsa "Conectar" e introduce el nombre de usuario y la contraseña del equipo anfitrión.
NoMachine funciona bien incluso con conexiones a internet inestables. Activando el "modo de bajo ancho de banda" en la configuración de sesión o bajando la resolución lo harás aún más estable.

Configuración de Windows RDP

El Protocolo de Escritorio Remoto (RDP) viene integrado en las ediciones Windows Professional, Enterprise y Education. Sin software adicional, puedes conectarte en remoto a un equipo Windows con la herramienta integrada Conexión de Escritorio Remoto.

¿Qué es Windows RDP?

Windows RDP es el protocolo de escritorio remoto de Microsoft. Ofrece una sesión remota gráfica completa y está integrado directamente en Windows, así que el equipo anfitrión no necesita software de terceros. El lado cliente puede conectarse desde Windows, Mac, iOS y Android con la aplicación gratuita Microsoft Remote Desktop.

Las ediciones Windows Home no admiten actuar como host RDP. Para ser anfitrión RDP se necesita Windows Professional, Enterprise o Education. Si usas Windows Home, utiliza NoMachine en su lugar.

Pasos de configuración

1. Activa el Escritorio Remoto — En el equipo anfitrión (Windows), pulsa Win + S, escribe "Configuración de Escritorio Remoto" y pulsa Enter. Activa "Habilitar Escritorio Remoto". Si Windows pide confirmación, confírmalo.
2. Comprueba la regla del cortafuegos — Al habilitar el Escritorio Remoto, Windows crea automáticamente una regla que permite conexiones RDP en el puerto 3389. En Firewall de Windows Defender → Permitir una aplicación o característica a través del Firewall de Windows Defender, comprueba que Escritorio Remoto esté marcado.
3. Verifica la cuenta de usuario — Confirma la cuenta de usuario y contraseña de Windows que usarás para iniciar sesión en remoto. Se recomienda una cuenta con privilegios de administrador. 
# Comprobar el nombre de usuario actual
whoami

# Comprobar la información del sistema
systeminfo | findstr /B /C:"Nombre de host" /C:"Nombre del sistema operativo"
4. Configura el reenvío de puertos RDP (para acceso por internet) — Para conectarte desde fuera de la red local, el router debe reenviar el puerto 3389 a la IP local de la máquina anfitriona.
  1. Inicia sesión en el panel de administración del router (normalmente 192.168.1.1 o 192.168.0.1).
  2. Busca la sección de Reenvío de puertos (o NAT).
  3. Crea una regla nueva: puerto externo 3389, puerto interno 3389, IP interna = la IP local del escritorio (por ejemplo, 192.168.1.100), protocolo = TCP.
  4. Guarda y aplica la regla.
5. Averigua la IP pública del anfitrión — En el equipo anfitrión, abre el navegador y visita whatismyipaddress.com o busca "cuál es mi dirección IP". Anota esta dirección — la usarás al conectarte desde el cliente.
6. Conéctate desde el cliente — En el dispositivo remoto, abre la herramienta de Conexión de Escritorio Remoto.
Cliente Windows

Pulsa Win + R, escribe mstsc y pulsa Enter. Introduce la IP pública del anfitrión y pulsa "Conectar".

mstsc
Mac / iOS / Android

Descarga la aplicación gratuita Microsoft Remote Desktop desde el App Store o Google Play. Añade una conexión nueva con la IP pública del anfitrión.

Advertencia de seguridad: Exponer RDP directamente a internet es muy arriesgado. Bots automatizados escanean constantemente puertos RDP abiertos. Para reducir el riesgo: (1) usa una contraseña fuerte y única en la cuenta de Windows del anfitrión, (2) activa la Autenticación a Nivel de Red (NLA) en la configuración del Escritorio Remoto y (3) se recomienda encarecidamente usar la VPN de Tailscale en lugar del reenvío de puertos, de modo que RDP solo sea alcanzable dentro de la red privada.

Tailscale VPN

  • Cifrado basado en WireGuard
  • Sin reenvío de puertos
  • Atraviesa NAT / cortafuegos
  • Gratis hasta 100 dispositivos
  • Ideal para acceso por línea de comandos
  • Sobrecoste mínimo de ancho de banda
  • El método más seguro

NoMachine

  • Escritorio gráfico completo
  • Alto rendimiento (protocolo NX)
  • Gratis para uso personal
  • Multiplataforma
  • Instalación sencilla
  • Ideal para flujos de trabajo GUI
  • Calidad de imagen ajustable

Windows RDP

  • Integrado en Windows Pro+
  • Sin software adicional en el anfitrión
  • Entorno de escritorio completo
  • Requiere reenvío de puertos para acceso por internet
  • Riesgo de seguridad si se expone directamente
  • Ideal para entornos puramente Windows
  • Cliente Microsoft Remote Desktop

Combinaciones recomendadas

Situación Configuración recomendada Razón
Conexión solo dentro de casa Windows RDP Sin instalación adicional, cómodo dentro de la misma red WiFi
Solo línea de comandos (Claude Code CLI, SSH, terminal) Tailscale solo Ligero y seguro, sin sobrecoste de GUI
Usar la GUI de Claude Desktop App en remoto Tailscale + NoMachine Tailscale aporta el túnel seguro y NoMachine la sesión gráfica
Windows Pro + máxima seguridad Tailscale + Windows RDP Tailscale sustituye al reenvío de puertos y RDP solo es accesible dentro de la VPN privada
Recomendación para principiantes: Empieza configurando Tailscale. Es lo más sencillo y seguro. Si necesitas entorno gráfico, usa la combinación Tailscale + NoMachine. Instala Tailscale en ambos dispositivos para crear la red segura y después usa NoMachine para una sesión de escritorio remoto completa. Funciona en Windows y macOS, no requiere configurar el router y mantiene la conexión segura.

Solución de problemas

Aquí tienes los problemas más habituales del acceso remoto y cómo resolverlos.

1. No se puede conectar — Primero comprueba que el equipo anfitrión esté encendido y conectado a internet. Después revisa cada herramienta:
  • Tailscale: Ambos dispositivos deben aparecer en línea en la consola de administración de Tailscale. Prueba a reiniciar el servicio de Tailscale.
  • NoMachine: Comprueba que NoMachine esté en ejecución en el anfitrión y que "Permitir conexiones" esté activado en la configuración del servidor.
  • RDP: Comprueba que el Escritorio Remoto esté habilitado en la configuración de Windows y que el puerto 3389 no esté bloqueado por el router o el proveedor.
2. Va muy lento o se corta — El rendimiento del escritorio remoto depende de la velocidad de tu conexión. Prueba lo siguiente:
  • Baja la resolución de pantalla en la configuración del cliente de escritorio remoto.
  • Cierra aplicaciones innecesarias en el equipo anfitrión para liberar recursos.
  • Con NoMachine, activa el "modo de bajo ancho de banda" en la configuración de sesión o baja la calidad de imagen.
  • Con RDP, reduce la profundidad de color en las opciones de conexión y desactiva el fondo de escritorio y el suavizado de fuentes.
  • Conéctate mediante Tailscale (ruta VPN local) en lugar de internet público vía reenvío de puertos.
3. Falla la autenticación o el inicio de sesión — Si no puedes iniciar sesión:
  • Revisa el nombre de usuario y la contraseña. Con Windows RDP debes usar las credenciales de la cuenta de Windows del equipo anfitrión.
  • Con Tailscale, comprueba que ambos dispositivos hayan iniciado sesión con la misma cuenta de Tailscale.
  • Con NoMachine, introduce el usuario y la contraseña del sistema operativo del anfitrión (salvo que hayas definido una contraseña específica de NoMachine).
  • Si cambiaste recientemente la contraseña en el anfitrión, el cliente puede tener en caché las credenciales antiguas. Borra la contraseña guardada e inténtalo de nuevo.
4. Lo bloquea un cortafuegos — Si un cortafuegos bloquea la conexión:
  • En el Firewall de Windows Defender, comprueba que Tailscale, NoMachine y el Escritorio Remoto estén "Permitidos".
  • En el cortafuegos del router, comprueba que los puertos necesarios estén abiertos: Tailscale (se gestiona automáticamente), NoMachine (puerto 4000), RDP (puerto 3389).
  • En redes corporativas o educativas, el administrador puede estar bloqueando el tráfico VPN. Consulta con el administrador o prueba otra red.
5. Problemas con varios monitores — Si varios monitores no se muestran correctamente en la sesión remota:
  • RDP: Antes de conectar, revisa la opción "Usar todos mis monitores" en la pestaña "Configuración de pantalla".
  • NoMachine: Puedes ajustar la disposición de monitores en la configuración de sesión. Cambiar a un solo monitor puede mejorar el rendimiento.
  • Dentro de la sesión remota, pulsa Win + P para cambiar el modo de pantalla (duplicar, extender, una sola pantalla).
  • Si el problema persiste, reconecta con un solo monitor conectado al dispositivo cliente y ajusta la configuración de pantalla dentro de la sesión.
¿Sigue sin resolverse? Si ninguna de las soluciones anteriores resuelve el problema, consulta la documentación oficial de cada herramienta: base de conocimiento de Tailscale, soporte de NoMachine, documentación de Microsoft RDP.
