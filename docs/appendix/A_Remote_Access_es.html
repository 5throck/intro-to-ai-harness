Apéndice A

Configuración de acceso remoto

Este apéndice cubre tres métodos para acceder a tu entorno de desarrollo de IA de forma remota — Tailscale VPN, NoMachine y Windows RDP.

What This Apéndice Covers
  • Why remote access is needed
  • Tailscale VPN setup
  • NoMachine setup
  • Windows RDP setup
  • Comparison and selection guide
  • Solución de problemas

Why Remote Access?

Los entornos de desarrollo de IA requieren una potencia informática significativa: CPU rápidas, abundante RAM y GPU dedicadas. Para la mayoría de las personas, la computadora más potente está en un escritorio en casa o en la oficina. Pero a veces necesitas trabajar desde otro lugar: una computadora portátil en una cafetería, una tableta mientras viajas o una estación de trabajo en otra habitación.

El acceso remoto te permite conectar a tu potente escritorio desde cualquier dispositivo, por lo que puedes ejecutar Claude Code, gestionar proyectos y dejar que los agentes de IA trabajen —todo sin estar físicamente presente en la máquina.

No necesitas configurar los tres métodos cubiertos en este apéndice. Elige el que mejor se adapte a tu situación —la Guía de Comparación y Selección al final te ayudará a decidir.

Tailscale VPN Setup

Tailscale es un servicio VPN mesh construido sobre WireGuard, un protocolo VPN moderno y de alto rendimiento. Crea una red segura y privada entre tus dispositivos —incluso detrás de routers y firewalls— sin requerir una configuración de red compleja.

What is Tailscale?

Piensa en Tailscale como una red privada que conecta tus dispositivos a través de internet. Una vez instalado tanto en tu computadora portátil como en tu escritorio, puedes acceder al escritorio como si estuviera en la misma red local. Sin reenvío de puertos, sin direcciones IP estáticas y sin configuración del router requerida.

Cómo funciona Tailscale: Cada dispositivo en el que instalas Tailscale se une a una red privada virtual. Cada dispositivo obtiene su propia dirección IP de Tailscale. Los dispositivos pueden comunicarse directamente usando estas IPs, independientemente de su ubicación física.
Create a Tailscale account — Visita tailscale.com/signup y regístrate usando tu cuenta de Google, Microsoft, GitHub o correo electrónico. El plan gratuito admite hasta 100 dispositivos, lo cual es más que suficiente para uso personal.
Install Tailscale on your AI Dev Desktop — Descarga e instala Tailscale desde la página de descargas.
Windows

Descarga el instalador de Windows y ejecútalo. Tailscale aparecerá en la bandeja del sistema después de la instalación.

MacOS

Download the MacOS app or install via Homebrew: brew install --cask tailscale

Inicia sesión en Tailscale en el escritorio — Abre Tailscale y haz clic en "Iniciar sesión". Se abrirá una ventana del navegador —autoriza el dispositivo usando la cuenta que creaste en el Paso 1. Después de la autorización, Tailscale mostrará la dirección IP de Tailscale de tu dispositivo (por ejemplo, 100.x.x.x).
Install Tailscale on your remote device — Repite la instalación en tu computadora portátil, tableta o teléfono. Tailscale es compatible con Windows, MacOS, Linux, iOS y Android.
Inicia sesión en el dispositivo remoto — Usa la misma cuenta para iniciar sesión en el dispositivo remoto. Ambos dispositivos aparecerán ahora en tu consola de administración de Tailscale en login.tailscale.com.
Verify connectivity — En tu dispositivo remoto, abre una terminal o símbolo del sistema y haz ping al escritorio usando su IP de Tailscale. 
ping 100.x.x.x
Replace 100.x.x.x with your desktop's Tailscale IP. If you receive replies, the VPN connection is working.
El plan gratuito de Tailscale es generoso — soporta hasta 100 dispositivos, enrutamiento de subredes y MagicDNS (resolución automática de nombres). No necesitas pagar nada para usar Tailscale para acceso remoto personal. Visita tailscale.com/pricing para ver los detalles del plan.

NoMachine Setup

NoMachine es una aplicación de escritorio remoto gratuita que proporciona una experiencia completa de escritorio gráfico. A diferencia de Tailscale (que crea un túnel de red), NoMachine te da una sesión visual completa de escritorio remoto — ves exactamente la misma pantalla, ventanas y aplicaciones que si estuvieras sentado frente a la máquina.

What is NoMachine?

NoMachine usa el protocolo NX para ofrecer sesiones de escritorio remoto de alto rendimiento. Es conocido por ser rápido, receptivo y fácil de configurar. Tanto el lado emisor (host) como el receptor (cliente) necesitan NoMachine instalado.

Cuándo usar NoMachine: Cuando necesitas una experiencia completa de escritorio visual — por ejemplo, ejecutar la interfaz gráfica de Claude Desktop App, gestionar múltiples ventanas o usar aplicaciones que requieren pantalla.
Download NoMachine on the host (AI Dev Desktop) — Visit nomachine.com/download and download the version for your operating system.
Windows

Descarga NoMachine for Windows y ejecuta el instalador. Acepta la configuración predeterminada.

MacOS

Descarga NoMachine for macOS y arrástralo a tu carpeta de Applications.

Install and configure the host — Tras la instalación, NoMachine se inicia automáticamente como servicio. Abre la aplicación NoMachine y ve a Settings → Server → Security. Asegúrate de que "Permitir conexiones desde otras computadoras" esté habilitado.
Note the host's IP address — En la ventana principal de NoMachine verás la dirección IP local de la máquina host (p. ej., 192.168.1.100). Si te conectas por internet, necesitarás la public IP address o usa la dirección IP de Tailscale en su lugar.
Descarga NoMachine en el cliente (tu dispositivo) — En el dispositivo que usarás para conectarte de forma remota, descarga e instala NoMachine desde la misma página de descargas. El software cliente de NoMachine está disponible para Windows, MacOS, Linux, iOS y Android.
Connect to the host — Abre NoMachine en el dispositivo cliente. Haz clic en "New connection" e introduce la dirección IP del host. Si usas Tailscale, introduce la IP de Tailscale (p. ej., 100.x.x.x). Haz clic en "Connect" e introduce el usuario y la contraseña de la máquina host cuando se te solicite.
Adjust display settings — Una vez conectado, puedes ajustar la calidad y la resolución desde el menú de NoMachine. Para conexiones lentas, reduce la resolución o habilita "Low bandwidth mode" en la configuración de la sesión.
Si tu conexión a internet es inestable, NoMachine puede volverse lento. En ese caso, prueba a reducir la resolución de pantalla en la configuración de la sesión o considera usar Tailscale combinado con acceso por línea de comandos (SSH o Claude Code CLI) en lugar de una sesión gráfica completa.

Windows RDP Setup

Remote Desktop Protocol (RDP) está integrado en las ediciones Windows Professional, Enterprise y Education. Te permite conectarte a una computadora con Windows de forma remota usando la herramienta integrada Remote Desktop Connection — sin software adicional en el lado del cliente.

What is Windows RDP?

Windows RDP es el protocolo de escritorio remoto propietario de Microsoft. Proporciona una sesión gráfica remota completa y es integrado directamente en Windows, por lo que no necesitas instalar software de terceros en la máquina host. El lado del cliente (el dispositivo desde el que te conectas) puede ser Windows, Mac, iOS o Android usando la aplicación gratuita Microsoft Remote Desktop.

Windows La edición Home NO soporta hospedaje RDP. Necesitas Windows Professional, Enterprise o Education para actuar como host RDP. Si tienes Windows Home, usa NoMachine en su lugar.
Enable Remote Desktop on the host — On the AI Dev Desktop (Windows), press Win + S, type "Remote Desktop Settings", and press Enter. Toggle "Enable Remote Desktop" to On. Windows may prompt you to confirm — click Confirm.
Configure Windows Firewall — Al habilitar Remote Desktop, Windows crea automáticamente una regla de firewall para permitir conexiones RDP en el puerto 3389. Verifícalo abriendo Windows Defender Firewall → Allow an app or feature through Windows Defender Firewall y confirmando que Remote Desktop esté marcado.
Configura el port forwarding en tu router (para acceso por internet) — To connect from outside your local network, you need to forward port 3389 on your router to the host machine's local IP.
  1. Inicia sesión en el panel de administración de tu router (generalmente 192.168.1.1 o 192.168.0.1).
  2. Find the Port Forwarding (or NAT) section.
  3. Create a new rule: External port 3389, Internal port 3389, Internal IP address = your desktop's local IP (e.g., 192.168.1.100), Protocol = TCP.
  4. Save and apply the rule.
Find the host's public IP address — En la máquina host, visita whatismyipaddress.com o busca "Cuál es mi IP" en un navegador. Anota esta dirección — la usarás para conectarte desde el cliente.
Connect from the client device — On your remote device, open the Remote Desktop Connection tool.
Windows Client

Press Win + R, type mstsc, and press Enter. Enter the host's public IP address and click Connect.

Mac / iOS / Android

Descarga la aplicación gratuita Microsoft Remote Desktop desde el App Store o Google Play. Añade una nueva conexión con la dirección IP pública del host.

Security exposure warning: Exponer RDP directamente a internet es riesgoso. Los bots automatizados escanean constantemente en busca de puertos RDP abiertos. Para reducir el riesgo: (1) usa una strong, unique password para la cuenta de Windows del host, (2) habilita Network Level Authentication (NLA) en la configuración de Remote Desktop, y (3) considera usar Tailscale VPN en lugar de port forwarding para que RDP solo sea accesible dentro de tu red privada.

Comparison & Selection Guide

Cada método de acceso remoto tiene sus fortalezas y debilidades. Usa esta comparación para encontrar la mejor opción para tu situación.

Tailscale VPN

  • Encrypted mesh VPN (WireGuard)
  • No port forwarding required
  • Works behind NAT / firewalls
  • Gratis hasta 100 dispositivos
  • Command-line access
  • Best for CLI / SSH workflows
  • Minimal bandwidth overhead

NoMachine

  • Full graphical remote desktop
  • High performance (NX protocol)
  • Free for personal use
  • Cross-platform (Win/Mac/Linux)
  • Easy installation
  • Best for GUI workflows
  • Adjustable quality settings

Windows RDP

  • Built into Windows Pro+
  • No extra host software
  • Full desktop experience
  • Requires port forwarding for internet
  • Security risk if exposed directly
  • Best for pure Windows environments
  • Microsoft Remote Desktop client

Combinaciones recomendadas

Scenario Configuración recomendada Why
Command-line only (Claude Code CLI, SSH, terminal) Tailscale alone Lightweight, secure, no GUI overhead
Need Claude Desktop App GUI remotely Tailscale + NoMachine Tailscale provides the secure tunnel; NoMachine provides the graphical session
Windows-only environment, no third-party software Windows RDP Integrado, sin instalación adicional en el host
Windows Pro + want maximum security Tailscale + Windows RDP Tailscale replaces port forwarding; RDP stays within the private VPN network
Para principiantes: La combinación más fácil para empezar es Tailscale + NoMachine. Instala Tailscale en ambas máquinas para crear una red segura, luego usa NoMachine para una sesión completa de escritorio remoto gráfico. Esta combinación funciona tanto en Windows como en MacOS, no requiere configuración del router y mantiene tu conexión segura.

Solución de problemas

Aquí tienes soluciones para los problemas de acceso remoto más comunes.

Cannot connect to the host machine — First, verify that the host machine is powered on and connected to the internet. Then check the following:
  • Tailscale: Ambos dispositivos deben aparecer como en línea en la consola de administración de Tailscale. Prueba reiniciar el servicio de Tailscale.
  • NoMachine: Verifica que NoMachine esté ejecutándose en el host y que "Allow connections" esté habilitado en la configuración del Server.
  • RDP: Confirma que Remote Desktop esté habilitado en la Configuración de Windows y que el puerto 3389 no esté bloqueado por tu router o ISP.
La conexión es muy lenta o con lag — Remote desktop performance depends on your internet connection speed. Try these fixes:
  • Reduce display resolution in the remote desktop client settings.
  • Cierra las aplicaciones innecesarias en la máquina host para liberar recursos.
  • En NoMachine, habilita "Low bandwidth mode" o reduce la calidad de visualización en la configuración de la sesión.
  • Si usas RDP, ajusta la configuración de pantalla en las opciones de conexión (menos profundidad de color, deshabilitar el fondo de pantalla, deshabilitar el suavizado de fuentes).
  • Conéctate vía Tailscale (ruta VPN local) en lugar de pasar por port forwarding a través de internet pública.
Authentication or login fails — If you cannot log in:
  • Verifica de nuevo tu nombre de usuario y contraseña. Para Windows RDP, debes usar las credenciales de la cuenta de Windows de la máquina host.
  • Para Tailscale, asegúrate de que ambos dispositivos hayan iniciado sesión en la misma cuenta de Tailscale.
  • Para NoMachine, comprueba que estés ingresando el nombre de usuario y contraseña del sistema operativo de la máquina host (no una contraseña específica de NoMachine, a menos que hayas configurado una).
  • Si cambiaste recientemente tu contraseña en el host, el cliente remoto puede tener credenciales antiguas en caché. Borra las contraseñas guardadas e inténtalo de nuevo.
El audio o el portapapeles no funciona en la sesión remota — These features are commonly affected:
  • Audio: En NoMachine, ve a Settings → Audio y asegúrate de que "Audio playback" y "Audio recording" estén habilitados. En RDP, marca "Record from this computer" en la pestaña Local Resources de las opciones de conexión.
  • Clipboard: Tanto NoMachine como RDP soportan compartir el portapapeles, pero debe habilitarse en la configuración de la sesión. En NoMachine, verifica la opción "Copy and paste" en el panel de configuración de entrada.
Tailscale devices show as offline — If a device appears offline in the Tailscale admin console but you know it is running:
  • Comprueba que el servicio de Tailscale esté ejecutándose. En Windows, busca el ícono de Tailscale en la bandeja del sistema. En MacOS, revisa el ícono de la barra de menú.
  • Prueba reiniciar el servicio de Tailscale. En Windows: abre Services, busca "Tailscale", haz clic derecho y selecciona Restart. En MacOS: cierra y vuelve a abrir la aplicación de Tailscale.
  • Verifica que el dispositivo tenga acceso a internet (Tailscale no puede funcionar sin conexión a internet).
  • Si usas una red corporativa o escolar, el firewall puede bloquear el tráfico de WireGuard. Contacta a tu administrador de red o prueba con una red diferente.
¿Sigue sin funcionar? Si ninguna de las soluciones anteriores resuelve tu problema, consulta la documentación oficial de cada herramienta: Tailscale Knowledge Base, NoMachine Support o Microsoft RDP Documentation.
