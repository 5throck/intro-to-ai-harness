リモートアクセス設定

この付録では、AI開発環境にリモートでアクセスする3つの方法 — Tailscale VPN、NoMachine、Windows RDP — について説明します。

この付録で扱う内容
  • リモートアクセスが必要な理由
  • Tailscale VPNの設定
  • NoMachineの設定
  • Windows RDPの設定
  • 比較と選択ガイド
  • トラブルシューティング

なぜリモートアクセスが必要か

AI開発環境には、高速なCPU、十分なRAM、専用GPUなど、大量の計算能力が必要です。多くの人にとって、最も強力なコンピュータは自宅やオフィスのデスクに置かれています。しかし、外出先から作業する必要がある場合もあります — カフェのノートPC、旅行中のタブレット、別の部屋のワークステーションなどです。

リモートアクセスを使えば、任意のデバイスから強力なデスクトップに接続できます。物理的にそのマシンの前にいなくても、Claude Codeを実行し、プロジェクトを管理し、AIエージェントに作業させることができます。

この付録で紹介する3つの方法すべてを設定する必要はありません。状況に合ったものを一つ選んでください。最後にある比較 & 選択ガイドが参考になります。

Tailscale VPNの設定

Tailscaleは、WireGuardというモダンで高性能なVPNプロトコル上に構築されたメッシュVPNサービスです。ルーターやファイアウォールの背後であっても、複雑なネットワーク設定なしに、デバイス間の安全なプライベートネットワークを作成します。

Tailscaleとは？

Tailscaleは、インターネット経由でデバイス同士を接続するプライベートネットワークです。ノートPCとデスクトップの両方にインストールするだけで、デスクトップが同じローカルネットワーク上にあるかのようにアクセスできます。ポートフォワーディング、静的IPアドレス、ルーター設定は一切不要です。

Tailscaleの仕組み: Tailscaleをインストールした各デバイスが仮想プライベートネットワークに参加します。各デバイスには独自のTailscale IPアドレスが割り当てられます。デバイスは物理的な場所に関係なく、これらのIPアドレスを使って直接通信できます。
Tailscaleアカウントを作成する — tailscale.comにアクセスし、Google、Microsoft、GitHub、またはメールアカウントでサインアップします。無料プランは最大100台のデバイスをサポートしており、個人利用には十分です。
AI開発デスクトップにTailscaleをインストールする — ダウンロードページからTailscaleをダウンロードしてインストールします。
Windows

Windowsインストーラーをダウンロードして実行します。インストール後、Tailscaleがシステムトレイに表示されます。

MacOS

MacOSアプリをダウンロードするか、Homebrewでインストールします: brew install --cask tailscale

デスクトップでTailscaleにログインする — Tailscaleを開き、「Log in」をクリックします。ブラウザウィンドウが開くので、手順1で作成したアカウントでデバイスを認証します。認証が完了すると、TailscaleにデバイスのTailscale IPアドレス（例: 100.x.x.x）が表示されます。
リモートデバイスにTailscaleをインストールする — ノートPC、タブレット、またはスマホにも同じようにインストールします。TailscaleはWindows、MacOS、Linux、iOS、Androidをサポートしています。
リモートデバイスでログインする — 同じアカウントを使用してリモートデバイスでログインします。両方のデバイスがlogin.tailscale.comの管理コンソールに表示されます。
接続を確認する — リモートデバイスでターミナルまたはコマンドプロンプトを開き、デスクトップのTailscale IPにpingを実行します。 
ping 100.x.x.x
100.x.x.xをデスクトップのTailscale IPに置き換えてください。応答が返ってくれば、VPN接続は正常に動作しています。
Tailscaleの無料プランは充実しています — 最大100台のデバイス、サブネットルーティング、MagicDNS（自動名前解決）をサポートしています。個人用のリモートアクセスにTailscaleを使うのに料金はかかりません。プランの詳細はtailscale.com/pricingをご覧ください。

NoMachineの設定

NoMachineは、フルグラフィカルデスクトップ体験を提供する無料のリモートデスクトップアプリケーションです。Tailscale（ネットワークトンネルを作成する）とは異なり、NoMachineは完全なビジュアルリモートデスクトップセッションを提供します — まるでマシンの前に座っているかのように、同じ画面、ウィンドウ、アプリケーションが表示されます。

NoMachineとは？

NoMachineはNXプロトコルを使用して、高性能なリモートデスクトップセッションを配信します。高速で応答性が高く、設定が簡単で知られています。送信側（ホスト）と受信側（クライアント）の両方にNoMachineをインストールする必要があります。

NoMachineを使うべき場面: フルグラフィカルデスクトップ体験が必要な場合 — 例えば、Claude Desktop AppのGUIを実行したり、複数のウィンドウを管理したり、ディスプレイが必要なアプリケーションを使用したりする場合。
ホスト（AI開発デスクトップ）にNoMachineをダウンロードする — nomachine.com/downloadにアクセスし、OSに合ったバージョンをダウンロードします。
Windows

NoMachine for Windowsをダウンロードしてインストーラーを実行します。デフォルト設定のまま進めてください。

MacOS

NoMachine for macOSをダウンロードして、Applicationsフォルダにドラッグします。

ホストをインストールして設定する — インストール後、NoMachineは自動的にサービスとして起動します。NoMachineアプリケーションを開き、Settings → Server → Securityに移動します。「Allow connections from other computers」が有効になっていることを確認します。
ホストのIPアドレスを確認する — NoMachineのメインウィンドウに、ホストマシンのローカルIPアドレス（例: 192.168.1.100）が表示されます。インターネット経由で接続する場合は、パブリックIPアドレスが必要になるか、代わりにTailscaleのIPアドレスを使用します。
クライアント（あなたのデバイス）にNoMachineをダウンロードする — リモート接続に使用するデバイスに、同じダウンロードページからNoMachineをダウンロードしてインストールします。NoMachineのクライアントソフトウェアはWindows、MacOS、Linux、iOS、Androidで利用可能です。
ホストに接続する — クライアントデバイスでNoMachineを開きます。「New connection」をクリックし、ホストのIPアドレスを入力します。Tailscaleを使用している場合は、Tailscale IP（例: 100.x.x.x）を入力します。「Connect」をクリックし、プロンプトが表示されたらホストマシンのユーザー名とパスワードを入力します。
ディスプレイ設定を調整する — 接続後、NoMachineメニューから画質と解像度を調整できます。回線が遅い場合は、セッション設定で解像度を下げるか、「Low bandwidth mode」を有効にしてください。
インターネット接続が不安定な場合、NoMachineがラグくなることがあります。その場合は、セッション設定でディスプレイ解像度を下げるか、フルグラフィカルセッションの代わりにTailscaleとコマンドラインアクセス（SSHまたはClaude Code CLI）の組み合わせを検討してください。

Windows RDPの設定

Remote Desktop Protocol（RDP）は、Windows Professional、Enterprise、Educationエディションに組み込まれています。クライアント側に追加のソフトウェアを必要とせず、内蔵のリモートデスクトップ接続ツールを使用してWindowsコンピュータにリモート接続できます。

Windows RDPとは？

Windows RDPはMicrosoftの独自リモートデスクトッププロトコルです。フルグラフィカルなリモートセッションを提供し、Windowsに直接組み込まれているため、ホストマシンにサードパーティソフトウェアをインストールする必要はありません。クライアント側（接続元のデバイス）は、無料のMicrosoft Remote Desktopアプリを使用して、Windows、Mac、iOS、Androidから接続できます。

Windows HomeエディションはRDPホストをサポートしていません。RDPホストとして使用するには、Windows Professional、Enterprise、またはEducationが必要です。Windows Homeをお使いの場合は、代わりにNoMachineを使用してください。
ホストでリモートデスクトップを有効にする — AI開発デスクトップ（Windows）で Win + Sを押し、「Remote Desktop Settings」と入力してEnterを押します。「Enable Remote Desktop」をOnに切り替えます。Windowsが確認を求めたら、「Confirm」をクリックします。
Windowsファイアウォールを設定する — リモートデスクトップを有効にすると、Windowsはポート3389でのRDP接続を許可するファイアウォールルールを自動的に作成します。Windows Defender Firewall → Allow an app or feature through Windows Defender Firewallを開き、Remote Desktopがチェックされていることを確認します。
ルーターにポートフォワーディングを設定する（インターネットアクセス用） — ローカルネットワーク外から接続するには、ルーターでポート3389をホストマシンのローカルIPに転送する必要があります。
  1. ルーターの管理パネルにログインします（通常は 192.168.1.1 または 192.168.0.1）。
  2. Port Forwarding（またはNAT）セクションを見つけます。
  3. 新しいルールを作成します: 外部ポート3389、内部ポート3389、内部IPアドレス = デスクトップのローカルIP（例: 192.168.1.100）、プロトコル = TCP。
  4. ルールを保存して適用します。
ホストのパブリックIPアドレスを確認する — ホストマシンで whatismyipaddress.com にアクセスするか、ブラウザで「What is my IP」を検索します。このアドレスをメモしておきます — クライアントからの接続に使用します。
クライアントデバイスから接続する — リモートデバイスでリモートデスクトップ接続ツールを開きます。
Windowsクライアント

Win + Rを押し、mstscと入力してEnterを押します。ホストのパブリックIPアドレスを入力し、「Connect」をクリックします。

Mac / iOS / Android

App StoreまたはGoogle Playから無料のMicrosoft Remote Desktopアプリをダウンロードします。ホストのパブリックIPアドレスで新しい接続を追加します。

セキュリティ警告: RDPをインターネットに直接公開するのは危険です。自動化されたボットが常にオープンなRDPポートをスキャンしています。リスクを軽減するには: (1) ホストWindowsアカウントに強力で一意のパスワードを設定する、(2) リモートデスクトップ設定でNetwork Level Authentication（NLA）を有効にする、(3) ポートフォワーディングの代わりにTailscale VPNを使用し、RDPをプライベートネットワーク内でのみアクセス可能にする。

比較 & 選択ガイド

それぞれのリモートアクセス方法には長所と短所があります。この比較を使って、状況に合った最適なオプションを見つけてください。

Tailscale VPN

  • 暗号化メッシュVPN（WireGuard）
  • ポートフォワーディング不要
  • NAT / ファイアウォール越えで動作
  • 最大100台まで無料
  • コマンドラインアクセス
  • CLI / SSHワークフローに最適
  • 最小限の帯域幅オーバーヘッド

NoMachine

  • フルグラフィカルリモートデスクトップ
  • 高性能（NXプロトコル）
  • 個人利用は無料
  • クロスプラットフォーム（Win/Mac/Linux）
  • 簡単なインストール
  • GUIワークフローに最適
  • 画質設定の調整可能

Windows RDP

  • Windows Pro+に組み込み
  • ホスト側の追加ソフトウェア不要
  • フルデスクトップ体験
  • インターネット接続にはポートフォワーディングが必要
  • 直接公開時のセキュリティリスク
  • 純粋なWindows環境に最適
  • Microsoft Remote Desktopクライアント

おすすめの組み合わせ

シナリオ おすすめの構成 理由
コマンドラインのみ（Claude Code CLI、SSH、ターミナル） Tailscale単体 軽量、安全、GUIのオーバーヘッドなし
リモートでClaude Desktop AppのGUIが必要 Tailscale + NoMachine Tailscaleが安全なトンネルを提供し、NoMachineがグラフィカルセッションを提供
Windowsのみの環境、サードパーティソフトウェア不要 Windows RDP 組み込み機能、ホスト側の追加インストール不要
Windows Pro + 最大限のセキュリティ Tailscale + Windows RDP Tailscaleがポートフォワーディングを不要にし、RDPはプライベートVPNネットワーク内にとどまる
初心者の方へ: 最も簡単に始められる組み合わせはTailscale + NoMachineです。両方のマシンにTailscaleをインストールして安全なネットワークを作成し、NoMachineでフルグラフィカルリモートデスクトップセッションを使用します。この組み合わせはWindowsとMacOSの両方で動作し、ルーターの設定が不要で、接続を安全に保ちます。

トラブルシューティング

最も一般的なリモートアクセス問題の解決策を以下に示します。

ホストマシンに接続できない — まず、ホストマシンが電源オンでインターネットに接続されていることを確認します。次に以下をチェックしてください:
  • Tailscale: 両方のデバイスがTailscale管理コンソールでオンラインとして表示されている必要があります。Tailscaleサービスの再起動を試してください。
  • NoMachine: ホストでNoMachineが実行されており、Server設定で「Allow connections」が有効になっていることを確認してください。
  • RDP: Windows設定でリモートデスクトップが有効になっており、ポート3389がルーターまたはISPによってブロックされていないことを確認してください。
接続が非常に遅い、またはラグい — リモートデスクトップのパフォーマンスはインターネット接続速度に依存します。以下の対策を試してください:
  • リモートデスクトップクライアント設定でディスプレイ解像度を下げる。
  • ホストマシンの不要なアプリケーションを閉じてリソースを解放する。
  • NoMachineでは、セッション設定で「Low bandwidth mode」を有効にするか、ディスプレイ画質を下げる。
  • RDPを使用している場合、接続オプションのディスプレイ設定を調整する（色深度を下げる、壁紙を無効にする、フォントスムージングを無効にする）。
  • ポートフォワーディング経由のパブリックインターネットではなく、Tailscale（ローカルVPNパス）経由で接続する。
認証またはログインに失敗する — ログインできない場合:
  • ユーザー名とパスワードを再確認してください。Windows RDPの場合、ホストマシンのWindowsアカウントの認証情報を使用する必要があります。
  • Tailscaleの場合、両方のデバイスが同じTailscaleアカウントにログインしていることを確認してください。
  • NoMachineの場合、ホストマシンのOSのユーザー名とパスワードを入力していることを確認してください（設定していなければNoMachine専用のパスワードではありません）。
  • ホストで最近パスワードを変更した場合、リモートクライアントが古い認証情報をキャッシュしている可能性があります。保存されたパスワードをクリアして再試行してください。
リモートセッションでオーディオまたはクリップボードが動作しない — これらの機能はよく影響を受けます:
  • オーディオ: NoMachineでは、Settings → Audioで「Audio playback」と「Audio recording」が有効になっていることを確認します。RDPでは、接続オプションのLocal Resourcesタブで「Record from this computer」をチェックします。
  • クリップボード: NoMachineとRDPの両方がクリップボード共有をサポートしていますが、セッション設定で有効にする必要があります。NoMachineでは、入力設定パネルの「Copy and paste」オプションを確認してください。
Tailscaleデバイスがオフラインと表示される — デバイスがTailscale管理コンソールでオフラインと表示されるが、実行中であることが分かっている場合:
  • Tailscaleサービスが実行されていることを確認してください。WindowsではシステムトレイのTailscaleアイコンを確認します。MacOSではメニューバーのアイコンを確認します。
  • Tailscaleサービスの再起動を試してください。Windows: Servicesを開き、「Tailscale」を見つけて右クリックし、Restartを選択します。MacOS: Tailscaleアプリを終了して再起動します。
  • デバイスがインターネットアクセスを持っていることを確認してください（Tailscaleはインターネット接続なしでは機能しません）。
  • 企業や学校のネットワークを使用している場合、ファイアウォールがWireGuardトラフィックをブロックしている可能性があります。ネットワーク管理者に連絡するか、別のネットワークを試してください。
それでも解決しない場合: 上記の解決策で問題が解決しない場合は、各ツールの公式ドキュメントを確認してください: Tailscaleナレッジベース、NoMachineサポート、またはMicrosoft RDPドキュメント。
