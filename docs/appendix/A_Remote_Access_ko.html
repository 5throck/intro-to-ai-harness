원격 접속 환경 설정

이 별첨에서는 외부에서 AI 개발 환경에 접속하는 세 가지 방법 — Tailscale VPN, NoMachine, Windows RDP —을 설명합니다.

이 별첨에서 다루는 것
  • 왜 원격 접속이 필요한가
  • Tailscale VPN 설정 (전 세계 어디서나)
  • NoMachine 설정 (고성능 원격 데스크톱)
  • Windows RDP 설정 (Windows 기본)
  • 비교 및 선택 가이드
  • 문제 해결

왜 원격 접속이 필요한가

AI 개발 환경은 일반적으로 강력한 데스크톱 컴퓨터에 구축합니다. 빠른 CPU, 충분한 RAM, 전용 GPU가 필요하기 때문입니다. 하지만 언제나 그 컴퓨터 앞에 앉아 있을 수는 없습니다. 카페에서 노트북으로 작업하고 싶거나, 여행 중에 태블릿으로 확인하고 싶거나, 다른 방에서 접속하고 싶을 때가 있습니다.

원격 접속을 설정하면 어디서든 내 강력한 데스크톱 컴퓨터에 연결할 수 있습니다. Claude Code를 실행하고, 프로젝트를 관리하고, AI 에이전트가 작업하게 만드는 모든 것을 물리적으로 그 자리에 있지 않아도 할 수 있습니다.

원격 접속은 "내 집 컴퓨터를 밖에서 쓰는 것"과 같습니다. 마치 원격 제어 TV를 사용하듯이, 카페나 회사에서 집에 있는 강력한 컴퓨터를 그대로 조작할 수 있습니다.
이 별첨에서 설명하는 세 가지 방법을 모두 설정할 필요는 없습니다. 상황에 맞는 하나를 선택하세요. 마지막의 비교 및 선택 가이드가 결정을 도와드립니다.

Tailscale VPN 설정

Tailscale은 WireGuard 기반의 Mesh VPN 서비스입니다. 라우터와 방화벽 뒤에 있어도 기기 간에 보안된 사설 네트워크를 만들어줍니다. 복잡한 네트워크 설정 없이, 몇 번의 클릭만으로 외부에서 내 컴퓨터에 접속할 수 있습니다.

Tailscale이란?

Tailscale은 인터넷을 통해 내 기기들을 연결하는 사설 네트워크입니다. 노트북과 데스크톱에 모두 설치하면, 마치 같은 로컬 네트워크에 있는 것처럼 데스크톱에 접속할 수 있습니다. 포트 포워딩, 고정 IP, 라우터 설정이 필요 없습니다.

Tailscale 작동 방식: Tailscale을 설치한 모든 기기가 가상 사설 네트워크에 참여합니다. 각 기기는 고유의 Tailscale IP 주소를 받습니다. 기기들은 물리적 위치와 상관없이 이 IP 주소로 직접 통신할 수 있습니다.

주요 장점

  • 설정 간단 — 몇 분 안에 설치 및 활성화 완료
  • NAT 통과 — 라우터 설정 변경 불필요
  • 자동 암호화 — WireGuard 프로토콜로 엔드투엔드 암호화
  • 무료 — 개인용으로 최대 100대 기기까지 무료
  • 크로스 플랫폼 — Windows, macOS, Linux, iOS, Android 지원

설치 단계

1. Tailscale 가입 — tailscale.com/signup 에 접속하여 Google, Microsoft, GitHub 또는 이메일 계정으로 가입합니다. 무료 플랜으로 100대까지 연결 가능하며, 개인 사용에는 충분합니다.
2. 호스트 PC에 Tailscale 설치 — 다운로드 페이지에서 운영체제에 맞는 버전을 설치합니다.
Windows

Windows 설치 파일을 다운로드하고 실행합니다. 설치가 완료되면 시스템 트레이에 Tailscale 아이콘이 나타납니다.

macOS

macOS 앱을 다운로드하거나 Homebrew로 설치합니다:

brew install --cask tailscale
3. 로그인 및 활성화 — Tailscale 앱을 열고 "로그인"을 클릭합니다. 브라우저가 열리면 1단계에서 만든 계정으로 인증합니다. 인증이 완료되면 Tailscale이 기기의 Tailscale IP 주소를 표시합니다 (예: 100.x.x.x).
4. 클라이언트 PC에 Tailscale 설치 — 원격으로 접속할 기기(노트북, 태블릿, 폰)에도 Tailscale을 설치합니다. Windows, macOS, Linux, iOS, Android 모두 지원합니다.
5. 같은 계정으로 로그인 — 클라이언트 기기에서 같은 계정으로 로그인합니다. 두 기기 모두 Tailscale 관리 콘솔에 표시됩니다.
6. 호스트 IP 확인 — 클라이언트 기기에서 터미널 또는 명령 프롬프트를 열고, 다음 명령어로 호스트 IP를 확인합니다: 
tailscale ip

또는 호스트 PC에서 직접 확인할 수 있습니다:

Windows

시스템 트레이의 Tailscale 아이콘을 클릭하면 IP 주소가 표시됩니다.

macOS

메뉴 바의 Tailscale 아이콘을 클릭하면 IP 주소가 표시됩니다.

7. 연결 테스트 — 클라이언트 기기에서 호스트로 ping 테스트를 실행합니다: 
ping 100.x.x.x

100.x.x.x를 호스트의 실제 Tailscale IP로 변경하세요. 응답이 돌아오면 VPN 연결이 정상 작동하는 것입니다.

Tailscale 무료 플랜은 매우 넉넉합니다. 최대 100대의 기기를 연결할 수 있고, 서브넷 라우팅과 MagicDNS(자동 이름 해결)도 포함됩니다. 개인용 원격 접속에는 비용을 지불할 필요가 없습니다. 자세한 내용은 tailscale.com/pricing을 참조하세요.

NoMachine 설정

NoMachine은 무료 원격 데스크톱 애플리케이션으로, 완전한 그래픽 데스크톱 환경을 제공합니다. Tailscale이 네트워크 터널을 만드는 것과 달리, NoMachine은 완전한 시각적 원격 데스크톱 세션을 제공합니다 — 마치 그 컴퓨터 앞에 앉아 있는 것처럼 화면, 창, 애플리케이션을 그대로 볼 수 있습니다.

NoMachine이란?

NoMachine은 NX 프로토콜을 사용하여 고성능 원격 데스크톱 세션을 전달합니다. 빠르고 반응성이 뛰어나며 설정이 간편한 것으로 알려져 있습니다. 송신 측(호스트)과 수신 측(클라이언트) 모두에 NoMachine이 설치되어 있어야 합니다.

언제 NoMachine을 사용할까요?: Claude Desktop App GUI를 원격으로 실행하거나, 여러 창을 관리하거나, 디스플레이가 필요한 애플리케이션을 사용할 때. 즉, 화면이 보이는 완전한 데스크톱 환경이 필요한 경우에 적합합니다.

주요 장점

  • 저지연 — NX 프로토콜로 빠르고 반응성 높은 세션
  • 고품질 화질 — 선명한 화면 전송
  • 무료 — 개인용으로 완전 무료
  • 크로스 플랫폼 — Windows, macOS, Linux, iOS, Android 지원
  • 불안정한 연결에도 강함 — 인터넷 연결이 끊기더라도 세션 유지

설치 단계

1. NoMachine 다운로드 — nomachine.com/download 에서 운영체제에 맞는 버전을 다운로드합니다.
Windows

NoMachine for Windows를 다운로드하고 설치합니다. 기본 설정을 그대로 적용하세요.

macOS

NoMachine for macOS를 다운로드하고 애플리케이션 폴더로 드래그합니다.

Linux

배포판에 맞는 .deb, .rpm 또는 .tar.gz 패키지를 다운로드합니다.

2. 호스트 PC에 설치 — AI 개발 데스크톱(호스트)에 NoMachine을 설치합니다. 설치가 완료되면 NoMachine이 자동으로 서비스로 시작됩니다.
3. 서비스 활성화 — NoMachine 앱을 열고 설정 → 서버 → 보안으로 이동합니다. "다른 컴퓨터의 연결 허용"이 활성화되어 있는지 확인하세요.
4. 호스트 IP 확인 — NoMachine 메인 창에서 호스트 컴퓨터의 로컬 IP 주소를 확인합니다 (예: 192.168.1.100). 인터넷을 통해 연결하려면 공인 IP 주소가 필요하거나, Tailscale IP 주소를 사용합니다. 
# 로컬 IP 확인 (Windows)
ipconfig

# 로컬 IP 확인 (macOS / Linux)
ifconfig
5. 클라이언트 PC에 설치 — 원격으로 접속할 기기에 NoMachine을 다운로드하여 설치합니다. Windows, macOS, Linux, iOS, Android 클라이언트 모두 지원됩니다.
6. 호스트에 연결 — 클라이언트 기기에서 NoMachine을 열고 "새 연결"을 클릭합니다. 호스트의 IP 주소를 입력합니다. Tailscale을 사용 중이라면 Tailscale IP (예: 100.x.x.x)를 입력하세요. "연결"을 클릭하고 호스트 컴퓨터의 사용자 이름과 비밀번호를 입력합니다.
NoMachine은 인터넷 연결이 불안정한 환경에서도 잘 동작합니다. 세션 설정에서 "저대역폭 모드"를 활성화하거나 해상도를 낮추면 더 안정적으로 사용할 수 있습니다.

Windows RDP 설정

원격 데스크톱 프로토콜(RDP)은 Windows Professional, Enterprise, Education 에디션에 내장되어 있습니다. 추가 소프트웨어 없이 내장된 원격 데스크톱 연결 도구를 사용하여 Windows 컴퓨터에 원격으로 연결할 수 있습니다.

Windows RDP란?

Windows RDP는 Microsoft의 원격 데스크톱 프로토콜입니다. 완전한 그래픽 원격 세션을 제공하며, Windows에 직접 내장되어 있어 호스트 컴퓨터에 서드파티 소프트웨어를 설치할 필요가 없습니다. 클라이언트 측(연결하는 기기)은 무료 Microsoft Remote Desktop 앱을 사용하여 Windows, Mac, iOS, Android에서 접속할 수 있습니다.

Windows Home 에디션은 RDP 호스팅을 지원하지 않습니다. RDP 호스트로 사용하려면 Windows Professional, Enterprise 또는 Education이 필요합니다. Windows Home을 사용 중이라면 NoMachine을 대신 사용하세요.

설정 단계

1. 원격 데스크톱 활성화 — 호스트 컴퓨터(Windows)에서 Win + S를 누르고 "원격 데스크톱 설정"을 입력한 후 Enter를 누릅니다. "원격 데스크톱 사용"을 켜기로 전환합니다. Windows에서 확인을 요청하면 확인을 클릭합니다.
2. 방화벽 규칙 확인 — 원격 데스크톱을 활성화하면 Windows가 자동으로 포트 3389에 대한 RDP 연결을 허용하는 방화벽 규칙을 만듭니다. Windows Defender 방화벽 → 앱 또는 기능을 Windows Defender 방화벽을 통해 허용에서 원격 데스크톱이 체크되어 있는지 확인합니다.
3. 사용자 계정 확인 — 원격으로 로그인할 Windows 사용자 계정과 비밀번호를 확인합니다. 해당 계정은 관리자 권한을 가진 것이 좋습니다. 
# 현재 사용자 이름 확인
whoami

# 시스템 정보 확인
systeminfo | findstr /B /C:"호스트 이름" /C:"OS 이름"
4. RDP 포트 포워딩 설정 (인터넷 접속 시) — 로컬 네트워크 외부에서 연결하려면 공유기에서 포트 3389를 호스트 머신의 로컬 IP로 포워딩해야 합니다.
  1. 공유기 관리 패널에 로그인합니다 (일반적으로 192.168.1.1 또는 192.168.0.1).
  2. 포트 포워딩 (또는 NAT) 섹션을 찾습니다.
  3. 새 규칙 생성: 외부 포트 3389, 내부 포트 3389, 내부 IP = 데스크톱의 로컬 IP (예: 192.168.1.100), 프로토콜 = TCP.
  4. 규칙을 저장하고 적용합니다.
5. 호스트 공인 IP 확인 — 호스트 컴퓨터에서 브라우저를 열고 whatismyipaddress.com에 접속하거나 "내 IP 주소"를 검색합니다. 이 주소를 기록해두세요 — 클라이언트에서 연결할 때 사용합니다.
6. 클라이언트에서 연결 — 원격 기기에서 원격 데스크톱 연결 도구를 엽니다.
Windows 클라이언트

Win + R을 누르고 mstsc를 입력한 후 Enter를 누릅니다. 호스트의 공인 IP 주소를 입력하고 "연결"을 클릭합니다.

mstsc
Mac / iOS / Android

App Store 또는 Google Play에서 무료 Microsoft Remote Desktop 앱을 다운로드합니다. 호스트의 공인 IP 주소로 새 연결을 추가합니다.

보안 경고: RDP를 인터넷에 직접 노출하면 보안 위험이 매우 큽니다. 자동화된 봇이 끊임없이 열린 RDP 포트를 스캔합니다. 위험을 줄이려면: (1) 호스트 Windows 계정에 강력하고 고유한 비밀번호를 사용하고, (2) 원격 데스크톱 설정에서 네트워크 수준 인증(NLA)을 활성화하고, (3) 포트 포워딩 대신 Tailscale VPN을 사용하여 RDP를 사설 네트워크 내에서만 접근 가능하게 하는 것을 강력히 추천합니다.

Tailscale VPN

  • WireGuard 기반 암호화
  • 포트 포워딩 불필요
  • NAT / 방화벽 통과
  • 최대 100대까지 무료
  • 명령줄 접속에 최적
  • 대역폭 오버헤드 최소
  • 가장 안전한 방법

NoMachine

  • 완전한 그래픽 데스크톱
  • 고성능 (NX 프로토콜)
  • 개인용 무료
  • 크로스 플랫폼
  • 설치 간편
  • GUI 워크플로우에 최적
  • 화질 조절 가능

Windows RDP

  • Windows Pro+ 내장
  • 호스트 추가 소프트웨어 불필요
  • 완전한 데스크톱 환경
  • 인터넷 접속 시 포트 포워딩 필요
  • 직접 노출 시 보안 위험
  • 순수 Windows 환경에 최적
  • Microsoft Remote Desktop 클라이언트

초보자 추천: 가장 먼저 Tailscale을 설정하세요. 가장 간단하고 안전합니다. 그래픽 환경이 필요하면 Tailscale + NoMachine 조합을 사용하세요. 두 기기에 모두 Tailscale을 설치하여 보안 네트워크를 만든 다음, NoMachine으로 완전한 원격 데스크톱 세션을 사용합니다. Windows와 macOS 모두에서 작동하며, 라우터 설정이 필요 없고 연결이 안전하게 유지됩니다.

문제 해결

원격 접속에서 가장 흔하게 발생하는 문제와 해결 방법을 정리했습니다.

1. 연결이 안 됩니다 — 먼저 호스트 컴퓨터가 켜져 있고 인터넷에 연결되어 있는지 확인합니다. 그 다음 각 도구별로 확인합니다:
  • Tailscale: 두 기기 모두 Tailscale 관리 콘솔에 온라인으로 표시되어야 합니다. Tailscale 서비스를 재시작해보세요.
  • NoMachine: 호스트에서 NoMachine이 실행 중이고, 서버 설정에서 "연결 허용"이 활성화되어 있는지 확인하세요.
  • RDP: Windows 설정에서 원격 데스크톱이 활성화되어 있는지, 포트 3389가 공유기나 ISP에 의해 차단되지 않았는지 확인하세요.
2. 속도가 너무 느리거나 끊깁니다 — 원격 데스크톱 성능은 인터넷 연결 속도에 좌우됩니다. 다음 방법을 시도해보세요:
  • 원격 데스크톱 클라이언트 설정에서 디스플레이 해상도를 낮추세요.
  • 호스트 컴퓨터에서 불필요한 애플리케이션을 닫아 리소스를 확보하세요.
  • NoMachine의 경우 세션 설정에서 "저대역폭 모드"를 활성화하거나 화질을 낮추세요.
  • RDP의 경우 연결 옵션에서 색상 심도를 낮추고, 배경화면과 글꼴 다듬기를 비활성화하세요.
  • 포트 포워딩을 통한 공개 인터넷 대신 Tailscale (로컬 VPN 경로)을 통해 연결하세요.
3. 인증 또는 로그인이 실패합니다 — 로그인할 수 없는 경우:
  • 사용자 이름과 비밀번호를 다시 확인하세요. Windows RDP의 경우 호스트 컴퓨터의 Windows 계정 자격 증명을 사용해야 합니다.
  • Tailscale의 경우 두 기기가 같은 Tailscale 계정으로 로그인되어 있는지 확인하세요.
  • NoMachine의 경우 호스트 컴퓨터의 운영체제 사용자 이름과 비밀번호를 입력해야 합니다 (별도 NoMachine 비밀번호를 설정하지 않은 한).
  • 최근에 호스트에서 비밀번호를 변경했다면, 클라이언트에 이전 자격 증명이 캐시되어 있을 수 있습니다. 저장된 비밀번호를 지우고 다시 시도하세요.
4. 방화벽에 의해 차단됩니다 — 연결이 방화벽에 의해 차단된 경우:
  • Windows Defender 방화벽에서 Tailscale, NoMachine, 원격 데스크톱이 "허용"되어 있는지 확인하세요.
  • 공유기 방화벽에서 필요한 포트가 열려 있는지 확인합니다: Tailscale (자동 처리), NoMachine (포트 4000), RDP (포트 3389).
  • 회사나 학교 네트워크를 사용 중이라면 네트워크 관리자가 VPN 트래픽을 차단하고 있을 수 있습니다. 관리자에게 문의하거나 다른 네트워크를 사용해보세요.
5. 다중 모니터 관련 문제 — 여러 모니터가 원격 세션에서 제대로 표시되지 않는 경우:
  • RDP: 연결하기 전 "디스플레이 구성" 탭에서 "모든 모니터 사용" 옵션을 확인하세요.
  • NoMachine: 세션 설정에서 모니터 레이아웃을 조정할 수 있습니다. 단일 모니터로 전환하면 성능이 향상될 수 있습니다.
  • 원격 세션에서 Win + P를 눌러 디스플레이 모드 (복제, 확장, 단일 화면)를 변경하세요.
  • 문제가 지속되면 클라이언트 기기에서 모니터를 하나만 연결한 상태로 연결한 다음, 세션 내에서 디스플레이 설정을 조정하세요.
그래도 해결되지 않나요? 위의 해결법으로 문제가 해결되지 않는다면 각 도구의 공식 문서를 확인하세요: Tailscale 지식 베이스, NoMachine 지원, Microsoft RDP 문서.
