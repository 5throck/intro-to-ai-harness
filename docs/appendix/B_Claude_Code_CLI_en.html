Appendix B

Claude Code CLI Guide

This appendix explains how to install the Claude Code CLI (command-line interface), how to use it day to day, and its key commands. The main tool of this handbook is the Claude Desktop App, but the CLI unlocks more powerful automation.

What This Appendix Covers
  • CLI vs Desktop App comparison
  • Installing the Claude Code CLI
  • Basic usage (terminal conversation)
  • Key commands
  • Project mode
  • Practical tips

1. CLI vs Desktop App

There are two ways to use Claude. One is the Claude Desktop App (a desktop application), and the other is the Claude Code CLI (command-line interface). The two differ in purpose and in how you use them, and each has its own strengths and weaknesses.

Item Claude Desktop App Claude Code CLI
Interface GUI (graphical) Terminal (command line)
Difficulty Easy Intermediate
Automation Limited Powerful (script integration)
File access Project folder Entire system
Agent support Claude only Claude + third-party backends
Recommended for Beginners Intermediate and above
The Desktop App is like 'automatic mode' in a car, and the CLI is 'manual mode'. The CLI gives you more control but requires learning. It is like learning to drive an automatic and switching to manual once you are comfortable.
Every exercise in this handbook can be done with the Claude Desktop App. The CLI is optional. If you need the CLI, this appendix will walk you through installing and using it.

2. Installing the Claude Code CLI

Installing the Claude Code CLI requires a few prerequisites. Once you are ready, follow the steps in order.

Prerequisites

  • Node.js 18 or later — the Claude Code CLI runs on Node.js
  • A Claude Pro or Max subscription — a paid Anthropic Claude account is required
  • A terminal app — macOS Terminal, Windows PowerShell, Linux Bash, etc.
Step 1: Check that Node.js is installed

Open a terminal and enter the following command to check whether Node.js is installed:

node --version

Expected result: a version number such as v18.x.x or higher is printed. If the version is below 18 or you get a "command not found" message, install the latest LTS version from nodejs.org.

Step 2: Install the Claude Code CLI

Once Node.js is confirmed, install the Claude Code CLI globally using npm:

npm install -g @anthropic-ai/claude-code

Expected result: the package downloads and installation completes. It may take a few minutes.

Step 3: Verify the installation

When installation finishes, check the version to confirm it was installed correctly:

claude --version

Expected result: the Claude Code version number is printed (e.g., 1.0.x). If you get an error, retry step 2.

Step 4: Authenticate with your Claude account

The first time you run claude in a terminal, you will be asked to log in with your Anthropic account:

claude

A browser opens and takes you to the Anthropic login page. Log in with your Claude Pro or Max subscription account. Once authentication completes, you can use Claude Code from the terminal.

Notes per operating system

Windows:

  • Run PowerShell as administrator
  • Be sure to check the "Add to PATH" option when installing Node.js
  • Open a new PowerShell window after installation so PATH takes effect

macOS:

  • Use the default Terminal app or iTerm2
  • If you have Homebrew, you can also install Node.js with brew install node

Linux (Ubuntu/Debian):

  • Use sudo apt install nodejs npm or nvm (Node Version Manager)
  • Global installs may require sudo: sudo npm install -g @anthropic-ai/claude-code
On Windows, run PowerShell as administrator to install it. Global package installation can fail with ordinary user privileges. Right-click the PowerShell icon and choose "Run as administrator".
Without a Claude Pro or Max subscription you cannot use the CLI. Free Claude accounts work only in the Claude.ai web interface. You can subscribe at claude.ai.

3. Basic Usage

Let's look at the basics of the Claude Code CLI. Unlike the Desktop App, this is a text-based conversation in the terminal.

Starting Claude Code

Open a terminal and enter the following command:

claude

When Claude Code starts, a prompt (the > symbol) appears; type your questions or instructions there.

How to converse

Just type your question at the prompt in natural language. As with the Desktop App, both Korean and English work.

Show me the list of files in the current folder

Because Claude Code can access the file system, it can also handle requests like "read the files in the current folder" or "find the bug in this file".

Reading/writing file example

Reading a file:

Read the contents of README.md and summarize it

Writing a file:

Create hello.py and write Python code that prints "Hello, World!"

Claude Code can create and modify files directly. Before doing so, it always explains what changes it will make and asks for approval.

Exiting

There are two ways to exit Claude Code:

# Method 1: exit with a command
/exit

# Method 2: exit with a shortcut
Ctrl + C

4. Key Commands

Here are the main commands available in the Claude Code CLI. You enter them in the Claude Code conversation, starting with /.

Command Description Example
claude Start Claude Code claude
/help Show help /help
/clear Reset the conversation /clear
/exit Exit Claude Code /exit
/model Change the model in use /model claude-sonnet-5
/cost Check the current session's cost /cost
/compact Compress context (summarize conversation) /compact

Command usage examples

/help — Help

Displays the list of all available commands with brief descriptions:

/help

/clear — Reset the conversation

Erases the current conversation and starts a new one. Useful when the context grows long and response quality drops:

/clear

/model — Change the model

Changes the Claude model used in the current session. The available model list depends on your Claude subscription level:

# Switch to the Sonnet model (fast and cost-efficient)
/model claude-sonnet-5

# Switch to the Opus model (most powerful, higher cost)
/model claude-opus-5

/cost — Check cost

Shows the number of tokens used and the estimated cost for the current session. Useful for monitoring API usage:

/cost

/compact — Compress context

As a conversation gets longer, Claude's context window — its "memory capacity" — fills up. /compact summarizes the previous conversation to free up space:

/compact
/compact is one of the most important commands when using Claude Code. Run it regularly whenever the conversation gets long. Otherwise Claude may forget earlier parts of the conversation or response quality may degrade.

5. Project Mode

The true strength of the Claude Code CLI shows in project mode. When you run Claude Code in a project folder, Claude understands the project's file structure and configuration and performs context-aware work.

Running Claude Code in a project

Step 1: Move into the project folder

In the terminal, move into the project folder you want to work on:

cd ~/my-project
Step 2: Start Claude Code

Run Claude Code inside the project folder:

claude
Step 3: Project context recognition

Claude Code automatically analyzes the project's file structure. You can now ask questions about the project:

Explain the structure of this project
Step 4: Agent dispatch

In projects that have an AGENTS.md, Claude Code recognizes your agents and delegates specialized tasks to the appropriate agent (dispatch):

Generate the design_spec.md for this project

Claude Code dispatches the design agent through the PM gateway and carries out the task.

In project mode, Claude Code reads AGENTS.md and recognizes the agents. Work is distributed automatically according to the agent rules, permissions, and workflows defined in AGENTS.md. This is one of the biggest reasons to use the Claude Code CLI.

Advantages of project mode

  • File context awareness — automatically analyzes the project's file structure, dependencies, and config files
  • Agent workflows — Claude automatically leverages the multi-agent system defined in AGENTS.md
  • Script integration — Claude Code can be included in CI/CD pipelines and automation scripts
  • Third-party backends — switch to DeepSeek, GLM, etc. to cut costs (see Appendix C)

6. Practical Tips

Here are five practical tips for getting more out of the Claude Code CLI.

Tip 1: Always start from the project folder

Before running Claude Code, move into the project folder with the cd command. Run it outside the project folder and Claude cannot grasp the file context:

# Good example
cd ~/my-project
claude

# Bad example — running from the home directory
claude
Tip 2: Manage context with /compact

Long conversations fill up Claude's context window. Run /compact periodically to summarize the conversation and free up space. It is especially effective after file analysis or code review:

# Run every 10-15 conversation turns
/compact
Tip 3: Monitor cost with /cost

Keep an eye on how much cost accrues while using Claude Code. This is especially useful for managing Claude Pro subscription limits:

# Check the session cost
/cost
Tip 4: Keep AGENTS.md up to date

Your project's AGENTS.md file is Claude Code's "instruction manual". Agent definitions, permissions, and workflows are defined there. If AGENTS.md is out of date, Claude may invoke the wrong agents:

# Check AGENTS.md
claude
# "Show me the list of agents in the current project"
Tip 5: Combine the Claude Code CLI with a low-cost backend

The CLI's biggest advantage is that it works with third-party backends. Hooking up low-cost backends such as DeepSeek, GLM, or LiteLLM lets you run Claude Code for less than a Claude Pro subscription:

# Example of switching to the DeepSeek backend
export ANTHROPIC_API_KEY="your-deepseek-key"
export ANTHROPIC_BASE_URL="https://api.deepseek.com/anthropic"
claude

For detailed setup instructions, see Appendix C: Low-Cost AI Backend Integration.

When starting out with the CLI, begin with simple questions. Learn how Claude Code behaves with simple requests like "show me the file structure of the current folder" or "find the problems in this code", then gradually expand to more complex tasks.
The Claude Code CLI can feel difficult if you are not used to terminal environments at first. But knowing just a few basic commands is enough. All you really need to remember is: start with claude, exit with /exit, and maintain with /compact.
