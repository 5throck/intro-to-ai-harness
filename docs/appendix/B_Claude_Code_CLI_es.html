Apéndice B

Guía de Claude Code CLI

Este apéndice explica la instalación del Claude Code CLI (interfaz de línea de comandos), su uso básico y sus comandos principales. La herramienta principal de este manual es Claude Desktop App, pero con la CLI puedes lograr una automatización más potente.

Lo que cubre este apéndice
  • Comparación entre CLI y Desktop App
  • Instalación de Claude Code CLI
  • Uso básico (conversación en la terminal)
  • Comandos principales
  • Modo proyecto
  • Consejos prácticos

1. CLI vs Desktop App

Hay dos formas de usar Claude. Una es la Claude Desktop App (aplicación de escritorio) y la otra es el Claude Code CLI (interfaz de línea de comandos). Ambas difieren en propósito y forma de uso, y cada una tiene sus ventajas e inconvenientes.

Aspecto Claude Desktop App Claude Code CLI
Interfaz GUI (gráfica) Terminal (línea de comandos)
Dificultad Fácil Intermedia
Automatización Limitada Potente (integración con scripts)
Acceso a archivos Carpeta del proyecto Sistema completo
Soporte de agentes Solo Claude Claude + backends de terceros
Recomendado para Principiantes Nivel intermedio o superior
La Desktop App es el "modo automático" de un coche, y la CLI es el "modo manual". La CLI da más control pero requiere aprendizaje. Es como aprender a conducir en automático y pasar al manual cuando ya te sientes cómodo.
Todos los ejercicios de este manual se pueden hacer con Claude Desktop App. La CLI es opcional. Si necesitas la CLI, este apéndice te guiará en su instalación y uso.

2. Instalación de Claude Code CLI

Instalar el Claude Code CLI requiere algunos requisitos previos. Cuando estés listo, sigue los pasos en orden.

Requisitos previos

  • Node.js 18 o superior — el Claude Code CLI funciona sobre Node.js
  • Suscripción Claude Pro o Max — se necesita una cuenta de pago de Anthropic Claude
  • Una app de terminal — macOS Terminal, Windows PowerShell, Linux Bash, etc.
Paso 1: Comprobar que Node.js está instalado

Abre una terminal e introduce el siguiente comando para comprobar si Node.js está instalado:

node --version

Resultado esperado: se muestra un número de versión como v18.x.x o superior. Si la versión es inferior a 18 o aparece un mensaje de "comando no encontrado", instala la última versión LTS desde nodejs.org.

Paso 2: Instalar Claude Code CLI

Cuando hayas confirmado Node.js, instala el Claude Code CLI globalmente con npm:

npm install -g @anthropic-ai/claude-code

Resultado esperado: el paquete se descarga y la instalación se completa. Puede tardar unos minutos.

Paso 3: Verificar la instalación

Al terminar la instalación, comprueba la versión para verificar que se instaló correctamente:

claude --version

Resultado esperado: se muestra el número de versión de Claude Code (por ejemplo, 1.0.x). Si da un error, repite el paso 2.

Paso 4: Autenticarte con tu cuenta de Claude

La primera vez que ejecutes claude en la terminal, se te pedirá iniciar sesión con tu cuenta de Anthropic:

claude

Se abre el navegador y te lleva a la página de inicio de sesión de Anthropic. Inicia sesión con tu cuenta de suscripción Claude Pro o Max. Tras completar la autenticación, podrás usar Claude Code desde la terminal.

Notas según el sistema operativo

Windows:

  • Ejecuta PowerShell con privilegios de administrador
  • Asegúrate de marcar la opción "Add to PATH" al instalar Node.js
  • Tras la instalación, abre una nueva ventana de PowerShell para que PATH surta efecto

macOS:

  • Usa la app Terminal predeterminada o iTerm2
  • Si tienes Homebrew, también puedes instalar Node.js con brew install node

Linux (Ubuntu/Debian):

  • Usa sudo apt install nodejs npm o nvm (Node Version Manager)
  • Las instalaciones globales pueden requerir sudo: sudo npm install -g @anthropic-ai/claude-code
En Windows, ejecuta PowerShell con privilegios de administrador para instalarlo. Con permisos de usuario normal, la instalación global de paquetes puede fallar. Haz clic derecho en el icono de PowerShell y elige "Ejecutar como administrador".
Sin una suscripción Claude Pro o Max no podrás usar la CLI. Las cuentas gratuitas de Claude solo funcionan en la interfaz web de Claude.ai. Puedes suscribirte en claude.ai.

3. Uso básico

Vamos a ver el uso básico del Claude Code CLI. A diferencia de la Desktop App, se trata de una conversación por texto en la terminal.

Iniciar Claude Code

Abre una terminal e introduce el siguiente comando:

claude

Cuando arranque Claude Code aparecerá el prompt (el símbolo >), donde escribirás tus preguntas o instrucciones.

Cómo conversar

Basta con escribir tu pregunta en lenguaje natural en el prompt. Igual que en la Desktop App, funcionan tanto coreano como inglés.

Muéstrame la lista de archivos de la carpeta actual

Como Claude Code puede acceder al sistema de archivos, también atiende peticiones como "lee los archivos de la carpeta actual" o "encuentra el bug de este archivo".

Ejemplo de lectura/escritura de archivos

Lectura de un archivo:

Lee el contenido del archivo README.md y resúmelo

Escritura de un archivo:

Crea el archivo hello.py y escribe código Python que imprima "Hello, World!"

Claude Code puede crear y modificar archivos directamente. Antes de hacerlo, siempre explica qué cambios va a realizar y solicita tu aprobación.

Salir

Hay dos formas de salir de Claude Code:

# Método 1: salir con un comando
/exit

# Método 2: salir con un atajo de teclado
Ctrl + C

4. Comandos principales

Estos son los comandos principales disponibles en el Claude Code CLI. Se introducen en la conversación de Claude Code comenzando con /.

Comando Descripción Ejemplo
claude Iniciar Claude Code claude
/help Mostrar la ayuda /help
/clear Restablecer la conversación /clear
/exit Salir de Claude Code /exit
/model Cambiar el modelo en uso /model claude-sonnet-5
/cost Consultar el costo de la sesión actual /cost
/compact Comprimir el contexto (resumir la conversación) /compact

Ejemplos de uso de los comandos

/help — Ayuda

Muestra la lista de todos los comandos disponibles con breves descripciones:

/help

/clear — Restablecer la conversación

Borra toda la conversación actual y empieza una nueva. Resulta útil cuando el contexto se alarga y la calidad de las respuestas empeora:

/clear

/model — Cambiar de modelo

Cambia el modelo de Claude usado en la sesión actual. La lista de modelos disponibles depende de tu nivel de suscripción de Claude:

# Cambiar al modelo Sonnet (rápido y eficiente en costo)
/model claude-sonnet-5

# Cambiar al modelo Opus (el más potente, mayor costo)
/model claude-opus-5

/cost — Consultar costo

Muestra el número de tokens usados y el costo estimado de la sesión actual. Útil para monitorizar el uso de la API:

/cost

/compact — Comprimir el contexto

Cuando la conversación se alarga, la ventana de contexto de Claude — su "capacidad de memoria" — se va llenando. /compact resume la conversación previa para liberar espacio:

/compact
/compact es uno de los comandos más importantes al usar Claude Code. Ejecútalo periódicamente cada vez que la conversación se alargue. De lo contrario, Claude puede olvidar partes anteriores de la conversación o degradarse la calidad de sus respuestas.

5. Modo proyecto

La verdadera fortaleza del Claude Code CLI aparece en el modo proyecto. Al ejecutar Claude Code dentro de la carpeta de un proyecto, Claude entiende su estructura de archivos y configuración, y puede realizar trabajos conscientes del contexto.

Ejecutar Claude Code en un proyecto

Paso 1: Entrar en la carpeta del proyecto

En la terminal, entra en la carpeta del proyecto sobre la que quieras trabajar:

cd ~/my-project
Paso 2: Ejecutar Claude Code

Ejecuta Claude Code dentro de la carpeta del proyecto:

claude
Paso 3: Reconocimiento del contexto del proyecto

Claude Code analiza automáticamente la estructura de archivos del proyecto. Ya puedes hacerle preguntas sobre el proyecto:

Explícame la estructura de este proyecto
Paso 4: Despacho de agentes

En los proyectos que tienen un AGENTS.md, Claude Code reconoce los agentes y delega las tareas especializadas al agente adecuado (despacho):

Genera el design_spec.md de este proyecto

Claude Code despacha al agente design a través de la puerta de enlace del PM y realiza la tarea.

En modo proyecto, Claude Code lee el AGENTS.md y reconoce los agentes. El trabajo se distribuye automáticamente según las reglas de agentes, permisos y flujos de trabajo definidos en el AGENTS.md. Esta es una de las mayores razones para usar el Claude Code CLI.

Ventajas del modo proyecto

  • Comprensión del contexto de archivos — analiza automáticamente la estructura de archivos, dependencias y configuraciones del proyecto
  • Flujos de trabajo de agentes — Claude aprovecha automáticamente el sistema multiagente definido en AGENTS.md
  • Integración con scripts — puedes incluir Claude Code en pipelines de CI/CD y scripts de automatización
  • Backends de terceros — cambia a DeepSeek, GLM u otros backends de IA para reducir costos (ver Apéndice C)

6. Consejos prácticos

Aquí tienes cinco consejos prácticos para sacar aún más partido al Claude Code CLI.

Consejo 1: Empieza siempre desde la carpeta del proyecto

Antes de ejecutar Claude Code, entra en la carpeta del proyecto con el comando cd. Si lo ejecutas fuera de esa carpeta, Claude no podrá captar el contexto de los archivos:

# Buen ejemplo
cd ~/my-project
claude

# Mal ejemplo — ejecutar desde el directorio personal
claude
Consejo 2: Gestiona el contexto con /compact

Cuando la conversación se alarga, la ventana de contexto de Claude se llena. Ejecuta /compact periódicamente para resumir la conversación y liberar espacio. Es especialmente eficaz tras análisis de archivos o revisiones de código:

# Ejecutar cada 10-15 turnos de conversación
/compact
Consejo 3: Monitoriza el costo con /cost

Comprueba cuánto costo se acumula mientras usas Claude Code. Resulta especialmente útil para gestionar los límites de uso de la suscripción Claude Pro:

# Consultar el costo de la sesión
/cost
Consejo 4: Mantén el AGENTS.md actualizado

El archivo AGENTS.md del proyecto es el "manual de instrucciones" de Claude Code. En él se definen los agentes, sus permisos y los flujos de trabajo. Si el AGENTS.md está desactualizado, Claude puede invocar a los agentes equivocados:

# Verificar el AGENTS.md
claude
# "Muéstrame la lista de agentes del proyecto actual"
Consejo 5: Combina Claude Code CLI + backend de bajo costo

La mayor ventaja de la CLI es que admite backends de terceros. Conectando backends de bajo costo como DeepSeek, GLM o LiteLLM puedes usar Claude Code por menos de lo que cuesta una suscripción Claude Pro:

# Ejemplo de cambio al backend de DeepSeek
export ANTHROPIC_API_KEY="your-deepseek-key"
export ANTHROPIC_BASE_URL="https://api.deepseek.com/anthropic"
claude

Para instrucciones detalladas de configuración, consulta el Apéndice C: Integración de backends de IA de bajo costo.

Cuando empieces con la CLI, arranca con preguntas sencillas. Familiarízate con el comportamiento de Claude Code mediante peticiones simples como "muéstrame la estructura de archivos de la carpeta actual" o "encuentra los problemas de este código", y amplía poco a poco hacia tareas más complejas.
El Claude Code CLI puede resultar difícil al principio si no estás acostumbrado a la terminal. Pero basta con conocer unos pocos comandos básicos. Lo único que debes recordar es: empezar con claude, salir con /exit y mantener con /compact.
