Apéndice B

Guía de Claude Code CLI

Este apéndice cubre la CLI de Claude Code —instalación, uso básico, comandos clave y modo proyecto. Si bien este manual utiliza principalmente Claude Desktop App, la CLI ofrece capacidades de automatización más potentes.

What This Apéndice Covers
  • CLI vs Desktop App comparison
  • Claude Code CLI installation
  • Basic usage (terminal conversation)
  • Key commands
  • Project mode
  • Practical tips

CLI vs Desktop App

Anthropic proporciona dos formas de interactuar con Claude para el trabajo de desarrollo: la Claude Desktop App (una aplicación gráfica que has estado utilizando a lo largo de este manual) y la Claude Code CLI (una herramienta de línea de comandos que se ejecuta en tu terminal). Ambas se conectan al mismo modelo Claude, pero cumplen diferentes propósitos.

La Desktop App es ideal para conversaciones, lluvia de ideas y tareas interactivas. La CLI, por otro lado, está diseñada para integración directa con tu base de código —puede leer tus archivos, ejecutar comandos, editar código y ejecutar scripts— todo desde la terminal. Para flujos de trabajo multi-agente harness, la CLI es el motor que impulsa la ejecución del agente.

Claude Desktop App

  • Graphical interface (GUI)
  • Conversational chat experience
  • Artifacts for previewing code and documents
  • Best for learning, brainstorming, and exploration
  • No direct file system access
  • Easier for beginners

Claude Code CLI

  • Terminal-based interface
  • Direct file read/write and code editing
  • Runs shell commands and scripts
  • Best for automation, CI/CD, and agent workflows
  • Full access to your local project files
  • More powerful for advanced users
¿Cuál debes usar? Comienza con la Desktop App si eres nuevo en Claude —es la más accesible. Una vez que te sientas cómodo y quieras ejecutar flujos de trabajo multi-agente harness (co-consult, co-deck), la CLI se vuelve esencial. Muchos usuarios terminan usando ambas: la Desktop App para exploración y la CLI para ejecución.
La Claude Code CLI requiere una suscripción a Claude Pro o Claude Max, la misma que la Desktop App. Tu suscripción cubre ambas interfaces. Si puedes usar la Desktop App, puedes usar la CLI.

Installing Claude Code CLI

La Claude Code CLI se instala mediante npm (Node Package Manager). Antes de instalar Claude Code CLI en sí, asegúrate de tener Node.js instalado en tu sistema.

Paso 1: Install Node.js — Claude Code CLI requires Node.js version 18 or later.
Windows
winget install OpenJS.NodeJS.LTS

Or download the installer from nodejs.org.

macOS
brew install node
Linux (Ubuntu/Debian)
sudo apt update && sudo apt install -y nodejs npm
Paso 2: Verify Node.js installation — Confirm that Node.js and npm are properly installed. 
node --version
npm --version

Expected result: v20.x.x or higher for Node.js, 10.x.x or higher for npm.

Paso 3: Install Claude Code CLI — Install the Claude Code CLI globally using npm. 
npm install -g @anthropic-ai/claude-code
Paso 4: Verify the installation — Check that Claude Code CLI is available. 
claude --version

If a version number is displayed, the installation was successful.

Paso 5: Authenticate — Before using Claude Code CLI for the first time, you must authenticate with your Anthropic account. 
claude auth login

A browser window will open. Log in with the same Anthropic account you use for Claude Desktop App. Once authentication is complete, you can start using Claude Code CLI.

On Windows, if you see a "claude is not recognized" error after installation, restart your terminal. If the issue persists, verify that the npm global bin directory (usually %APPDATA%\npm) is in your system PATH environment variable.

Basic Usage

Once Claude Code CLI is installed and authenticated, you can start a conversation directly in your terminal. The basic flow is simple: navigate to your project folder, launch Claude, and start chatting.

Starting a Session

To start using Claude Code CLI, open a terminal and follow these steps:

Navigate to your project folder — Use cd to move to the directory containing your project files. 
cd ~/git/project/my-harness
Launch Claude Code — Type claude and press Enter. 
claude
Claude will load your project context and display a welcome message. You can now type your request in natural language, just like chatting with Claude Desktop App.
Interact with Claude — Type your question or instruction and press Enter. Claude can read files, edit code, run terminal commands, and explain its reasoning. When Claude needs permission to execute a command or modify a file, it will ask you first.
End the session — Type /exit or press Ctrl+C to end the Claude Code session.
When you start Claude Code CLI in a project directory, Claude automatically reads the project structure and configuration files (such as CLAUDE.md, AGENTS.md, or .claude/ directories). This context helps Claude understand your project and follow your workspace rules.

Key Commands

Claude Code CLI provides a set of slash commands that give you quick access to common actions. These commands are typed at the Claude prompt (prefixed with /).

Command Descripción Example
/help Display a list of all available commands and their descriptions /help
/exit End the current Claude Code session and return to the terminal /exit
/clear Clear the conversation history within the current session /clear
/compact Summarize the conversation so far to free up context window space /compact
/model Switch to a different Claude model (e.g., Claude Sonnet, Claude Opus) /model claude-sonnet-5
/cost Display token usage and estimated cost for the current session /cost
/config View or modify Claude Code configuration settings /config
/doctor Run diagnostics to check Claude Code health and configuration /doctor
/login Re-authenticate with your Anthropic account /login
/logout Sign out of your Anthropic account /logout

Common Usage Patterns

Beyond slash commands, the most common way to use Claude Code CLI is through natural language instructions. Here are some typical patterns:

Reading project files — Ask Claude to read and explain any file in your project. 
Read agents/pm.md and explain the PM Agent's role
Editing files — Ask Claude to make changes to your code or configuration files. 
Add a new agent entry for "translator" to the AGENTS.md roster table
Running commands — Claude can execute terminal commands on your behalf. 
Run bun scripts/audit.ts and show me the results
Claude will ask for your permission before executing any command.
Debugging — Paste error messages and ask Claude to diagnose and fix the issue. 
I get a "module not found" error when running the audit script.
  Check the dependencies and suggest a fix.
Modelo de permisos: Claude Code CLI solicita tu permiso antes de realizar acciones potencialmente destructivas como escribir archivos, ejecutar comandos de shell o hacer solicitudes de red. Puedes otorgar o denegar cada solicitud individualmente. Esto te da control total sobre lo que Claude hace en tu proyecto.

Project Mode

Cuando lanzas Claude Code CLI dentro de un directorio de proyecto, automáticamente entra en modo proyecto. Este es el concepto más importante que los usuarios de harness multi-agente deben comprender.

What is Project Mode?

En modo proyecto, Claude Code lee los archivos de configuración que definen cómo debe comportarse dentro de tu proyecto. Estos archivos actúan como "instrucciones" que Claude sigue para cada interacción en ese proyecto. Los archivos clave son:

File Purpose Read by
CLAUDE.md Main instruction file for Claude — contains project rules, coding standards, and workflow definitions Claude Code CLI
AGENTS.md Agent ecosystem registry — defines all agents, their roles, phases, and dispatch rules PM Agent (orchestrator)
agents/*.md Individual agent definition files — each agent's detailed instructions and scope Respective specialist agent
.claude/commands/*.md Custom slash commands — reusable prompt templates you can invoke Claude Code CLI
.claude/skills/*/SKILL.md Skill definitions — specialized capabilities loaded on demand Claude Code CLI

Why Project Mode Matters for Harness Users

Cuando ejecutas un harness multi-agente (como co-consult o co-deck), Claude Code CLI lee los archivos de configuración del proyecto y automáticamente:

  • Carga las definiciones de los agentes —Sabe qué agentes existen, qué hacen y cuándo despacharlos.
  • Sigue las reglas del flujo de trabajo —Respeta los portones de fase, las comprobaciones de calidad y los contratos de traspaso definidos en tu configuración.
  • Aplica los estándares de codificación —Sigue las convenciones de codificación y las reglas de organización de archivos especificadas en tu proyecto.
  • Hace cumplir los permisos —Entiende qué agentes pueden editar qué archivos, previniendo modificaciones no autorizadas.
Idea clave: El poder de Claude Code CLI proviene de la combinación de la propia CLI y los archivos de configuración del proyecto. Sin los archivos de configuración, Claude Code CLI es un asistente de codificación de propósito general. Con los archivos de configuración, se convierte en un orquestador especializado que sigue automáticamente las reglas y flujos de trabajo de tu equipo.

Launching with a Specific Prompt

Puedes pasar una instrucción inicial directamente al lanzar Claude Code CLI, lo cual es útil para la automatización y el scripting:

# Start Claude with an initial prompt
claude "Run the audit script and report any issues"

# Start Claude in non-interactive mode (for automation)
claude -p "Generate a summary of all agent definitions"
La bandera -p (imprimir) ejecuta Claude en modo no interactivo. Claude procesa la instrucción, genera su respuesta y sale. Esto es especialmente útil para scripting e integración de CI/CD.

Practical Tips

Aquí tienes cinco consejos prácticos para ayudarte a aprovechar al máximo Claude Code CLI, basados en patrones comunes de los usuarios de harness multi-agente.

Tip 1: Keep CLAUDE.md Updated — Tu archivo CLAUDE.md es el conjunto de instrucciones primario de Claude para tu proyecto. Mantenlo actualizado con tus últimos estándares de codificación, reglas de flujo de trabajo y convenciones del proyecto. Un CLAUDE.md desactualizado conduce a un comportamiento inconsistente. Cada vez que cambies tu estructura de proyecto o definiciones de agentes, revisa y actualiza CLAUDE.md en consecuencia.
Tip 2: Use /compact When Context Fills Up — Las conversaciones largas consumen la ventana de contexto. Cuando notas que Claude comienza a "olvidar" partes anteriores de la conversación o sus respuestas son menos precisas, escribe /compact. Esto resume el historial de la conversación hasta ahora, liberando espacio para nuevas interacciones sin perder el contexto esencial.
Tip 3: Grant Permissions Wisely — Claude Code CLI solicita permiso antes de ejecutar comandos y modificar archivos. Si bien es tentador aprobar siempre, tómate un momento para revisar lo que Claude está a punto de hacer, especialmente para rm, git push u otras operaciones irreversibles. Este hábito previene la pérdida accidental de datos.
Tip 4: Leverage Non-Interactive Mode for Automation — Usa claude -p "your prompt" para ejecutar Claude en modo no interactivo dentro de scripts de shell. Esto permite potentes patrones de automatización, como ejecutar comprobaciones de calidad, generar documentación o activar flujos de trabajo del agente como parte de un pipeline de CI/CD. Combina esto con tuberías y redirección de shell para integrar la salida de Claude en tu cadena de herramientas existente.
Tip 5: Use the /cost Command to Monitor Usage — Claude Code CLI rastrea el uso de tokens para cada sesión. Escribe /cost en cualquier momento para ver cuántos tokens has consumido y el costo estimado. Esto te ayuda a mantenerte dentro de tus límites de suscripción y comprender qué tipos de tareas consumen más recursos. Si una sesión se está volviendo costosa, considera comenzar una sesión fresca con /clear.
Obtener ayuda: Si tienes problemas con Claude Code CLI, la documentación oficial está en docs.anthropic.com/en/docs/claude-code. También puedes escribir /help dentro de Claude Code CLI para una referencia rápida de los comandos disponibles, o ejecutar /doctor para diagnosticar problemas comunes de configuración.
