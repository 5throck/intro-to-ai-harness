Appendix C

Low-Cost AI Backend Integration

This appendix explains how to set up low-cost AI backends compatible with Claude Code — DeepSeek, GLM/ZhipuAI, and LiteLLM.

What This Appendix Covers
  • Why low-cost backends matter
  • DeepSeek backend setup
  • GLM/ZhipuAI backend setup
  • LiteLLM proxy setup
  • Backend comparison
  • Practice: switch backends

1. Why Low-Cost Backends?

Claude Code uses Anthropic's Claude models as its default backend. A Claude Pro subscription costs $20 per month and, as a flat-rate plan, allows a fixed number of questions each month. But if you run many projects or need large volumes of code generation, the cost can become a burden.

With an API-based low-cost backend you are billed only for what you use, so light usage is far cheaper than Claude Pro. In particular, the Claude Code CLI offers the flexibility to switch to another AI backend simply by changing environment variables.

Claude Pro is a 'flat-rate plan' while API backends are 'pay-as-you-go plans.' The less you use, the cheaper it gets. An easy way to grasp this is to think of a smartphone plan — it is just like the difference between a flat-rate plan with a fixed monthly data allowance and a pay-as-you-go plan where you pay only for what you consume.
You need the Claude Code CLI. The Claude Desktop App does not support custom backends (see Appendix B).

When a Low-Cost Backend Makes Sense

  • High-volume work (batch processing) — When you run dozens of agent jobs back-to-back (for example, generating multiple chapters of this handbook), pay-as-you-go billing is far cheaper than a flat-rate subscription.
  • Experimentation and prototyping — When prototyping a new harness or testing agent configurations, trial and error can consume a lot of tokens. Low-cost backends reduce the cost of experimentation.
  • Team or classroom use — When several people share one workspace, each person can use their own low-cost API key instead of splitting a single Claude Pro seat.
  • Cost control — With pay-as-you-go billing you can set strict spending limits. Even if an agent loop runs forever, you can never be charged beyond your API key balance.
Low-cost backends are not a perfect replacement for Claude. Claude (Anthropic) models tend to produce better results on complex reasoning, nuanced writing, and multi-step planning tasks. Low-cost backends are ideal for high-volume, moderate-complexity work such as code generation, summarization, and formatting.

2. DeepSeek Backend

What is DeepSeek?

DeepSeek is a Chinese low-cost, high-performance AI platform. Its latest models, such as DeepSeek-V3, show outstanding performance in code generation, mathematical reasoning, multilingual understanding, and more. Because it provides a Claude-compatible API, you can start using it in Claude Code by simply changing environment variables.

Key Features

  • Claude-compatible API — Supports the Anthropic API format as-is, integrating seamlessly with Claude Code
  • Affordable pricing — Far cheaper than Claude Pro at $20/month for modest usage
  • Ultra-low rates — Roughly $0.27 per 1M input tokens and $1.10 per 1M output tokens on DeepSeek-V3
  • Powerful code generation — Excellent programming-language understanding and code-writing ability
  • Open-source models — Open-source models such as the DeepSeek-V3/R1 family are also available

Setup

Step 1: Issue a DeepSeek API key

Visit https://platform.deepseek.com, create an account, and issue an API key. Whether free credits are offered may vary depending on platform policy.

Step 2: Set environment variables

On macOS / Linux:

export ANTHROPIC_API_KEY="your-deepseek-api-key"
export ANTHROPIC_BASE_URL="https://api.deepseek.com/anthropic"

On Windows (PowerShell):

$env:ANTHROPIC_API_KEY="your-deepseek-api-key"
$env:ANTHROPIC_BASE_URL="https://api.deepseek.com/anthropic"

Step 3: Run Claude Code

After setting the environment variables, run Claude Code as usual:

claude
You can get a DeepSeek API key for free at https://platform.deepseek.com. Free credit availability varies with platform policy, so test it yourself before deciding.
Never commit API keys to GitHub. Use a .env file or system environment variables. If an API key leaks, someone else can use your account.

3. GLM/ZhipuAI Backend

What is GLM/ZhipuAI?

ZhipuAI is a Chinese AI research company developing the GLM (General Language Model) series. GLM-4, its latest model, excels at multilingual processing, and its strong Korean handling makes it well suited to Korean projects. Like DeepSeek, it provides a Claude-compatible API. ZhipuAI also operates Z.ai, a global English-language developer platform.

Key Features

  • Claude-compatible API — Supports the Anthropic API format for direct integration with Claude Code
  • Multilingual support — Excellent processing of Asian languages such as Korean, Japanese, and Chinese
  • Optimized for Korean — Delivers high quality on Korean instructions and responses
  • Pay-as-you-go billing — Usage-based pricing keeps costs efficient
  • Free tier available — GLM-4-Flash has a free tier, and even paid usage is competitively priced at around $0.10 per 1M input tokens

Setup

Step 1: Issue a ZhipuAI API key

Visit https://z.ai/model-api (Z.ai, ZhipuAI's global English-language developer platform), create an account, and issue an API key.

Step 2: Set environment variables

On macOS / Linux:

export ANTHROPIC_AUTH_TOKEN="your-zai-api-key"
export ANTHROPIC_BASE_URL="https://api.z.ai/api/anthropic"

On Windows (PowerShell):

$env:ANTHROPIC_AUTH_TOKEN="your-zai-api-key"
$env:ANTHROPIC_BASE_URL="https://api.z.ai/api/anthropic"

Step 3: Run Claude Code

After setting the environment variables, run Claude Code. This is exactly the same as with DeepSeek:

claude
GLM's excellent Korean processing makes it a good fit for Korean projects. It is especially advantageous for work where you ask questions in Korean and get answers in Korean.
To decide between DeepSeek and GLM, refer to the Backend Comparison section. Both backends are compatible with Claude Code, but each has different strengths.

Pricing: Pay-as-you-go API and the Flat-Rate GLM Coding Plan

The GLM backend can be used in two ways. The pay-as-you-go API configured above bills by token usage and uses an API key issued at z.ai/model-api. By contrast, the GLM Coding Plan is a monthly flat-rate subscription compatible with Claude Code, Cline, and OpenCode, whose credits reset every 5 hours and weekly.

Plan 5-hour credits Weekly credits Notes
Lite 2,000 10,000 Starting at $18/month
Pro 12,000 60,000 —
Max 28,000 140,000 —

Credits are token-based with per-model multipliers applied, and reset every 5 hours and weekly. Every plan includes the GLM-5.3, GLM-5-Turbo, and GLM-4.7 models plus the Vision, Web Search, Web Reader, and Zread MCP servers. Check the subscription page for current pricing. A 50% discount applies to usage outside peak hours (Mon–Fri 14:00-18:00, UTC+8).

# macOS / Linux
export ANTHROPIC_AUTH_TOKEN="your-zai-api-key"
export ANTHROPIC_BASE_URL="https://api.z.ai/api/anthropic"

# Windows (PowerShell)
$env:ANTHROPIC_AUTH_TOKEN="your-zai-api-key"
$env:ANTHROPIC_BASE_URL="https://api.z.ai/api/anthropic"

To automate setup, you can also run npx @z_ai/coding-helper. If needed, you can pin the default model with environment variables such as ANTHROPIC_DEFAULT_SONNET_MODEL.

If you use Claude Code heavily every day, the predictable-cost GLM Coding Plan (flat rate) is the better deal. For occasional light use, the pay-as-you-go API is more economical. Note that DeepSeek offers only a pay-as-you-go API and has no flat-rate subscription.

For details, see the GLM Coding Plan subscription page, the official plan documentation, and the Claude Code integration guide.

Model Selection Guide

GLM-4-Flash

  • Lowest cost (free tier available)
  • Fast response speed
  • Suited to simple tasks: formatting, summarization, translation
  • 8K context window

GLM-4-Plus

  • Higher cost, yet still reasonably priced
  • Strong reasoning and coding ability
  • Suited to complex tasks: multi-step planning, code generation
  • 128K context window

4. LiteLLM Proxy

What is LiteLLM?

LiteLLM is an open-source proxy that lets you manage multiple AI backends through a single unified API. It consolidates the APIs of several providers (OpenAI, Anthropic, DeepSeek, ZhipuAI, etc.) into one endpoint, and also provides automatic failover.

Advantages

  • Multi-backend consolidation — Use multiple AI providers behind a single API endpoint
  • Automatic failover — Switches to another backend automatically when one stops responding
  • Per-model routing — Route each request to different backends/models
  • Load balancing — Distribute requests automatically across providers
  • Cost tracking — Records token usage and cost per request in built-in logs
  • Free and open source — LiteLLM itself is free (each backend's API costs are separate)

Installation

A Python environment is required. Install with the following command:

pip install litellm
# Or if you prefer an isolated environment
pipx install litellm

Writing the Configuration File

Create a litellm_config.yaml file in your project directory:

model_list:
  - model_name: claude-sonnet
    litellm_params:
      model: deepseek/deepseek-chat
      api_key: os.environ/DEEPSEEK_API_KEY
  - model_name: claude-opus
    litellm_params:
      model: zhipu/glm-4
      api_key: os.environ/ZHIPU_API_KEY

Starting the Proxy

litellm --config litellm_config.yaml

The proxy runs at http://localhost:4000.

Finally, set the environment variables so Claude Code uses this proxy, and run it:

export ANTHROPIC_API_KEY="any-key"
export ANTHROPIC_BASE_URL="http://localhost:4000"
claude
LiteLLM requires Python. The Claude Code CLI installation covered in Appendix B must come first. If you don't have Python, install it from python.org.
LiteLLM is useful when you want multiple backends configured side by side. For example, you can assign code generation to DeepSeek and Korean responses to GLM. It also switches automatically to another backend if one fails.

5. Backend Comparison

Let's compare the characteristics of each backend at a glance.

Aspect Claude Pro DeepSeek API GLM API LiteLLM
Cost model Monthly flat rate ($20) Pay-as-you-go Pay-as-you-go + flat-rate coding plan Free (proxy)
Korean Excellent Good Excellent Depends on backend
Code generation Excellent Excellent Good Depends on backend
Setup difficulty Easy Moderate Moderate Hard
Claude Code compatibility Native Yes Yes Yes
Rate limits Generous daily cap per plan Varies by account tier Generous free limits, expandable when paid Distributed across backends
Best for Beginners Cost-sensitive users Korean-focused work Multiple backends
Beginners should start with Claude Pro and switch to DeepSeek once cost becomes a burden. If Korean work dominates, GLM is also a great choice. If you want multiple backends at once, consider LiteLLM.

6. Practice: Switching Backends

In this exercise, we walk step by step through the whole process of switching Claude Code's backend from Claude Pro to DeepSeek. See for yourself that switching backends takes nothing more than setting environment variables.

Verify the Claude Code CLI installation

Refer to Appendix B to confirm that the Claude Code CLI is installed. Enter the following command in your terminal:

claude --version

Expected result: The Claude Code version number is printed. If you get an error, follow the installation guide in Appendix B.

Issue a DeepSeek API key

Visit https://platform.deepseek.com:

  • Create an account (email or Google sign-in)
  • Click "Create API Key" on the API Keys page
  • Store the issued key somewhere safe

Expected result: An API key starting with sk- is issued.

Set environment variables (per OS)

Enter the command for your operating system in the terminal:

macOS / Linux:

export ANTHROPIC_API_KEY="sk-your-deepseek-key"
export ANTHROPIC_BASE_URL="https://api.deepseek.com/anthropic"

Windows (PowerShell):

$env:ANTHROPIC_API_KEY="sk-your-deepseek-key"
$env:ANTHROPIC_BASE_URL="https://api.deepseek.com/anthropic"

Permanent setup (optional): If typing them every time is a hassle, add them to your shell profile:

  • macOS/Linux: add the export lines to ~/.bashrc or ~/.zshrc
  • Windows: system environment variable settings → add under user variables

Expected result: The command runs without errors.

Run Claude Code

From the terminal where the environment variables are set, run Claude Code:

claude

Expected result: Claude Code starts normally and responds through the DeepSeek backend.

Verify behavior with a test question

Enter a simple question in Claude Code to confirm that the DeepSeek backend is working properly:

Write a Python function that computes the sum of the numbers from 1 to 10

Expected result: DeepSeek responds by generating Python code. Check the response speed and quality.

(Optional) Test switching to GLM

Try switching to the GLM backend instead of DeepSeek. All you have to change is the environment variables:

# macOS / Linux
export ANTHROPIC_AUTH_TOKEN="your-zai-api-key"
export ANTHROPIC_BASE_URL="https://api.z.ai/api/anthropic"

# Windows (PowerShell)
$env:ANTHROPIC_AUTH_TOKEN="your-zai-api-key"
$env:ANTHROPIC_BASE_URL="https://api.z.ai/api/anthropic"

Expected result: The same claude command now runs the GLM backend. Compare the Korean response quality.

(Optional) Set up the LiteLLM proxy

To use multiple backends at the same time, set up the LiteLLM proxy. Referring to the LiteLLM setup instructions above:

  • Write the litellm_config.yaml file
  • Set each backend's API key as environment variables
  • Run litellm --config litellm_config.yaml
  • Change ANTHROPIC_BASE_URL to http://localhost:4000

Expected result: Claude Code uses multiple backends through the LiteLLM proxy.

After setting environment variables, you must open a new terminal for them to take effect. Existing terminals may not reflect the change. Always open a new terminal before running Claude Code.
