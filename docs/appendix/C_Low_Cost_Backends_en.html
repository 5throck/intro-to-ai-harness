Appendix C

Low-Cost AI Backend Integration

This appendix covers setting up Claude-compatible low-cost AI backends — DeepSeek, GLM/ZhipuAI, and LiteLLM proxy — so you can run multi-agent harnesses without a premium Claude Pro subscription.

What This Appendix Covers
  • Why low-cost backends matter
  • DeepSeek backend setup
  • GLM/ZhipuAI backend setup
  • LiteLLM proxy setup
  • Backend comparison
  • Practice: switch backends

1. Why Low-Cost Backends?

Think of AI API pricing like a mobile phone plan. Claude Pro is like a flat-rate unlimited plan: you pay a fixed monthly fee ($20/month) and can use it extensively. Low-cost backends are like pay-as-you-go plans: you only pay for what you actually use, often at a fraction of the per-token cost. For developers who run many automated agent tasks, the pay-as-you-go model can be significantly cheaper.

When Low-Cost Backends Make Sense

  • Batch processing — When you run dozens of agent tasks back-to-back (e.g., generating multiple chapters of a handbook), per-token pricing is far cheaper than a flat-rate subscription.
  • Experimentation — When you are prototyping a new harness or testing agent configurations, you may burn through many tokens on trial runs. Low-cost backends reduce the cost of experimentation.
  • Team or classroom use — When multiple people share a workspace, each person can use their own low-cost API key instead of sharing a single Claude Pro seat.
  • Cost control — With pay-per-use, you can set hard spending limits. A runaway agent loop will not charge you more than the balance on your API key.
Low-cost backends are not a perfect replacement for Claude. Claude (Anthropic) models tend to produce better output for complex reasoning, nuanced writing, and multi-step planning tasks. Low-cost backends are ideal for high-volume, moderate-complexity tasks such as code generation, summarization, and formatting.

2. DeepSeek Backend

DeepSeek is a Chinese AI research lab that offers high-performance language models at very competitive prices. DeepSeek-V3 and DeepSeek-R1 are widely used as drop-in replacements for Claude in many agent workflows.

Why DeepSeek?

  • Extremely low cost: approximately $0.27 per 1M input tokens and $1.10 per 1M output tokens (DeepSeek-V3).
  • Strong coding and reasoning capabilities, especially DeepSeek-R1 for chain-of-thought tasks.
  • Claude-compatible API format via the deepseek-chat model endpoint.

Setup Overview

Step-by-Step Setup

Step 1 — Create an account: Visit platform.deepseek.com, sign up with your email or phone number, and complete the registration.

Step 2 — Generate an API key: Navigate to the API Keys section in your account dashboard. Click "Create API Key", copy the key, and store it securely. You will not be able to see it again.

Step 3 — Set the environment variable:

Mac / Linux

# Add to your ~/.bashrc, ~/.zshrc, or ~/.profile
export DEEPSEEK_API_KEY="sk-your-api-key-here"

# Apply immediately
source ~/.bashrc

Windows (PowerShell)

# Set for the current session
$env:DEEPSEEK_API_KEY = "sk-your-api-key-here"

# Set permanently (recommended)
[System.Environment]::SetEnvironmentVariable("DEEPSEEK_API_KEY", "sk-your-api-key-here", "User")

Windows (Command Prompt)

# Set for the current session
set DEEPSEEK_API_KEY=sk-your-api-key-here

# Set permanently (recommended — via System Properties)
setx DEEPSEEK_API_KEY "sk-your-api-key-here"
Restart your terminal (or IDE) after setting environment variables so the new values take effect. If you are using Claude Code CLI, it reads the API key at startup.

Step 4 — Configure Claude Code to use DeepSeek: In your workspace configuration (e.g., CLAUDE.md or the equivalent settings file), point the API base URL and model to DeepSeek:

ANTHROPIC_BASE_URL=https://api.deepseek.com
ANTHROPIC_MODEL=deepseek-chat

This tells Claude Code to send requests to DeepSeek's API endpoint instead of Anthropic's. The response format is compatible, so no other changes are needed.

3. GLM/ZhipuAI Backend

ZhipuAI (formerly known as GLM) is a Chinese AI company backed by Tsinghua University. Their GLM-4 series of models offer strong performance for coding, reasoning, and — notably — Chinese language tasks.

Why GLM/ZhipuAI?

  • Competitive pricing: roughly $0.10 per 1M input tokens for GLM-4-Flash (free tier available).
  • Excellent Chinese language support — better than most Western models for Chinese text generation and comprehension.
  • GLM-4-Plus offers performance comparable to GPT-4 class models at a fraction of the cost.
  • Claude-compatible API with OpenAI-style endpoints.
GLM/ZhipuAI models are particularly well-suited for Korean and Chinese language tasks. If your harness processes content in Korean (research notes, storyline drafts, handbook chapters), GLM-4 often produces more natural and grammatically correct output than Western-centric models. Consider using GLM-4 as the default backend for Korean-language workflows.

Step-by-Step Setup

Step 1 — Create an account: Visit open.bigmodel.cn (ZhipuAI's developer platform), register, and verify your phone number.

Step 2 — Generate an API key: In the console, navigate to the API Keys section and create a new key.

Step 3 — Set the environment variable:

Mac / Linux

export ZHIPUAI_API_KEY="your-api-key-here"
source ~/.bashrc

Windows (PowerShell)

$env:ZHIPUAI_API_KEY = "your-api-key-here"

# Permanent
[System.Environment]::SetEnvironmentVariable("ZHIPUAI_API_KEY", "your-api-key-here", "User")

Windows (Command Prompt)

set ZHIPUAI_API_KEY=your-api-key-here

# Permanent
setx ZHIPUAI_API_KEY "your-api-key-here"

Step 4 — Configure the API:

ANTHROPIC_BASE_URL=https://open.bigmodel.cn/api/paas/v4
ANTHROPIC_MODEL=glm-4-flash

glm-4-flash is the most cost-effective option. Use glm-4-plus or glm-4-long for tasks that require higher reasoning quality or longer context windows.

Model Selection Guide

GLM-4-Flash

  • Lowest cost (free tier available)
  • Fast response time
  • Good for simple tasks: formatting, summarization, translation
  • 8K context window

GLM-4-Plus

  • Higher cost but still affordable
  • Strong reasoning and coding
  • Better for complex tasks: multi-step planning, code generation
  • 128K context window

4. LiteLLM Proxy

LiteLLM is an open-source Python library that acts as a unified proxy for over 100 LLM providers. Instead of configuring each backend separately, you set up LiteLLM once and it translates Claude-style API calls into the correct format for any provider you choose.

Think of LiteLLM as a universal adapter. Just as a travel adapter lets you plug any device into any country's electrical outlet, LiteLLM lets Claude Code (or any Claude-compatible client) talk to any LLM provider — DeepSeek, GLM, OpenAI, Mistral, Ollama (local), and many more.

Why Use LiteLLM?

  • Single configuration — Define all backends in one YAML file.
  • Easy switching — Change the active model by editing one line, no environment variable changes needed.
  • Load balancing — Distribute requests across multiple providers automatically.
  • Fallback support — If one provider is down, LiteLLM automatically routes to the next.
  • Cost tracking — Built-in logging of token usage and cost per request.

Installation

# Install LiteLLM via pip
pip install litellm[proxy]

# Or via uv (faster)
uv pip install litellm[proxy]

Configuration

Create a configuration file called litellm_config.yaml:

# litellm_config.yaml
model_list:
  - model_name: claude-3-5-sonnet
    litellm_params:
      model: deepseek/deepseek-chat
      api_key: ${DEEPSEEK_API_KEY}

  - model_name: claude-3-5-sonnet
    litellm_params:
      model: zhipu/glm-4-flash
      api_key: ${ZHIPUAI_API_KEY}

  - model_name: claude-3-5-sonnet
    litellm_params:
      model: openai/gpt-4o-mini
      api_key: ${OPENAI_API_KEY}
Notice that all three backends are mapped to the same model_name: claude-3-5-sonnet. This means Claude Code sends requests to claude-3-5-sonnet as usual, and LiteLLM routes them to whichever backend you have configured. You can activate or deactivate backends by commenting them out or reordering the list.

Starting the Proxy

# Start the LiteLLM proxy server
litellm --config litellm_config.yaml --port 4000

Then point Claude Code at the local proxy:

ANTHROPIC_BASE_URL=http://localhost:4000
ANTHROPIC_MODEL=claude-3-5-sonnet

All requests from Claude Code will flow through LiteLLM to your configured backend. The proxy handles authentication, format translation, and error handling transparently.

Request Flow: Claude Code → localhost:4000 (LiteLLM) → DeepSeek / GLM / OpenAI → Response flows back through the same path. Claude Code does not know the backend has changed — it sees the same API interface as always.

5. Backend Comparison

The table below compares the four main options covered in this appendix across key criteria that matter for multi-agent harness workflows.

Claude Pro (Anthropic)

  • Cost: $20/month flat rate
  • Best for: complex reasoning, nuanced writing, multi-step planning
  • Quality: highest (Anthropic's own models)
  • Languages: strong English; good Korean/Chinese
  • Setup: install Claude Desktop, sign in
  • Rate limits: generous daily cap per plan

DeepSeek

  • Cost: ~$0.27/1M input tokens
  • Best for: coding, math, batch processing
  • Quality: high for code/reasoning; moderate for creative writing
  • Languages: strong English and Chinese
  • Setup: API key + env var + base URL
  • Rate limits: depends on account tier

GLM/ZhipuAI

  • Cost: free tier available; ~$0.10/1M tokens paid
  • Best for: Chinese/Korean tasks, long-context work
  • Quality: high for Asian languages; good for code
  • Languages: excellent Chinese/Korean; good English
  • Setup: API key + env var + base URL
  • Rate limits: generous free tier; higher limits paid

LiteLLM Proxy

  • Cost: depends on backend(s) chosen
  • Best for: multi-backend management, easy switching
  • Quality: same as the configured backend
  • Languages: same as the configured backend
  • Setup: install Python package + YAML config
  • Rate limits: distributed across backends
There is no single "best" backend. The right choice depends on your task, budget, and language requirements. Many teams use Claude Pro for high-quality final output and switch to DeepSeek or GLM for bulk processing during development and testing.

6. Practice: Switch Backends

This hands-on exercise walks you through switching your Claude Code workspace from one backend to another. By the end, you will have tried at least two different backends and observed how each one handles the same agent task.

Check Your Current Backend

Open your terminal and check which environment variables are currently set. On Mac/Linux, run env | grep -i anthropic. On Windows PowerShell, run dir env:ANTHROPIC*. If no variables are set, you are using Claude Pro's default endpoint. Write down the current values (if any) so you can restore them later.

Choose a Target Backend

Pick one backend to try first. For this exercise, we recommend DeepSeek if you want to test coding tasks, or GLM if your content is primarily in Korean or Chinese. Visit the provider's website, create an account, and generate an API key.

Set the Environment Variables

Set the API key and base URL for your chosen backend. For DeepSeek on Mac/Linux:

export DEEPSEEK_API_KEY="sk-your-key"
export ANTHROPIC_BASE_URL="https://api.deepseek.com"
export ANTHROPIC_MODEL="deepseek-chat"

For GLM on Windows PowerShell:

$env:ZHIPUAI_API_KEY = "your-key"
$env:ANTHROPIC_BASE_URL = "https://open.bigmodel.cn/api/paas/v4"
$env:ANTHROPIC_MODEL = "glm-4-flash"
Run a Simple Agent Task

Open your CLI and run a straightforward task, such as "List all .md files in the workspace and summarize their purpose." Observe the response speed, quality, and any formatting differences compared to Claude Pro. Pay attention to whether code snippets, lists, and explanations are clear and accurate.

Compare the Output

Run the same task on a second backend (or on Claude Pro if you started with a low-cost backend). Place the two outputs side by side. Note the differences in: response speed (seconds), output quality (accuracy, clarity, completeness), tone (formal vs. casual), and any hallucinations or errors.

Try LiteLLM (Optional)

If you have Python installed, set up LiteLLM following the instructions in Section 4. Configure at least two backends in litellm_config.yaml, start the proxy, and point Claude Code at localhost:4000. Run the same agent task and verify that LiteLLM routes to the correct backend.

Restore Your Original Settings

When you are done experimenting, restore your original environment variables. If you were using Claude Pro, simply unset the backend variables:

# Mac / Linux
unset ANTHROPIC_BASE_URL
unset ANTHROPIC_MODEL

# Windows PowerShell
Remove-Item Env:\ANTHROPIC_BASE_URL
Remove-Item Env:\ANTHROPIC_MODEL

Claude Code will revert to using Anthropic's default endpoint on the next launch.

Recommended Strategy: Use Claude Pro as your primary backend for final-quality output (storyline writing, design decisions, quality gates). Switch to a low-cost backend (DeepSeek or GLM) for high-volume tasks during development and testing (code generation, formatting, batch processing). This hybrid approach gives you the best quality where it matters most while keeping costs under control.
