Integración de backends de IA de bajo costo

Este apéndice cubre la configuración de backends de IA compatibles con Claude y de bajo costo — DeepSeek, GLM/ZhipuAI y el proxy LiteLLM — para que puedas ejecutar harness multi-agente sin una suscripción premium de Claude Pro.

What This Apéndice Covers
  • Why low-cost backends matter
  • DeepSeek backend setup
  • GLM/ZhipuAI backend setup
  • LiteLLM proxy setup
  • Backend comparison
  • Practice: switch backends

1. Why Backends de bajo costo?

Piensa en la fijación de precios de las API de IA como un plan de teléfono móvil. Claude Pro es como un plan ilimitado a tarifa plana: pagas una tarifa mensual fija ($20/mes) y puedes usarlo extensivamente. Los backends de bajo costo son como planes de pago por uso: solo pagas por lo que realmente utilizas, a menudo una fracción del costo por token. Para los desarrolladores que ejecutan muchas tareas automatizadas de agentes, el modelo de pago por uso puede ser significativamente más barato.

When Backends de bajo costo Make Sense

  • Procesamiento por lotes — Cuando ejecutas docenas de tareas de agentes consecutivamente (por ejemplo, generar múltiples capítulos de un manual), el precio por token es mucho más barato que una suscripción a tarifa plana.
  • Experimentación — Cuando estás prototipando un nuevo harness o probando configuraciones de agentes, puedes consumir muchos tokens en pruebas. Los backends de bajo costo reducen el coste de la experimentación.
  • Uso en equipo o aula — Cuando varias personas comparten un workspace, cada persona puede usar su propia clave API de bajo costo en lugar de compartir un único asiento de Claude Pro.
  • Control de costes — Con el pago por uso, puedes establecer límites de gasto estrictos. Un bucle de agente descontrolado no te cobrará más allá del saldo de tu clave API.
Los backends de bajo costo no son un reemplazo perfecto para Claude. Los modelos de Claude (Anthropic) tienden a producir mejores resultados para tareas complejas de razonamiento, escritura matizada y planificación en múltiples pasos. Los backends de bajo costo son ideales para tareas de alto volumen y complejidad moderada, como generación de código, resumen y formato.

2. DeepSeek Backend

DeepSeek es un laboratorio de investigación de IA chino que ofrece modelos lingüísticos de alto rendimiento a precios muy competitivos. DeepSeek-V3 y DeepSeek-R1 se utilizan ampliamente como reemplazos directos de Claude en muchos flujos de trabajo de agentes.

Why DeepSeek?

  • Extremely low cost: approximately $0.27 per 1M input tokens and $1.10 per 1M output tokens (DeepSeek-V3).
  • Capacidades sólidas de codificación y razonamiento, especialmente DeepSeek-R1 para tareas de cadena de pensamiento.
  • Claude-compatible API format via the deepseek-chat model endpoint.

Setup Overview

Step-by-Step Setup

Paso 1 — Crear una cuenta: Visita platform.deepseek.com, regístrate con tu correo electrónico o número de teléfono y completa el registro.

Paso 2 — Generar una clave API: Navega a la sección de Claves API en el panel de control de tu cuenta. Haz clic en "Create API Key", copia la clave y guárdala de forma segura. No podrás verla de nuevo.

Paso 3 — Establece la variable de entorno:

Mac / Linux

# Add to your ~/.bashrc, ~/.zshrc, or ~/.profile
export ANTHROPIC_API_KEY="sk-your-api-key-here"

# Apply immediately
source ~/.bashrc

Windows (PowerShell)

# Set for the current session
$env:ANTHROPIC_API_KEY = "sk-your-api-key-here"

# Set permanently (recommended)
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_API_KEY", "sk-your-api-key-here", "User")

Windows (Command Prompt)

# Set for the current session
set ANTHROPIC_API_KEY=sk-your-api-key-here

# Set permanently (recommended — via System Properties)
setx ANTHROPIC_API_KEY "sk-your-api-key-here"
Reinicia tu terminal (o IDE) después de establecer las variables de entorno para que los nuevos valores surtan efecto. Si estás utilizando Claude Code CLI, lee la clave API al iniciar.

Paso 4 — Configurar Claude Code para usar DeepSeek: En la configuración de tu workspace (por ejemplo, CLAUDE.md o el archivo de configuración equivalente), apunta la URL base de la API y el modelo a DeepSeek:

ANTHROPIC_BASE_URL=https://api.deepseek.com/anthropic
ANTHROPIC_MODEL=deepseek-chat

Esto le indica a Claude Code que envíe solicitudes al endpoint de la API de DeepSeek en lugar del de Anthropic. El formato de respuesta es compatible, por lo que no se necesitan otros cambios.

3. GLM/ZhipuAI Backend

ZhipuAI (anteriormente conocido como GLM) es una empresa de IA china respaldada por la Universidad de Tsinghua. Su serie de modelos GLM-4 ofrece un sólido rendimiento para tareas de codificación, razonamiento y — notablemente — lenguaje chino. ZhipuAI también opera Z.ai, su plataforma global de desarrolladores en inglés para usuarios internacionales.

Why GLM/ZhipuAI?

  • Competitive pricing: roughly $0.10 per 1M input tokens for GLM-4-Flash (free tier available).
  • Excelente soporte para el idioma chino — mejor que la mayoría de los modelos occidentales para generación y comprensión de texto en chino.
  • GLM-4-Plus ofrece un rendimiento comparable a los modelos clase GPT-4 por una fracción del costo.
  • Claude-compatible API with OpenAI-style endpoints.
Los modelos GLM/ZhipuAI son particularmente adecuados para tareas en idiomas coreano y chino. Si tu harness procesa contenido en coreano (notas de investigación, borradores de la trama, capítulos del manual), GLM-4 a menudo produce un resultado más natural y gramaticalmente correcto que los modelos centrados en Occidente. Considera usar GLM-4 como backend predeterminado para flujos de trabajo en idioma coreano.

Step-by-Step Setup

Paso 1 — Crear una cuenta: Visita z.ai/model-api (Z.ai, la plataforma global de desarrolladores en inglés de ZhipuAI), regístrate y verifica tu número de teléfono.

Paso 2 — Generar una clave API: En la consola, navega a la sección de Claves API y crea una nueva clave.

Paso 3 — Establece la variable de entorno:

Mac / Linux

export ANTHROPIC_AUTH_TOKEN="your-api-key-here"
source ~/.bashrc

Windows (PowerShell)

$env:ANTHROPIC_AUTH_TOKEN = "your-api-key-here"

# Permanent
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_AUTH_TOKEN", "your-api-key-here", "User")

Windows (Command Prompt)

set ANTHROPIC_AUTH_TOKEN=your-api-key-here

# Permanent
setx ANTHROPIC_AUTH_TOKEN "your-api-key-here"

Paso 4 — Configura la API:

ANTHROPIC_BASE_URL=https://api.z.ai/api/anthropic

glm-4-flash es la opción más rentable. Utiliza glm-4-plus o glm-4-long para tareas que requieran una mayor calidad de razonamiento o ventanas de contexto más largas.

Precios: API de pago por uso frente a la suscripción GLM Coding Plan

Hay dos formas de pagar por GLM. La API de pago por uso configurada anteriormente factura por token con una clave API de z.ai/model-api. El GLM Coding Plan es una suscripción mensual para programación con IA, compatible con Claude Code, Cline y OpenCode; sus créditos se reinician cada 5 horas y semanalmente.

Plan Créditos por 5 horas Créditos semanales Notas
Lite 2,000 10,000 Suscripción desde $18/mes
Pro 12,000 60,000 —
Max 28,000 140,000 —

Los créditos se basan en tokens con multiplicadores por modelo y se reinician cada 5 horas y semanalmente. Todos los planes incluyen los modelos GLM-5.3, GLM-5-Turbo y GLM-4.7, además de los servidores MCP Vision, Web Search, Web Reader y Zread. Consulta los precios actuales en la página de suscripción — el uso fuera de las horas pico tiene un descuento del 50% (las horas pico son de lunes a viernes de 14:00 a 18:00 UTC+8).

# Mac / Linux
export ANTHROPIC_AUTH_TOKEN="your-zai-api-key"
export ANTHROPIC_BASE_URL="https://api.z.ai/api/anthropic"

# Windows PowerShell
$env:ANTHROPIC_AUTH_TOKEN="your-zai-api-key"
$env:ANTHROPIC_BASE_URL="https://api.z.ai/api/anthropic"

Para configurarlo automáticamente, ejecuta npx @z_ai/coding-helper. Opcionalmente, puedes fijar modelos concretos mediante variables como ANTHROPIC_DEFAULT_SONNET_MODEL.

Si usas Claude Code a diario o de forma intensiva, el GLM Coding Plan mantiene los costes predecibles. Para un uso ocasional o ligero, la API de pago por uso suele ser más económica. Ten en cuenta que DeepSeek solo ofrece API de pago por uso — no tiene plan de suscripción.

Consulta la página de suscripción del GLM Coding Plan, la documentación oficial del plan y la guía de integración con Claude Code para más detalles.

Model Selection Guide

GLM-4-Flash

  • Lowest cost (free tier available)
  • Fast response time
  • Good for simple tasks: formatting, summarization, translation
  • 8K context window

GLM-4-Plus

  • Higher cost but still affordable
  • Strong reasoning and coding
  • Better for complex tasks: multi-step planning, code generation
  • 128K context window

4. LiteLLM Proxy

LiteLLM es una biblioteca Python de código abierto que actúa como un proxy unificado para más de 100 proveedores de LLM. En lugar de configurar cada backend por separado, configuras LiteLLM una vez y traduce las llamadas API al estilo Claude al formato correcto para cualquier proveedor que elijas.

Piensa en LiteLLM como un adaptador universal. Así como un adaptador de viaje te permite enchufar cualquier dispositivo en el tomacorriente eléctrico de cualquier país, LiteLLM permite que Claude Code (o cualquier cliente compatible con Claude) se comunique con cualquier proveedor de LLM — DeepSeek, GLM, OpenAI, Mistral, Ollama (local) y muchos más.

Why Use LiteLLM?

  • Single configuration — Define all backends in one YAML file.
  • Easy switching — Change the active model by editing one line, no environment variable changes needed.
  • Load balancing — Distribute requests across multiple providers automatically.
  • Soporte de respaldo (fallback) — Si un proveedor está caído, LiteLLM enruta automáticamente al siguiente.
  • Cost tracking — Registro integrado del uso de tokens y el costo por solicitud.

Installation

# Install LiteLLM via pip
pip install litellm[proxy]

# Or via uv (faster)
uv pip install litellm[proxy]

Configuration

Create a configuration file called litellm_config.yaml:

# litellm_config.yaml
model_list:
  - model_name: claude-3-5-sonnet
    litellm_params:
      model: deepseek/deepseek-chat
      api_key: ${DEEPSEEK_API_KEY}

  - model_name: claude-3-5-sonnet
    litellm_params:
      model: zhipu/glm-4-flash
      api_key: ${ZHIPUAI_API_KEY}

  - model_name: claude-3-5-sonnet
    litellm_params:
      model: openai/gpt-4o-mini
      api_key: ${OPENAI_API_KEY}
Observa que los tres backends están mapeados al mismo model_name: claude-3-5-sonnet. Esto significa que Claude Code envía solicitudes a claude-3-5-sonnet como de costumbre, y LiteLLM las enruta al backend que hayas configurado. Puedes activar o desactivar backends comentándolos o reordenando la lista.

Starting the Proxy

# Start the LiteLLM proxy server
litellm --config litellm_config.yaml --port 4000

Luego apunta Claude Code al proxy local:

ANTHROPIC_BASE_URL=http://localhost:4000
ANTHROPIC_MODEL=claude-3-5-sonnet

Todas las solicitudes de Claude Code fluirán a través de LiteLLM hasta tu backend configurado. El proxy maneja la autenticación, la traducción de formato y el manejo de errores de forma transparente.

Flujo de la solicitud: Claude Code → localhost:4000 (LiteLLM) → DeepSeek / GLM / OpenAI → La respuesta fluye de regreso por la misma ruta. Claude Code no sabe que el backend ha cambiado — ve la misma interfaz API como siempre.

5. Backend Comparison

La siguiente tabla compara las cuatro opciones principales cubiertas en este apéndice según criterios clave que son importantes para los flujos de trabajo multi-agente de harness.

Claude Pro (Anthropic)

  • Cost: $20/month flat rate
  • Best for: complex reasoning, nuanced writing, multi-step planning
  • Quality: highest (Anthropic's own models)
  • Languages: strong English; good Korean/Chinese
  • Setup: install Claude Desktop, sign in
  • Rate limits: generous daily cap per plan

DeepSeek

  • Cost: ~$0.27/1M input tokens
  • Best for: coding, math, batch processing
  • Quality: high for code/reasoning; moderate for creative writing
  • Languages: strong English and Chinese
  • Setup: API key + env var + base URL
  • Rate limits: depends on account tier

GLM/ZhipuAI

  • Cost: free tier available; ~$0.10/1M tokens paid; GLM Coding Plan desde $18/mes
  • Best for: Chinese/Korean tasks, long-context work
  • Calidad: alta para idiomas asiáticos; buena para código
  • Languages: excellent Chinese/Korean; good English
  • Setup: API key + env var + base URL
  • Rate limits: generous free tier; higher limits paid

LiteLLM Proxy

  • Cost: depends on backend(s) chosen
  • Best for: multi-backend management, easy switching
  • Quality: igual que el backend configurado
  • Languages: same as the configured backend
  • Setup: install Python package + YAML config
  • Rate limits: distributed across backends
No existe un único backend "mejor". La elección correcta depende de tu tarea, presupuesto y requisitos lingüísticos. Muchos equipos utilizan Claude Pro para obtener resultados finales de alta calidad y cambian a DeepSeek o GLM para el procesamiento por lotes durante el desarrollo y las pruebas.

6. Practice: Switch Backends

Este ejercicio práctico te guiará a través del cambio de tu workspace de Claude Code de un backend a otro. Al final, habrás probado al menos dos backends diferentes y observado cómo cada uno maneja la misma tarea del agente.

Check Your Current Backend

Abre tu terminal y comprueba qué variables de entorno están configuradas actualmente. En Mac/Linux, ejecuta env | grep -i anthropic. En Windows PowerShell, ejecuta dir env:ANTHROPIC*. Si no hay variables configuradas, estás utilizando el endpoint predeterminado de Claude Pro. Anota los valores actuales (si los hay) para poder restaurarlos más tarde.

Choose a Target Backend

Elige un backend para probar primero. Para este ejercicio, recomendamos DeepSeek si quieres probar tareas de codificación, o GLM si tu contenido es principalmente en coreano o chino. Visita el sitio web del proveedor, crea una cuenta y genera una clave API.

Set the Environment Variables

Establece la clave API y la URL base para tu backend elegido. Para DeepSeek en Mac/Linux:

export ANTHROPIC_API_KEY="sk-your-key"
export ANTHROPIC_BASE_URL="https://api.deepseek.com/anthropic"
export ANTHROPIC_MODEL="deepseek-chat"

For GLM on Windows PowerShell:

$env:ANTHROPIC_AUTH_TOKEN = "your-key"
$env:ANTHROPIC_BASE_URL = "https://api.z.ai/api/anthropic"
Run a Simple Agent Task

Abre tu CLI y ejecuta una tarea sencilla, como "Lista todos los archivos .md en el workspace y resume su propósito." Observa la velocidad de respuesta, la calidad y cualquier diferencia de formato con respecto a Claude Pro. Presta atención a si los fragmentos de código, las listas y las explicaciones son claros y precisos.

Compare the Resultado

Ejecuta la misma tarea en un segundo backend (o en Claude Pro si comenzaste con un backend de bajo costo). Coloca los dos resultados uno al lado del otro. Anota las diferencias en: velocidad de respuesta (segundos), calidad de la salida (precisión, claridad, integridad), tono (formal vs. informal) y cualquier alucinación o error.

Try LiteLLM (Optional)

Si tienes Python instalado, configura LiteLLM siguiendo las instrucciones de la Sección 4. Configura al menos dos backends en litellm_config.yaml, inicia el proxy y apunta Claude Code a localhost:4000. Ejecuta la misma tarea del agente y verifica que LiteLLM enrute al backend correcto.

Restore Your Original Settings

Cuando termines la experimentación, restaura tus variables de entorno originales. Si estabas usando Claude Pro, simplemente desactiva las variables del backend:

# Mac / Linux
unset ANTHROPIC_BASE_URL
unset ANTHROPIC_MODEL

# Windows PowerShell
Remove-Item Env:\ANTHROPIC_BASE_URL
Remove-Item Env:\ANTHROPIC_MODEL

Claude Code volverá a usar el endpoint predeterminado de Anthropic en el próximo inicio.

Estrategia recomendada: Utiliza Claude Pro como tu backend principal para la salida de calidad final (escritura de la trama, decisiones de diseño, puertas de calidad). Cambia a un backend de bajo costo (DeepSeek o GLM) para tareas de alto volumen durante el desarrollo y las pruebas. Este enfoque híbrido te brinda la mejor calidad donde más importa mientras mantienes los costes bajo control.
