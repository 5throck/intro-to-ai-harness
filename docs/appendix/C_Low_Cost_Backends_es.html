Integración de backends de IA de bajo costo

Este apéndice explica cómo configurar backends de IA de bajo costo compatibles con Claude Code — DeepSeek, GLM/ZhipuAI y LiteLLM.

Qué cubre este apéndice
  • Por qué hacen falta backends de bajo costo
  • Configuración del backend de DeepSeek
  • Configuración del backend de GLM/ZhipuAI
  • Configuración del proxy de LiteLLM
  • Comparación de backends
  • Práctica: cambio de backends

1. ¿Por qué backends de bajo costo?

Claude Code usa por defecto los modelos Claude de Anthropic. La suscripción Claude Pro cuesta $20 al mes y, como plan de tarifa plana, permite un número fijo de preguntas cada mes. Pero si llevas muchos proyectos adelante o necesitas generar grandes volúmenes de código, el costo puede convertirse en una carga.

Con un backend de bajo costo basado en API se factura solo lo que usas, así que con poco uso sale mucho más barato que Claude Pro. En particular, la CLI de Claude Code ofrece la flexibilidad de cambiar a otro backend de IA con solo modificar variables de entorno.

Claude Pro es un «plan de tarifa plana» y los backends de API son «planes de pago por uso». Cuanto menos usas, menos pagas. Se entiende fácil si piensas en un plan de teléfono móvil — es como la diferencia entre un plan de tarifa plana con datos fijos cada mes y un plan de pago por uso donde pagas solo lo que consumas.
Necesitas la CLI de Claude Code. La app de escritorio de Claude (Claude Desktop App) no admite backends personalizados (consulta el Apéndice B).

Cuándo conviene un backend de bajo costo

  • Trabajo masivo (procesamiento por lotes) — Cuando ejecutas decenas de tareas de agentes una tras otra (por ejemplo, generar varios capítulos del manual), el pago por uso sale mucho más barato que una suscripción de tarifa plana.
  • Experimentación y prototipado — Al prototipar un nuevo harness o probar configuraciones de agentes, el proceso de ensayo y error puede consumir muchos tokens. Los backends de bajo costo reducen el costo de experimentar.
  • Uso en equipo o en clase — Cuando varias personas comparten un mismo espacio de trabajo, cada quien puede usar su propia clave API de bajo costo en lugar de repartirse un único asiento de Claude Pro.
  • Control de costos — Con el pago por uso puedes fijar límites de gasto estrictos. Aunque un bucle de agente quede corriendo sin fin, nunca se facturará más allá del saldo de tu clave API.
Un backend de bajo costo no es un reemplazo perfecto de Claude. Los modelos de Claude (Anthropic) tienden a dar mejores resultados en razonamiento complejo, escritura cuidada y planificación de múltiples pasos. Los backends de bajo costo son ideales para trabajo de gran volumen y complejidad media, como generación de código, resúmenes y formato.

2. Backend de DeepSeek

¿Qué es DeepSeek?

DeepSeek es una plataforma china de IA de bajo costo y alto rendimiento. Sus modelos más recientes, como DeepSeek-V3, muestran un rendimiento sobresaliente en generación de código, razonamiento matemático, comprensión multilingüe y más. Como ofrece una API compatible con Claude, puedes usarlo en Claude Code con solo cambiar variables de entorno.

Características principales

  • API compatible con Claude — Admite el formato de la API de Anthropic tal cual, integrándose sin fricciones con Claude Code
  • Precio accesible — Con poco uso, mucho más barato que Claude Pro a $20 al mes
  • Tarifas ultrabajas — En DeepSeek-V3, unos $0.27 por 1M de tokens de entrada y $1.10 por 1M de tokens de salida
  • Poderosa generación de código — Excelente comprensión de lenguajes de programación y capacidad de escritura de código
  • Modelos de código abierto — También ofrece modelos abiertos como la familia DeepSeek-V3/R1

Configuración

Paso 1: Emitir una clave API de DeepSeek

Accede a https://platform.deepseek.com, crea una cuenta y emite una clave API. La disponibilidad de crédito gratuito puede variar según la política de la plataforma.

Paso 2: Configurar las variables de entorno

En macOS / Linux:

export ANTHROPIC_API_KEY="your-deepseek-api-key"
export ANTHROPIC_BASE_URL="https://api.deepseek.com/anthropic"

En Windows (PowerShell):

$env:ANTHROPIC_API_KEY="your-deepseek-api-key"
$env:ANTHROPIC_BASE_URL="https://api.deepseek.com/anthropic"

Paso 3: Ejecutar Claude Code

Tras configurar las variables de entorno, ejecuta Claude Code como de costumbre:

claude
Puedes obtener gratis una clave API de DeepSeek en https://platform.deepseek.com. La disponibilidad de crédito gratuito depende de la política de la plataforma, así que pruébalo tú mismo antes de decidir.
Nunca subas claves API a GitHub. Usa un archivo .env o las variables de entorno del sistema. Si una clave API se filtra, otras personas podrían usar tu cuenta.

3. Backend de GLM/ZhipuAI

¿Qué es GLM/ZhipuAI?

ZhipuAI es una empresa china de investigación en IA que desarrolla la serie GLM (General Language Model). Su modelo más reciente, GLM-4, destaca en procesamiento multilingüe y su capacidad para el coreano es excelente, lo que lo hace adecuado para proyectos en coreano. Igual que DeepSeek, ofrece una API compatible con Claude. ZhipuAI también opera Z.ai, su plataforma global para desarrolladores en inglés.

Características principales

  • API compatible con Claude — Admite el formato de la API de Anthropic para integrarse directamente con Claude Code
  • Soporte multilingüe — Gran capacidad de procesamiento de lenguas asiáticas como el coreano, el japonés y el chino
  • Optimizado para el coreano — Ofrece alta calidad en instrucciones y respuestas en coreano
  • Facturación por uso — Costos eficientes calculados según el consumo
  • Nivel gratuito disponible — GLM-4-Flash tiene nivel gratuito e incluso pagando compite con un precio de unos $0.10 por 1M de tokens de entrada

Configuración

Paso 1: Emitir una clave API de ZhipuAI

Accede a https://z.ai/model-api (Z.ai, la plataforma global para desarrolladores en inglés de ZhipuAI), crea una cuenta y emite una clave API.

Paso 2: Configurar las variables de entorno

En macOS / Linux:

export ANTHROPIC_AUTH_TOKEN="your-zai-api-key"
export ANTHROPIC_BASE_URL="https://api.z.ai/api/anthropic"

En Windows (PowerShell):

$env:ANTHROPIC_AUTH_TOKEN="your-zai-api-key"
$env:ANTHROPIC_BASE_URL="https://api.z.ai/api/anthropic"

Paso 3: Ejecutar Claude Code

Tras configurar las variables de entorno, ejecuta Claude Code. Es idéntico al método de DeepSeek:

claude
La gran capacidad de GLM para el coreano lo hace ideal para proyectos en ese idioma. Resulta especialmente ventajoso cuando preguntas en coreano y recibes respuestas en coreano.
Para elegir entre DeepSeek y GLM, consulta la sección Comparación de backends. Ambos backends son compatibles con Claude Code, pero cada uno tiene fortalezas distintas.

Precios: API de pago por uso y GLM Coding Plan de tarifa plana

El backend de GLM puede usarse de dos maneras. La API de pago por uso configurada arriba factura según el consumo de tokens y usa una clave API emitida en z.ai/model-api. En cambio, el GLM Coding Plan es una suscripción mensual de tarifa plana compatible con Claude Code, Cline y OpenCode, cuyos créditos se reinician cada 5 horas y cada semana.

Plan Créditos de 5 horas Créditos semanales Notas
Lite 2,000 10,000 Desde $18 al mes
Pro 12,000 60,000 —
Max 28,000 140,000 —

Los créditos se basan en tokens, aplican multiplicadores por modelo y se reinician cada 5 horas y cada semana. Todos los planes incluyen los modelos GLM-5.3, GLM-5-Turbo y GLM-4.7 además de los servidores MCP Vision, Web Search, Web Reader y Zread. Consulta los precios vigentes en la página de suscripción. El uso fuera de las horas pico (lunes-viernes 14:00-18:00, UTC+8) recibe un descuento del 50%.

# macOS / Linux
export ANTHROPIC_AUTH_TOKEN="your-zai-api-key"
export ANTHROPIC_BASE_URL="https://api.z.ai/api/anthropic"

# Windows (PowerShell)
$env:ANTHROPIC_AUTH_TOKEN="your-zai-api-key"
$env:ANTHROPIC_BASE_URL="https://api.z.ai/api/anthropic"

Para automatizar la configuración también puedes ejecutar npx @z_ai/coding-helper. Si hace falta, puedes fijar el modelo predeterminado con variables de entorno como ANTHROPIC_DEFAULT_SONNET_MODEL.

Si usas Claude Code intensivamente todos los días, te conviene el GLM Coding Plan (tarifa plana) por su costo predecible. Para un uso ocasional y ligero, la API de pago por uso resulta más económica. Ten en cuenta que DeepSeek solo ofrece API de pago por uso y no tiene suscripción de tarifa plana.

Para más detalles consulta la página de suscripción del GLM Coding Plan, la documentación oficial del plan y la guía de integración con Claude Code.

Guía de selección de modelos

GLM-4-Flash

  • El costo más bajo (hay nivel gratuito)
  • Respuestas rápidas
  • Apto para tareas simples: formato, resúmenes, traducción
  • Ventana de contexto de 8K

GLM-4-Plus

  • Más caro, pero aún a un precio razonable
  • Potente razonamiento y capacidad de código
  • Apto para tareas complejas: planificación de varios pasos, generación de código
  • Ventana de contexto de 128K

4. Proxy de LiteLLM

¿Qué es LiteLLM?

LiteLLM es un proxy de código abierto que permite gestionar varios backends de IA con una única API unificada. Integra las API de varios proveedores (OpenAI, Anthropic, DeepSeek, ZhipuAI, etc.) en un solo endpoint y además ofrece conmutación automática ante fallos (failover).

Ventajas

  • Integración de varios backends — Usa varios proveedores de IA tras un único endpoint de API
  • Failover automático — Si un backend deja de responder, cambia automáticamente a otro
  • Enrutado por modelo — Cada solicitud puede dirigirse a distintos backends/modelos
  • Balanceo de carga — Reparte las solicitudes automáticamente entre proveedores
  • Seguimiento de costos — Registra en bitácoras integradas el consumo de tokens y el costo por solicitud
  • Gratis y de código abierto — LiteLLM en sí es gratuito (los costos de API de cada backend van aparte)

Instalación

Se necesita un entorno de Python. Instala con el siguiente comando:

pip install litellm
# O si prefieres un entorno aislado
pipx install litellm

Creación del archivo de configuración

Crea un archivo litellm_config.yaml en el directorio de tu proyecto:

model_list:
  - model_name: claude-sonnet
    litellm_params:
      model: deepseek/deepseek-chat
      api_key: os.environ/DEEPSEEK_API_KEY
  - model_name: claude-opus
    litellm_params:
      model: zhipu/glm-4
      api_key: os.environ/ZHIPU_API_KEY

Inicio del proxy

litellm --config litellm_config.yaml

El proxy queda corriendo en http://localhost:4000.

Por último, configura las variables de entorno para que Claude Code use este proxy y ejecútalo:

export ANTHROPIC_API_KEY="any-key"
export ANTHROPIC_BASE_URL="http://localhost:4000"
claude
LiteLLM requiere Python. Primero debe estar instalada la CLI de Claude Code del Apéndice B. Si no tienes Python, instálalo desde python.org.
LiteLLM resulta útil cuando quieres tener varios backends configurados a la vez. Por ejemplo, puedes asignar la generación de código a DeepSeek y las respuestas en coreano a GLM. Además, si un backend falla, cambia automáticamente a otro.

Comparemos de un vistazo las características de cada backend.

Coreano Excelente Bueno Excelente Depende del backend

6. Práctica: cambio de backends

En esta práctica recorremos paso a paso todo el proceso de cambiar el backend de Claude Code de Claude Pro a DeepSeek. Comprueba por ti mismo que basta con ajustar variables de entorno para cambiar de backend.

Verificar la instalación de la CLI de Claude Code

Consulta el Apéndice B para confirmar que la CLI de Claude Code está instalada. Escribe el siguiente comando en tu terminal:

claude --version

Resultado esperado: Se muestra el número de versión de Claude Code. Si aparece un error, sigue la guía de instalación del Apéndice B.

Emitir una clave API de DeepSeek

Accede a https://platform.deepseek.com:

  • Crear una cuenta (correo electrónico o inicio de sesión con Google)
  • Hacer clic en "Create API Key" en la página de API Keys
  • Guardar la clave emitida en un lugar seguro

Resultado esperado: Se emite una clave API que empieza por sk-.

Configurar las variables de entorno (según el SO)

Escribe en la terminal el comando correspondiente a tu sistema operativo:

macOS / Linux:

export ANTHROPIC_API_KEY="sk-your-deepseek-key"
export ANTHROPIC_BASE_URL="https://api.deepseek.com/anthropic"

Windows (PowerShell):

$env:ANTHROPIC_API_KEY="sk-your-deepseek-key"
$env:ANTHROPIC_BASE_URL="https://api.deepseek.com/anthropic"

Configuración permanente (opcional): Si te molesta escribirlo cada vez, añádelo a tu perfil de shell:

  • macOS/Linux: añadir las líneas export a ~/.bashrc o ~/.zshrc
  • Windows: configuración de variables de entorno del sistema → añadir en las variables de usuario

Resultado esperado: Los comandos se ejecutan sin errores.

Ejecutar Claude Code

Desde la terminal donde configuraste las variables de entorno, ejecuta Claude Code:

claude

Resultado esperado: Claude Code arranca con normalidad y responde a través del backend de DeepSeek.

Comprobar el funcionamiento con una pregunta de prueba

Escribe una pregunta sencilla en Claude Code para verificar que el backend de DeepSeek funciona correctamente:

Escribe una función en Python que calcule la suma de los números del 1 al 10

Resultado esperado: DeepSeek responde generando código Python. Comprueba la velocidad y la calidad de la respuesta.

(Opcional) Probar el cambio a GLM

Prueba a cambiar al backend de GLM en lugar de DeepSeek. Solo hay que cambiar las variables de entorno:

# macOS / Linux
export ANTHROPIC_AUTH_TOKEN="your-zai-api-key"
export ANTHROPIC_BASE_URL="https://api.z.ai/api/anthropic"

# Windows (PowerShell)
$env:ANTHROPIC_AUTH_TOKEN="your-zai-api-key"
$env:ANTHROPIC_BASE_URL="https://api.z.ai/api/anthropic"

Resultado esperado: Con el mismo comando claude se ejecuta el backend de GLM. Compara la calidad de las respuestas en coreano.

(Opcional) Configurar el proxy de LiteLLM

Para usar varios backends al mismo tiempo, configura el proxy de LiteLLM. Siguiendo el método de configuración de LiteLLM explicado antes:

  • Crear el archivo litellm_config.yaml
  • Definir como variables de entorno las claves API de cada backend
  • Ejecutar litellm --config litellm_config.yaml
  • Cambiar ANTHROPIC_BASE_URL a http://localhost:4000

Resultado esperado: Claude Code usa varios backends a través del proxy de LiteLLM.

Después de configurar las variables de entorno hay que abrir una terminal nueva para que surtan efecto. En una terminal ya abierta puede que no se reflejen. Abre siempre una terminal nueva antes de ejecutar Claude Code.
