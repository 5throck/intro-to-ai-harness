低コストAIバックエンド統合

この付録では、Claude互換の低コストAIバックエンド — DeepSeek、GLM/ZhipuAI、LiteLLMプロキシ — の設定について説明します。プレミアムなClaude Proサブスクリプションなしでマルチエージェントハーネスを実行できます。

この付録で扱う内容
  • 低コストバックエンドが重要な理由
  • DeepSeekバックエンドの設定
  • GLM/ZhipuAIバックエンドの設定
  • LiteLLMプロキシの設定
  • バックエンド比較
  • 実習: バックエンドの切り替え

1. なぜ低コストバックエンドか

AI APIの料金体系は携帯電話の料金プランに似ています。Claude Proは定額制プランのようなものです: 毎月固定料金（$20/月）を支払えば、広範に使用できます。低コストバックエンドは従量課金プランのようなものです: 実際に使った分だけ支払い、トークン単価は大幅に安くなります。多くの自動化エージェントタスクを実行する開発者にとって、従量課金モデルは大幅に安くなります。

低コストバックエンドが適している場面

  • バッチ処理 — 数十のエージェントタスクを立て続けに実行する場合（例: ハンドブックの複数章の生成）、トークン単価の pricing は定額サブスクリプションよりはるかに安価です。
  • 実験 — 新しいハーネスをプロトタイピングしたり、エージェント設定をテストしたりする場合、試行で多くのトークンを消費することがあります。低コストバックエンドは実験のコストを削減します。
  • チームや教室での利用 — 複数の人がワークスペースを共有する場合、各人が独自の低コストAPIキーを使用でき、1つのClaude Proシートを共有する必要がありません。
  • コスト管理 — 従量課金では、支出上限を厳格に設定できます。暴走したエージェントループがAPIキーの残高以上に請求することはありません。
低コストバックエンドはClaudeの完全な代替ではありません。Claude（Anthropic）モデルは、複雑な推論、ニュアンスのある文章、多段階の計画タスクでより良い出力を生む傾向があります。低コストバックエンドは、コード生成、要約、フォーマットなど、大量の適度な複雑さのタスクに最適です。

2. DeepSeekバックエンド

DeepSeekは、非常に競争力のある価格で高性能な言語モデルを提供する中国のAI研究ラボです。DeepSeek-V3とDeepSeek-R1は、多くのエージェントワークフローでClaudeの代替として広く使われています。

なぜDeepSeek？

  • 極めて低コスト: 約$0.27 / 100万入力トークン、$1.10 / 100万出力トークン（DeepSeek-V3）。
  • 強力なコーディングと推論能力。特にDeepSeek-R1はChain-of-Thoughtタスクに優れています。
  • deepseek-chatモデルエンドポイント経由でClaude互換のAPI形式。

設定の概要

ステップバイステップの設定

ステップ1 — アカウントの作成: platform.deepseek.comにアクセスし、メールまたは電話番号でサインアップして、登録を完了します。

ステップ2 — APIキーの生成: アカウントダッシュボードのAPI Keysセクションに移動します。「Create API Key」をクリックし、キーをコピーして安全に保管してください。後で再表示することはできません。

ステップ3 — 環境変数の設定:

Mac / Linux

# ~/.bashrc、~/.zshrc、または~/.profileに追加
export ANTHROPIC_API_KEY="sk-your-api-key-here"

# 即座に適用
source ~/.bashrc

Windows（PowerShell）

# 現在のセッションに設定
$env:ANTHROPIC_API_KEY = "sk-your-api-key-here"

# 恒久的に設定（推奨）
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_API_KEY", "sk-your-api-key-here", "User")

Windows（コマンドプロンプト）

# 現在のセッションに設定
set ANTHROPIC_API_KEY=sk-your-api-key-here

# 恒久的に設定（推奨 — システムのプロパティ経由）
setx ANTHROPIC_API_KEY "sk-your-api-key-here"
環境変数を設定した後は、新しい値が有効になるようにターミナル（またはIDE）を再起動してください。Claude Code CLIを使用している場合、APIキーは起動時に読み込まれます。

ステップ4 — Claude CodeにDeepSeekを使用するよう設定する: ワークスペース設定（CLAUDE.mdまたは同等の設定ファイル）で、APIのベースURLとモデルをDeepSeekに指定します:

ANTHROPIC_BASE_URL=https://api.deepseek.com/anthropic
ANTHROPIC_MODEL=deepseek-chat

これにより、Claude CodeはAnthropicのAPIエンドポイントではなくDeepSeekのAPIエンドポイントにリクエストを送信するようになります。レスポンス形式は互換性があるため、他の変更は不要です。

3. GLM/ZhipuAIバックエンド

ZhipuAI（旧称: GLM）は、清華大学の支援を受けている中国のAI企業です。GLM-4シリーズのモデルは、コーディング、推論、そして — 特筆すべきことに — 中国語タスクで優れた性能を発揮します。ZhipuAIは、海外向けのグローバル英語開発者プラットフォーム Z.ai も運営しています。

なぜGLM/ZhipuAI？

  • 競争力のある価格: GLM-4-Flashは約$0.10 / 100万入力トークン（無料ティアあり）。
  • 優れた中国語サポート — 中国語のテキスト生成と理解で、ほとんどの西洋モデルより優れています。
  • GLM-4-PlusはGPT-4クラスのモデルに匹敵する性能を低コストで提供します。
  • OpenAIスタイルのエンドポイントによるClaude互換API。
GLM/ZhipuAIモデルは韓国語と中国語のタスクに特に適しています。ハーネスが韓国語のコンテンツ（リサーチノート、ストーリーラインの草案、ハンドブックの章など）を処理する場合、GLM-4は西洋中心のモデルよりも自然で文法的に正確な出力を生成することが多いです。韓国語ワークフローのデフォルトバックエンドとしてGLM-4を使用することを検討してください。

ステップバイステップの設定

ステップ1 — アカウントの作成: z.ai/model-api（Z.ai、ZhipuAIのグローバル英語開発者プラットフォーム）にアクセスし、登録して電話番号を認証します。

ステップ2 — APIキーの生成: コンソールでAPI Keysセクションに移動し、新しいキーを作成します。

ステップ3 — 環境変数の設定:

Mac / Linux

export ANTHROPIC_AUTH_TOKEN="your-api-key-here"
source ~/.bashrc

Windows（PowerShell）

$env:ANTHROPIC_AUTH_TOKEN = "your-api-key-here"

# 恒久的に設定
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_AUTH_TOKEN", "your-api-key-here", "User")

Windows（コマンドプロンプト）

set ANTHROPIC_AUTH_TOKEN=your-api-key-here

# 恒久的に設定
setx ANTHROPIC_AUTH_TOKEN "your-api-key-here"

ステップ4 — APIの設定:

ANTHROPIC_BASE_URL=https://api.z.ai/api/anthropic

glm-4-flashは最もコスト効率の良いオプションです。より高い推論品質や長いコンテキストウィンドウが必要なタスクにはglm-4-plusまたはglm-4-longを使用してください。

料金体系: 従量制APIと定額制GLM Coding Plan

GLMの支払い方法は2つあります。上で設定した従量制APIは、z.ai/model-api で発行したAPIキーを使い、トークン使用量に応じて課金されます。一方、GLM Coding PlanはClaude Code、Cline、OpenCodeと互換性のある月額定額制サブスクリプションで、クレジットは5時間ごとと週単位でリセットされます。

プラン 5時間あたりクレジット 週間クレジット 備考
Lite 2,000 10,000 サブスクリプションは$18/月から
Pro 12,000 60,000 —
Max 28,000 140,000 —

クレジットはトークンベースでモデルごとの倍率が適用され、5時間ごとと週単位でリセットされます。すべてのプランにGLM-5.3、GLM-5-Turbo、GLM-4.7モデルと、Vision、Web Search、Web Reader、ZreadのMCPサーバーが含まれます。最新の価格は購読ページで確認してください。オフピーク時間の利用は50%割引になります（ピークは月曜〜金曜 14:00〜18:00 UTC+8）。

# Mac / Linux
export ANTHROPIC_AUTH_TOKEN="your-zai-api-key"
export ANTHROPIC_BASE_URL="https://api.z.ai/api/anthropic"

# Windows PowerShell
$env:ANTHROPIC_AUTH_TOKEN="your-zai-api-key"
$env:ANTHROPIC_BASE_URL="https://api.z.ai/api/anthropic"

自動設定には npx @z_ai/coding-helper を実行する方法もあります。必要に応じて、ANTHROPIC_DEFAULT_SONNET_MODEL などの環境変数でモデルを指定できます。

Claude Codeを毎日大量に使うなら、コストを予測しやすい定額制のGLM Coding Planが有利です。たまに軽く使うだけなら従量制APIのほうが経済的です。なお、DeepSeekは従量制APIのみの提供で、定額制サブスクリプションはありません。

詳しくは GLM Coding Planの購読ページ、公式プランドキュメント、Claude Code連携ガイドを参照してください。

モデル選択ガイド

GLM-4-Flash

  • 最安コスト（無料ティアあり）
  • 高速なレスポンス
  • シンプルなタスクに最適: フォーマット、要約、翻訳
  • 8Kコンテキストウィンドウ

GLM-4-Plus

  • やや高いが依然として手頃
  • 強力な推論とコーディング
  • 複雑なタスクに最適: 多段階の計画、コード生成
  • 128Kコンテキストウィンドウ

4. LiteLLMプロキシ

LiteLLMは、100以上のLLMプロバイダーのための統合プロキシとして機能するオープンソースのPythonライブラリです。各バックエンドを個別に設定する代わりに、LiteLLMを一度設定すれば、ClaudeスタイルのAPIコールを任意のプロバイダーに適切な形式に変換します。

LiteLLMはユニバーサルアダプタと考えてください。旅行用アダプタが任意のデバイスを任意の国の電源コンセントに接続できるように、LiteLLMはClaude Code（またはClaude互換クライアント）を任意のLLMプロバイダー — DeepSeek、GLM、OpenAI、Mistral、Ollama（ローカル）、その他多数 — に接続させます。

なぜLiteLLMを使うのか

  • 単一の設定 — すべてのバックエンドを1つのYAMLファイルで定義。
  • 簡単な切り替え — 1行編集するだけでアクティブモデルを変更。環境変数の変更は不要。
  • 負荷分散 — リクエストを複数のプロバイダーに自動的に分散。
  • フェイルバック — あるプロバイダーがダウンすると、LiteLLMは自動的に次のプロバイダーにルーティング。
  • コスト追跡 — トークン使用量とリクエストごとのコストを組み込みでロギング。

インストール

# pipでLiteLLMをインストール
pip install litellm[proxy]

# またはuvで（より高速）
uv pip install litellm[proxy]

設定

litellm_config.yamlという名前の設定ファイルを作成します:

# litellm_config.yaml
model_list:
  - model_name: claude-3-5-sonnet
    litellm_params:
      model: deepseek/deepseek-chat
      api_key: ${DEEPSEEK_API_KEY}

  - model_name: claude-3-5-sonnet
    litellm_params:
      model: zhipu/glm-4-flash
      api_key: ${ZHIPUAI_API_KEY}

  - model_name: claude-3-5-sonnet
    litellm_params:
      model: openai/gpt-4o-mini
      api_key: ${OPENAI_API_KEY}
3つのバックエンドすべてが同じmodel_name: claude-3-5-sonnetにマッピングされていることに注意してください。つまり、Claude Codeは通常通りclaude-3-5-sonnetにリクエストを送信し、LiteLLMが設定したバックエンドにルーティングします。コメントアウトやリストの並び替えでバックエンドの有効/無効を切り替えられます。

プロキシの起動

# LiteLLMプロキシサーバーを起動
litellm --config litellm_config.yaml --port 4000

その後、Claude Codeをローカルプロキシに向けるように設定します:

ANTHROPIC_BASE_URL=http://localhost:4000
ANTHROPIC_MODEL=claude-3-5-sonnet

Claude CodeからのすべてのリクエストはLiteLLMを経由して設定したバックエンドに送られます。プロキシは認証、フォーマット変換、エラー処理を透過的に行います。

リクエストフロー: Claude Code → localhost:4000（LiteLLM）→ DeepSeek / GLM / OpenAI → レスポンスが同じパスを通って戻ります。Claude Codeはバックエンドが変更されたことを知りません — 常に同じAPIインターフェースを見ています。

5. バックエンド比較

以下の表は、マルチエージェントハーネスのワークフローに関連する重要な基準で、この付録で扱った4つの主要なオプションを比較しています。

Claude Pro（Anthropic）

  • コスト: $20/月の定額
  • 最適: 複雑な推論、ニュアンスのある文章、多段階の計画
  • 品質: 最高（Anthropic独自のモデル）
  • 言語: 英語に強い；韓国語/中国語も良好
  • 設定: Claude Desktopをインストールしてサインイン
  • レート制限: プランごとの寛大な1日上限

DeepSeek

  • コスト: ~$0.27/100万入力トークン
  • 最適: コーディング、数学、バッチ処理
  • 品質: コード/推論では高い；創作では中程度
  • 言語: 英語と中国語に強い
  • 設定: APIキー + 環境変数 + ベースURL
  • レート制限: アカウントティアによる

GLM/ZhipuAI

  • コスト: 無料ティアあり; 有料は~$0.10/100万トークン; GLM Coding Planは$18/月から
  • 最適: 中国語/韓国語タスク、長文脈の作業
  • 品質: アジア言語では高い; コードも良好
  • 言語: 中国語/韓国語に最適; 英語も良好
  • 設定: APIキー + 環境変数 + ベースURL
  • レート制限: 無料ティアは寛大; 有料は上限更高

LiteLLMプロキシ

  • コスト: 選択したバックエンドによる
  • 最適: マルチバックエンド管理、簡単な切り替え
  • 品質: 設定したバックエンドと同じ
  • 言語: 設定したバックエンドと同じ
  • 設定: Pythonパッケージのインストール + YAML設定
  • レート制限: バックエンド間で分散
唯一の「最適な」バックエンドはありません。正しい選択は、タスク、予算、言語要件によって異なります。多くのチームは高品質の最終成果物にClaude Proを使用し、開発・テスト中の一括処理にはDeepSeekやGLMに切り替えています。

6. 実習: バックエンドの切り替え

この実践的な演習では、Claude Codeワークスペースをあるバックエンドから別のバックエンドに切り替える手順を体験します。最後には、少なくとも2つの異なるバックエンドを試し、それぞれが同じエージェントタスクをどのように処理するかを観察できます。

現在のバックエンドを確認する

ターミナルを開き、現在設定されている環境変数を確認します。Mac/Linuxの場合は env | grep -i anthropic、Windows PowerShellの場合は dir env:ANTHROPIC* を実行します。変数が設定されていない場合、Claude Proのデフォルトエンドポイントを使用しています。後で復元できるように、現在の値（もしあれば）をメモしてください。

ターゲットバックエンドを選ぶ

まず試すバックエンドを一つ選びます。コーディングタスクをテストしたい場合はDeepSeekを、コンテンツが主に韓国語または中国語の場合はGLMをお勧めします。プロバイダーのウェブサイトにアクセスし、アカウントを作成してAPIキーを生成します。

環境変数を設定する

選択したバックエンドのAPIキーとベースURLを設定します。Mac/LinuxのDeepSeekの場合:

export ANTHROPIC_API_KEY="sk-your-key"
export ANTHROPIC_BASE_URL="https://api.deepseek.com/anthropic"
export ANTHROPIC_MODEL="deepseek-chat"

Windows PowerShellのGLMの場合:

$env:ANTHROPIC_AUTH_TOKEN = "your-key"
$env:ANTHROPIC_BASE_URL = "https://api.z.ai/api/anthropic"
シンプルなエージェントタスクを実行する

CLIを開き、シンプルなタスクを実行します。「ワークスペース内のすべての.mdファイルをリストして、その目的を要約して」など。Claude Proと比較して、レスポンス速度、品質、フォーマットの違いを観察してください。コードスニペット、リスト、説明が明確で正確かどうかに注意してください。

出力を比較する

2番目のバックエンド（または低コストバックエンドから始めた場合はClaude Pro）で同じタスクを実行します。2つの出力を並べて配置し、以下の点での違いを確認します: レスポンス速度（秒）、出力品質（正確さ、明瞭さ、完全性）、トーン（フォーマル vs カジュアル）、ハルシネーションやエラー。

LiteLLMを試す（オプション）

Pythonがインストールされている場合、セクション4の手順に従ってLiteLLMを設定します。litellm_config.yamlに少なくとも2つのバックエンドを設定し、プロキシを起動し、Claude Codeをlocalhost:4000に向けてください。同じエージェントタスクを実行し、LiteLLMが正しいバックエンドにルーティングすることを確認します。

元の設定に戻す

実験が終わったら、元の環境変数に復元します。Claude Proを使用していた場合は、バックエンド変数をアンセットするだけです:

# Mac / Linux
unset ANTHROPIC_BASE_URL
unset ANTHROPIC_MODEL

# Windows PowerShell
Remove-Item Env:\ANTHROPIC_BASE_URL
Remove-Item Env:\ANTHROPIC_MODEL

Claude Codeは次回の起動時にAnthropicのデフォルトエンドポイントに戻ります。

推奨戦略: 最終品質の成果物（ストーリーラインの執筆、設計決定、品質ゲート）にはClaude Proをプライマリバックエンドとして使用します。開発・テスト中の大量のタスク（コード生成、フォーマット、バッチ処理）には低コストバックエンド（DeepSeekまたはGLM）に切り替えます。このハイブリッドアプローチで、最も重要な場面で最高品質を維持しながら、コストを抑えられます。
