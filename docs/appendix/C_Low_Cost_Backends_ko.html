저비용 AI 백엔드 연동

이 별첨에서는 Claude Code와 호환되는 저비용 AI 백엔드 — DeepSeek, GLM/ZhipuAI, LiteLLM —의 설정 방법을 설명합니다.

이 별첨에서 다루는 것
  • 왜 저비용 백엔드가 필요한가
  • DeepSeek 백엔드 설정
  • GLM/ZhipuAI 백엔드 설정
  • LiteLLM 프록시 설정
  • 백엔드 비교

왜 저비용 백엔드인가

Claude Code는 Anthropic의 Claude 모델을 기본으로 사용합니다. Claude Pro 구독은 월 $20이며, 정액제로 매월 일정 횟수의 질문을 할 수 있습니다. 하지만 프로젝트를 많이 진행하거나 대량의 코드 생성이 필요한 경우, 비용이 부담될 수 있습니다.

API 기반 저비용 백엔드를 사용하면 사용량만큼만 과금되므로, 적게 사용하면 Claude Pro보다 훨씬 저렴합니다. 특히 Claude Code CLI는 환경 변수만 변경하면 다른 AI 백엔드로 쉽게 전환할 수 있는 유연성을 제공합니다.

Claude Pro는 '정액제 요금제'이고, API 백엔드는 '종량제 요금제'입니다. 적게 쓰면 더 저렴합니다. 스마트폰 요금제를 생각하시면 이해하기 쉽습니다 — 매월 정해진 데이터를 쓰는 정액제와, 쓴 만큼 내는 종량제의 차이와 같습니다.
Claude Code CLI가 필요합니다. Claude Desktop App은 커스텀 백엔드를 지원하지 않습니다 (별첨 B 참조).

DeepSeek 백엔드

DeepSeek이란?

DeepSeek은 중국의 저비용 고성능 AI 플랫폼입니다. DeepSeek-V3와 같은 최신 모델은 코드 생성, 수학 추론, 다국어 이해 등 다양한 분야에서 뛰어난 성능을 보여줍니다. Claude와 호환되는 API를 제공하므로 Claude Code에서 환경 변수만 변경하면 바로 사용할 수 있습니다.

주요 특징

  • Claude 호환 API — Anthropic API 형식을 그대로 지원하므로 Claude Code와 원활하게 연동
  • 저렴한 가격 — Claude Pro 월 $20보다 적은 사용량에서 훨씬 저렴
  • 강력한 코드 생성 — 프로그래밍 언어 이해와 코드 작성 능력이 우수
  • 오픈 소스 모델 — DeepSeek-Coder 등 오픈 소스 모델도 제공

설정 방법

1단계: DeepSeek API 키 발급

https://platform.deepseek.com 에 접속하여 계정을 생성하고 API 키를 발급받습니다. 신규 가입 시 무료 크레딧이 제공될 수 있습니다.

2단계: 환경 변수 설정

macOS / Linux의 경우:

export ANTHROPIC_API_KEY="your-deepseek-api-key"
export ANTHROPIC_BASE_URL="https://api.deepseek.com/anthropic"

Windows (PowerShell)의 경우:

$env:ANTHROPIC_API_KEY="your-deepseek-api-key"
$env:ANTHROPIC_BASE_URL="https://api.deepseek.com/anthropic"

3단계: Claude Code 실행

환경 변수를 설정한 후, Claude Code를 일반적으로 실행합니다:

claude
DeepSeek API 키는 https://platform.deepseek.com 에서 무료로 발급받을 수 있습니다. 신규 가입 시 무료 크레딧이 제공되므로, 먼저 테스트해보고 결정하세요.
API 키는 절대 GitHub에 커밋하지 마세요. .env 파일이나 시스템 환경 변수를 사용하세요. API 키가 유출되면 타인이 여러분의 계정을 사용할 수 있습니다.

GLM/ZhipuAI 백엔드

GLM/ZhipuAI이란?

ZhipuAI는 중국의 AI 연구 기업으로, GLM(General Language Model) 시리즈를 개발하고 있습니다. GLM-4는 최신 모델로 다국어 처리 능력이 뛰어나며, 특히 한국어 처리 능력이 우수하여 한국어 프로젝트에 적합합니다. DeepSeek과 마찬가지로 Claude 호환 API를 제공합니다.

주요 특징

  • Claude 호환 API — Anthropic API 형식을 지원하여 Claude Code와 직접 연동
  • 다국어 지원 — 한국어, 일본어, 중국어 등 아시아 언어 처리 능력이 우수
  • 한국어 최적화 — 한국어 명령어와 응답에 높은 품질을 제공
  • 종량제 과금 — 사용량에 따른 비용 산정으로 비용 효율적

설정 방법

1단계: ZhipuAI API 키 발급

https://open.bigmodel.cn 에 접속하여 계정을 생성하고 API 키를 발급받습니다.

2단계: 환경 변수 설정

macOS / Linux의 경우:

export ANTHROPIC_API_KEY="your-zhipuai-api-key"
export ANTHROPIC_BASE_URL="https://open.bigmodel.cn/api/anthropic"

Windows (PowerShell)의 경우:

$env:ANTHROPIC_API_KEY="your-zhipuai-api-key"
$env:ANTHROPIC_BASE_URL="https://open.bigmodel.cn/api/anthropic"

3단계: Claude Code 실행

환경 변수 설정 후 Claude Code를 실행합니다. DeepSeek과 동일한 방식입니다:

claude
GLM은 한국어 처리 능력이 뛰어나 한국어 프로젝트에 적합합니다. 한국어로 질문하고 한국어로 답변받는 작업에서 특히 유리합니다.
DeepSeek와 GLM 중 어떤 것을 선택할지는 백엔드 비교 섹션을 참조하세요. 두 백엔드 모두 Claude Code와 호환되지만, 각기 다른 강점이 있습니다.

LiteLLM 프록시

LiteLLM이란?

LiteLLM은 다중 AI 백엔드를 하나의 통합 API로 관리할 수 있는 오픈 소스 프록시입니다. 여러 AI 제공자(OpenAI, Anthropic, DeepSeek, ZhipuAI 등)의 API를 하나의 엔드포인트로 통합하며, 자동 장애 조치(failover) 기능도 제공합니다.

장점

  • 다중 백엔드 통합 — 하나의 API 엔드포인트로 여러 AI 제공자 사용
  • 자동 장애 조치 — 한 백엔드가 응답하지 않으면 자동으로 다른 백엔드로 전환
  • 모델별 라우팅 — 요청마다 서로 다른 백엔드/모델로 라우팅 가능
  • 무료 오픈 소스 — LiteLLM 자체는 무료 (각 백엔드의 API 비용은 별도)

설정 방법

1단계: LiteLLM 설치

Python 환경이 필요합니다. 다음 명령어로 설치합니다:

pip install litellm
# 또는 격리된 환경을 선호하는 경우
pipx install litellm

2단계: 설정 파일 작성

프로젝트 디렉토리에 litellm_config.yaml 파일을 생성합니다:

model_list:
  - model_name: claude-sonnet
    litellm_params:
      model: deepseek/deepseek-chat
      api_key: os.environ/DEEPSEEK_API_KEY
  - model_name: claude-opus
    litellm_params:
      model: zhipu/glm-4
      api_key: os.environ/ZHIPU_API_KEY

3단계: 프록시 실행

litellm --config litellm_config.yaml

프록시가 http://localhost:4000 에서 실행됩니다.

4단계: Claude Code에서 프록시 사용

export ANTHROPIC_API_KEY="any-key"
export ANTHROPIC_BASE_URL="http://localhost:4000"
claude
LiteLLM은 Python이 필요합니다. 별첨 B의 Claude Code CLI 설치가 선행되어야 합니다. Python이 없다면 python.org 에서 설치하세요.
LiteLLM은 여러 백엔드를 동시에 설정하고 싶을 때 유용합니다. 예를 들어 코드 생성은 DeepSeek, 한국어 응답은 GLM으로 각각 할당할 수 있습니다. 또한 한 백엔드가 장애가 발생하면 자동으로 다른 백엔드로 전환됩니다.

백엔드 비교

각 백엔드의 특징을 한눈에 비교해봅시다.

항목 Claude Pro DeepSeek API GLM API LiteLLM
비용 체계 월 정액 ($20) 종량제 종량제 무료 (프록시)
한국어 우수 양호 우수 백엔드 의존
코드 생성 우수 우수 양호 백엔드 의존
설정 난이도 쉬움 보통 보통 어려움
Claude Code 호환 네이티브 네 네 네
추천 대상 초보자 비용 민감 한국어 중심 다중 백엔드
초보자는 Claude Pro로 시작하고, 비용이 부담되면 DeepSeek으로 전환하세요. 한국어 작업이 주가 된다면 GLM도 좋은 선택입니다. 여러 백엔드를 동시에 사용하고 싶다면 LiteLLM을 고려해보세요.

실습: 백엔드 전환

이 실습에서는 Claude Code의 백엔드를 Claude Pro에서 DeepSeek으로 전환하는 전체 과정을 단계별로 진행합니다. 환경 변수 설정만으로 백엔드를 전환할 수 있다는 것을 직접 확인해봅시다.

Claude Code CLI 설치 확인

별첨 B를 참조하여 Claude Code CLI가 설치되어 있는지 확인합니다. 터미널에서 다음 명령어를 입력하세요:

claude --version

예상 결과: Claude Code 버전 번호가 출력됩니다. 에러가 나면 별첨 B의 설치 가이드를 따르세요.

DeepSeek API 키 발급

https://platform.deepseek.com 에 접속합니다:

  • 계정 생성 (이메일 또는 Google 로그인)
  • API Keys 페이지에서 "Create API Key" 클릭
  • 발급된 키를 안전한 곳에 저장

예상 결과: sk-로 시작하는 API 키가 발급됩니다.

환경 변수 설정 (OS별)

운영체제에 맞는 명령어를 터미널에 입력합니다:

macOS / Linux:

export ANTHROPIC_API_KEY="sk-your-deepseek-key"
export ANTHROPIC_BASE_URL="https://api.deepseek.com/anthropic"

Windows (PowerShell):

$env:ANTHROPIC_API_KEY="sk-your-deepseek-key"
$env:ANTHROPIC_BASE_URL="https://api.deepseek.com/anthropic"

영구 설정 (선택): 매번 입력하기 번거롭다면 셸 프로필에 추가하세요:

  • macOS/Linux: ~/.bashrc 또는 ~/.zshrc에 export 줄 추가
  • Windows: 시스템 환경 변수 설정 → 사용자 변수에 추가

예상 결과: 에러 없이 명령어가 실행됩니다.

Claude Code 실행

환경 변수를 설정한 터미널에서 Claude Code를 실행합니다:

claude

예상 결과: Claude Code가 정상적으로 시작되며, DeepSeek 백엔드를 통해 응답합니다.

테스트 질문으로 동작 확인

Claude Code에 간단한 질문을 입력하여 DeepSeek 백엔드가 정상 작동하는지 확인합니다:

파이썬으로 1부터 10까지 합을 구하는 함수를 작성해줘

예상 결과: DeepSeek가 파이썬 코드를 생성하여 응답합니다. 응답 속도와 품질을 확인하세요.

(선택) GLM으로 전환 테스트

DeepSeek 대신 GLM 백엔드로 전환해보세요. 환경 변수만 변경하면 됩니다:

# macOS / Linux
export ANTHROPIC_API_KEY="your-zhipuai-key"
export ANTHROPIC_BASE_URL="https://open.bigmodel.cn/api/anthropic"

# Windows (PowerShell)
$env:ANTHROPIC_API_KEY="your-zhipuai-key"
$env:ANTHROPIC_BASE_URL="https://open.bigmodel.cn/api/anthropic"

예상 결과: 같은 claude 명령어로 GLM 백엔드가 실행됩니다. 한국어 응답 품질을 비교해보세요.

(선택) LiteLLM 프록시 설정

여러 백엔드를 동시에 사용하려면 LiteLLM 프록시를 설정하세요. 앞서 설명한 LiteLLM 설정 방법을 참조하여:

  • litellm_config.yaml 파일 작성
  • 각 백엔드의 API 키를 환경 변수로 설정
  • litellm --config litellm_config.yaml 실행
  • ANTHROPIC_BASE_URL을 http://localhost:4000로 변경

예상 결과: Claude Code가 LiteLLM 프록시를 통해 다중 백엔드를 사용합니다.

환경 변수 설정 후 새로운 터미널을 열어야 적용됩니다. 기존 터미널에서는 환경 변수가 반영되지 않을 수 있습니다. 반드시 새 터미널을 열고 Claude Code를 실행하세요.
