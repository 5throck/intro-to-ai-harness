Appendix D

Korean Open-Data API Keys (DART · LAW · KOSIS)

This appendix explains how to obtain and configure the three Korean public open-data API credentials that the k-dart, k-law, and k-kosis skills rely on — DART electronic disclosures (Financial Supervisory Service), the National Law Information Center (Ministry of Government Legislation), and the KOSIS national statistics portal (Statistics Korea).

What This Appendix Covers
  • The three public API services and their portals, at a glance
  • Getting a DART electronic-disclosure API key (issued immediately)
  • Requesting a National Law Information Center OC identifier (1–2 business days)
  • Requesting a KOSIS statistics portal API key
  • Configuring the keys in .env (Windows / macOS / Linux)
  • Verifying the setup with curl, plus troubleshooting

1. Overview

This workspace ships three skills that query Korean public data. k-dart calls the Open API of DART, the electronic disclosure system of the Financial Supervisory Service (금융감독원); k-law calls the National Law Information Center (국가법령정보센터) operated by the Ministry of Government Legislation; k-kosis calls the KOSIS national statistics portal (국가통계포털) of Statistics Korea. All three skills read their credentials from environment variables right before each request, so you must obtain and configure a key for each service before using them.

The flow is identical for all three services: the skill reads an environment variable → curl sends the request with the key attached → a JSON response comes back. Once configured, the keys are reused by every later session.

All three services are free; individual developers can use them right after completing registration. Approval times differ, though — DART issues keys immediately, the National Law Information Center takes 1–2 business days, and KOSIS has no officially documented timeline, so check the portal notices.

2. Keys at a Glance

The table below summarizes the three services. See each service's section for the detailed signup steps.

Service Provider Portal Approval Env var
DART electronic disclosure Financial Supervisory Service (FSS) opendart.fss.or.kr Immediate DART_API_KEY
National Law Information Center Ministry of Government Legislation (MOLEG) open.law.go.kr 1–2 business days LAW_API_OC
KOSIS national statistics portal Statistics Korea (KOSTAT) kosis.kr/openapi See portal notices KOSIS_API_KEY
The law portal does not issue a key string — it uses the email ID you registered with as the OC identifier. The KOSIS approval process and timeline are not officially documented; after applying, check the portal notices.

3. DART Electronic Disclosure API

DART is the Open API of the electronic disclosure system run by the Financial Supervisory Service (금융감독원). It serves everything from listed-company disclosure lists to company overviews, financial statements, and material-event reports in a machine-readable form, making it a good data source for corporate-analysis agents.

Getting a Key

  1. Create an account on the opendart.fss.or.kr signup page.
  2. After logging in, request an Open API key from the API key request menu (인증키 신청).
  3. Store the issued key — a 40-character string — somewhere safe; you can re-check it on My Page.

Keys are issued immediately; there is no approval wait.

Making Requests

  • Passing the key — every request carries the 40-character key in the crtfc_key parameter.
  • Daily limit — about 20,000 requests per day. Exceeding it returns status code 020.
  • Corp code required — most company endpoints require an 8-digit corp_code. Download corpCode.xml (the corporation code file) and look up the company by name to resolve it.

The main status codes are:

Status code Meaning
000 Success
010 Unregistered key
011 Key not usable
013 No data found
020 Daily limit exceeded
100 Invalid field value
800 System under maintenance

What You Can Query

  • Disclosure search (공시검색) — disclosure lists by date, company, and report type
  • Company overview (기업개황) — company summary, industry, capital, and other basics
  • Financial statements (재무제표) — single- and multi-company key accounts and full statements
  • Material-event reports (주요사항보고) — capital changes, bonus share issuances, and other key events
The corp_code of Samsung Electronics, 00126380, is a common verification example. Right after key issuance, query the company overview with it (see the Verification section).

4. National Law Information Center API

The National Law Information Center (국가법령정보센터) is the integrated statute portal operated by the Ministry of Government Legislation (법제처, MOLEG). Beyond the current statutes themselves, it exposes case law, administrative rules, and autonomous regulations through its Open API, making it the data source for statute-search and summarization skills.

Applying

Register at open.law.go.kr, then open the OPEN API > Application (활용신청) menu at the top and submit an application for the API you want to use. Approval usually takes 1–2 business days.

The OC Identifier

The law portal does not issue a separate key string. Instead, the full email ID you registered with (for example, myname@example.com) serves as the OC identifier. Store that email ID in LAW_API_OC and pass it with the OC= parameter on every request.

If you omit type=JSON, the API returns an HTML page instead of JSON. Always include type=JSON in every request.

What You Can Query

  • Current statutes (현행법령) — acts, enforcement decrees, and enforcement rules
  • Case law (판례) — Supreme Court and Constitutional Court decisions
  • Administrative rules and autonomous regulations (행정규칙·자치법규) — directives, ordinances, and rules
  • Statute interpretations and treaties (법령해석례·조약) — authoritative interpretation cases and international treaties

5. KOSIS Statistics Portal API

KOSIS (국가통계포털) is the national statistics portal operated by Statistics Korea (통계청, KOSTAT). It exposes official statistical tables across population, economy, and society through its Open API, serving as the data source for statistics-lookup and time-series analysis skills.

Applying

Register at kosis.kr/openapi and submit an Open API usage application through the Application (활용신청) menu.

The KOSIS approval process and timeline are not officially documented. After applying, check the portal notices and your My Page for the approval status. Calls are rejected until approval is granted.

Making Requests

  • Passing the key — store the key in KOSIS_API_KEY and pass it with the apiKey= parameter.
  • Error responses — an invalid parameter returns {"err":"21"}; no matching data returns {"err":"30"}.
  • Resolving codes — requests need table and item codes such as objL1 and itmId; walk the statistics-list endpoints step by step to resolve them.

What You Can Query

  • Integrated search (통합검색) — keyword search across statistical tables and items
  • Statistics list (통계목록) — table listings by classification
  • Statistics data (통계자료) — the actual numeric data
  • Statistics descriptions (통계설명) — definitions, units, and notes for each table

6. Environment Variable Setup

Configure the issued keys by copying the project's .env.sample to .env. The Korean keys live inside the # >>> country-scoped:KR marker block. DART_API_KEY and LAW_API_OC are already listed there; KOSIS_API_KEY is not yet in .env.sample, so add the line manually.

cp .env.sample .env

# country-scoped:KR block — fill in your three keys
DART_API_KEY=your-40-char-dart-key
LAW_API_OC=your-registered-email-id@example.com
KOSIS_API_KEY=your-kosis-key

On Windows (PowerShell), set them for the current session and, if you like, store them permanently as user variables.

$env:DART_API_KEY="your-40-char-dart-key"
$env:LAW_API_OC="your-registered-email-id@example.com"
$env:KOSIS_API_KEY="your-kosis-key"

# Permanent (user variable) — persists across new terminals
[System.Environment]::SetEnvironmentVariable("DART_API_KEY", "your-40-char-dart-key", "User")

On macOS / Linux, add export lines to your shell profile.

export DART_API_KEY="your-40-char-dart-key"
export LAW_API_OC="your-registered-email-id@example.com"
export KOSIS_API_KEY="your-kosis-key"
Never commit .env or real keys to Git. Keep .env excluded via .gitignore, and reissue any key that has been exposed.

7. Verification

A simple curl call per service confirms the keys are configured correctly. All three commands read the environment variables, so run them in the same terminal where you set them.

DART — company overview (Samsung Electronics)

# DART — company overview (Samsung Electronics)
curl -fsS --get 'https://opendart.fss.or.kr/api/company.json' \
  --data-urlencode "crtfc_key=$DART_API_KEY" \
  --data-urlencode 'corp_code=00126380'

Expected result: JSON with status "000" containing the Samsung Electronics company overview.

LAW — statute search

# LAW — statute search
curl -fsS --get 'https://www.law.go.kr/DRF/lawSearch.do' \
  --data-urlencode "OC=$LAW_API_OC" \
  --data-urlencode 'target=law' \
  --data-urlencode 'type=JSON' \
  --data-urlencode 'query=개인정보보호법' \
  --data-urlencode 'display=10'

Expected result: a LawSearch JSON response whose totalCnt is 1 or higher (matching the Personal Information Protection Act, 개인정보보호법).

KOSIS — statistics list

# KOSIS — statistics list
curl -fsS --get 'https://kosis.kr/openapi/statisticsList.do' \
  --data-urlencode "apiKey=$KOSIS_API_KEY" \
  --data-urlencode 'method=getList' \
  --data-urlencode 'vwCd=MT_ZTITLE' \
  --data-urlencode 'parentId=A' \
  --data-urlencode 'format=json'

Expected result: a JSON array of statistics-list rows.

8. Troubleshooting

The table below lists common symptoms and how to fix them.

Symptom Service Cause & fix
status 010 / 011 DART Unregistered or unusable key — double-check the key and reissue it
status 020 DART Daily request limit exceeded — retry the next day
status 013 DART No data — check the date range and corp_code
totalCnt 0 LAW No matching statute — broaden the keyword and check the target value
HTML page returned LAW Missing type=JSON — add type=JSON to the request
Calls fail before approval LAW · KOSIS Calls are rejected until the application is approved — wait for approval
{"err":"21"} KOSIS Invalid parameter — resolve codes like objL1 and itmId via the list endpoints
{"err":"30"} KOSIS No data — check the keyword and statistical-table codes
Korean keywords garbled in Git Bash KOSIS Windows Git Bash encoding issue — percent-encode Korean values and pass them literally

9. Licensing and Attribution

Data from all three services is published under the Korea Open Government License (공공누리, KOGL). When you quote or rework the data in reports or agent deliverables, you must attribute the source (for example, Source: Financial Supervisory Service DART electronic disclosures). The attribution format for each work type is documented on the KOGL website.
