Apéndice D

Claves de API de datos abiertos de Corea

Este apéndice explica cómo obtener y configurar las tres credenciales de API de datos abiertos de Corea que usan los skills k-dart, k-law y k-kosis — la divulgación electrónica DART del Servicio Financiero de Supervisión (금융감독원), el Centro Nacional de Información Legal (국가법령정보센터) y el portal de estadísticas nacionales KOSIS (KOSTAT).

Lo que cubre este apéndice
  • Panorama de los tres servicios públicos y sus portales
  • Obtención de la clave de DART (emisión inmediata)
  • Solicitud del identificador OC del portal legal (1–2 días hábiles)
  • Solicitud de la clave del portal estadístico KOSIS
  • Configuración de las claves en .env (Windows / macOS / Linux)
  • Verificación con curl y solución de problemas

1. Descripción general

Este espacio de trabajo incluye tres skills que consultan datos públicos de Corea. k-dart llama a la Open API de DART, el sistema de divulgación electrónica del Servicio Financiero de Supervisión (금융감독원, FSS); k-law llama al Centro Nacional de Información Legal (국가법령정보센터) operado por el Ministerio de Legislación Gubernamental (법제처, MOLEG); k-kosis llama al portal de estadísticas nacionales KOSIS (국가통계포털) de Statistics Korea (통계청). Los tres skills leen sus credenciales de variables de entorno justo antes de cada petición, por lo que debes obtener y configurar una clave de cada servicio antes de usarlos.

El flujo es idéntico en los tres servicios: el skill lee una variable de entorno → curl envía la petición con la clave adjunta → vuelve una respuesta JSON. Una vez configuradas, las claves se reutilizan en todas las sesiones posteriores.

Los tres servicios son gratuitos; cualquier desarrollador individual puede usarlos tras completar el registro. Los tiempos de aprobación difieren: DART emite la clave de inmediato, el Centro Nacional de Información Legal tarda 1–2 días hábiles y KOSIS no tiene un plazo documentado oficialmente, así que consulta los avisos del portal.

2. Las claves de un vistazo

La tabla siguiente resume los tres servicios. Consulta la sección de cada servicio para los pasos detallados.

El portal legal no emite una cadena de clave: usa el ID de correo electrónico con el que te registraste como identificador OC. El proceso y el plazo de aprobación de KOSIS no están documentados oficialmente; tras solicitarlo, consulta los avisos del portal.

3. API de divulgación electrónica DART

DART es la Open API del sistema de divulgación electrónica que opera el Servicio Financiero de Supervisión (금융감독원). Ofrece desde listas de divulgación de empresas cotizadas hasta perfiles corporativos, estados financieros e informes de hechos relevantes en formato legible por máquinas, lo que lo convierte en una buena fuente de datos para agentes de análisis corporativo.

Cómo obtener la clave

  1. Crea una cuenta en la página de registro de opendart.fss.or.kr.
  2. Tras iniciar sesión, solicita una clave de Open API desde el menú solicitud de clave (인증키 신청).
  3. Guarda la clave emitida — una cadena de 40 caracteres — en un lugar seguro; puedes volver a verla en Mi Página.

Las claves se emiten de inmediato; no hay espera de aprobación.

Cómo hacer peticiones

  • Envío de la clave — cada petición incluye la clave de 40 caracteres en el parámetro crtfc_key.
  • Límite diario — unas 20.000 peticiones al día. Superarlo devuelve el código de estado 020.
  • Código de empresa obligatorio — la mayoría de los endpoints por empresa exigen un corp_code de 8 dígitos. Descarga corpCode.xml (el archivo de códigos) y busca la empresa por nombre.

Los principales códigos de estado son:

Código de estado Significado
000 Éxito
010 Clave no registrada
011 Clave no utilizable
013 Sin datos
020 Límite diario superado
100 Valor de campo no válido
800 Sistema en mantenimiento

Qué puedes consultar

  • Búsqueda de divulgaciones (공시검색) — listas por fecha, empresa y tipo de informe
  • Perfil corporativo (기업개황) — resumen de la empresa, sector, capital y otros datos básicos
  • Estados financieros (재무제표) — cuentas principales y estados completos de una o varias empresas
  • Informes de hechos relevantes (주요사항보고) — ampliaciones de capital gratuitas, cambios de capital y otros eventos clave
El corp_code de Samsung Electronics, 00126380, es un ejemplo habitual de verificación. Justo después de recibir tu clave, consulta su perfil corporativo (consulta la sección de Verificación).

4. API del Centro Nacional de Información Legal

El Centro Nacional de Información Legal (국가법령정보센터) es el portal legal integrado que opera el Ministerio de Legislación Gubernamental (법제처, MOLEG). Además de las leyes vigentes, expone jurisprudencia, normas administrativas y reglamentos autonómicos mediante su Open API, por lo que es la fuente de datos de los skills de búsqueda y resumen de leyes.

Cómo solicitarla

Regístrate en open.law.go.kr, abre el menú superior OPEN API > Solicitud de uso (활용신청) y envía la solicitud de la API que quieras usar. La aprobación suele tardar 1–2 días hábiles.

El identificador OC

El portal legal no emite una cadena de clave aparte. En su lugar, el ID de correo electrónico completo con el que te registraste (por ejemplo, myname@example.com) actúa como identificador OC. Guarda ese ID en LAW_API_OC y pásalo con el parámetro OC= en cada petición.

Si omites type=JSON, la API devuelve una página HTML en lugar de JSON. Incluye siempre type=JSON en cada petición.

Qué puedes consultar

  • Leyes vigentes (현행법령) — leyes, decretos de ejecución y reglamentos
  • Jurisprudencia (판례) — decisiones del Tribunal Supremo y del Tribunal Constitucional
  • Normas administrativas y reglamentos autonómicos (행정규칙·자치법규) — directivas, ordenanzas y reglas
  • Interpretaciones legales y tratados (법령해석례·조약) — casos de interpretación con autoridad y tratados internacionales

5. API del portal estadístico KOSIS

KOSIS (국가통계포털) es el portal de estadísticas nacionales que opera Statistics Korea (통계청, KOSTAT). Expone tablas estadísticas oficiales de población, economía y sociedad mediante su Open API, y sirve como fuente de datos de los skills de consulta de estadísticas y análisis de series temporales.

Cómo solicitarla

Regístrate en kosis.kr/openapi y envía la solicitud de uso de la Open API desde el menú Solicitud de uso (활용신청).

El proceso y el plazo de aprobación de KOSIS no están documentados oficialmente. Tras solicitarlo, consulta los avisos del portal y tu Mi Página para ver el estado. Las llamadas se rechazan hasta que se conceda la aprobación.

Cómo hacer peticiones

  • Envío de la clave — guarda la clave en KOSIS_API_KEY y pásala con el parámetro apiKey=.
  • Respuestas de error — un parámetro no válido devuelve {"err":"21"}; sin datos coincidentes devuelve {"err":"30"}.
  • Resolver códigos — las peticiones necesitan códigos de tabla y de ítem como objL1 y itmId; recorre los endpoints de listado de estadísticas paso a paso para resolverlos.

Qué puedes consultar

  • Búsqueda integrada (통합검색) — búsqueda por palabras clave en tablas e ítems estadísticos
  • Lista de estadísticas (통계목록) — tablas por clasificación
  • Datos estadísticos (통계자료) — los datos numéricos reales
  • Descripciones de estadísticas (통계설명) — definiciones, unidades y notas de cada tabla

6. Configuración de variables de entorno

Configura las claves copiando el .env.sample del proyecto a .env. Las tres claves coreanas — DART_API_KEY, LAW_API_OC y KOSIS_API_KEY — ya vienen prelistadas dentro del bloque marcador # >>> country-scoped:KR; solo rellena sus valores y no añadas líneas duplicadas.

cp .env.sample .env

# bloque country-scoped:KR — rellena tus tres claves
DART_API_KEY=tu-clave-dart-de-40-caracteres
LAW_API_OC=tu-id-de-correo-registrado@example.com
KOSIS_API_KEY=tu-clave-kosis

En Windows (PowerShell), configúralas para la sesión actual y, si quieres, guárdalas de forma permanente como variables de usuario.

$env:DART_API_KEY="tu-clave-dart-de-40-caracteres"
$env:LAW_API_OC="tu-id-de-correo-registrado@example.com"
$env:KOSIS_API_KEY="tu-clave-kosis"

# Permanente (variable de usuario) — persiste en nuevas terminales
[System.Environment]::SetEnvironmentVariable("DART_API_KEY", "tu-clave-dart-de-40-caracteres", "User")

En macOS / Linux, añade líneas export a tu perfil de shell.

export DART_API_KEY="tu-clave-dart-de-40-caracteres"
export LAW_API_OC="tu-id-de-correo-registrado@example.com"
export KOSIS_API_KEY="tu-clave-kosis"
Nunca subas a Git el archivo .env ni claves reales. Mantén .env excluido con .gitignore y vuelve a emitir cualquier clave que se haya expuesto.

7. Verificación

Una llamada curl por servicio confirma que las claves están bien configuradas. Los tres comandos leen las variables de entorno, así que ejecútalos en la misma terminal donde las configuraste.

DART — perfil corporativo (Samsung Electronics)

# DART — company overview (Samsung Electronics)
curl -fsS --get 'https://opendart.fss.or.kr/api/company.json' \
  --data-urlencode "crtfc_key=$DART_API_KEY" \
  --data-urlencode 'corp_code=00126380'

Resultado esperado: JSON con status "000" que contiene el perfil corporativo de Samsung Electronics.

LAW — búsqueda de leyes

# LAW — statute search
curl -fsS --get 'https://www.law.go.kr/DRF/lawSearch.do' \
  --data-urlencode "OC=$LAW_API_OC" \
  --data-urlencode 'target=law' \
  --data-urlencode 'type=JSON' \
  --data-urlencode 'query=개인정보보호법' \
  --data-urlencode 'display=10'

Resultado esperado: una respuesta JSON LawSearch cuyo totalCnt es 1 o más (coincidencias de la Ley de Protección de Datos Personales, 개인정보보호법).

KOSIS — lista de estadísticas

# KOSIS — statistics list
curl -fsS --get 'https://kosis.kr/openapi/statisticsList.do' \
  --data-urlencode "apiKey=$KOSIS_API_KEY" \
  --data-urlencode 'method=getList' \
  --data-urlencode 'vwCd=MT_ZTITLE' \
  --data-urlencode 'parentId=A' \
  --data-urlencode 'format=json'

Resultado esperado: un array JSON con filas de la lista de estadísticas.

8. Solución de problemas

La tabla siguiente recoge los síntomas habituales y cómo corregirlos.

Síntoma Servicio Causa y solución
status 010 / 011 DART Clave no registrada o no utilizable — revisa la clave y vuelve a emitirla
status 020 DART Límite diario de peticiones superado — reintenta al día siguiente
status 013 DART Sin datos — comprueba el rango de fechas y el corp_code
totalCnt 0 LAW Ninguna ley coincide — amplía la palabra clave y revisa el valor de target
Devuelve una página HTML LAW Falta type=JSON — añade type=JSON a la petición
Fallo antes de la aprobación LAW · KOSIS Las llamadas se rechazan hasta aprobarse la solicitud — espera la aprobación
{"err":"21"} KOSIS Parámetro no válido — resuelve códigos como objL1 e itmId con los endpoints de listado
{"err":"30"} KOSIS Sin datos — revisa la palabra clave y los códigos de tabla estadística
Palabras clave coreanas corruptas en Git Bash KOSIS Problema de codificación de Git Bash en Windows — codifica los valores coreanos en formato percent y pásalos literalmente

9. Licencias y atribución

Los datos de los tres servicios se publican bajo la Licencia de Datos Abiertos del Gobierno de Corea (공공누리, KOGL). Al citar o re elaborar los datos en informes o entregables de agentes, debes atribuir la fuente (por ejemplo, Fuente: DART, divulgación electrónica del Servicio Financiero de Supervisión). El formato de atribución para cada tipo de obra está documentado en el sitio de KOGL.
