Claude Desktop App 시작하기

이 핸드북의 기본 도구인 Claude Desktop App을 설치하고 사용법을 익힙니다. Claude Desktop App은 터미널 명령어 없이, 마우스 클릭만으로 AI와 대화할 수 있는 가장 쉬운 방법입니다.

Claude Desktop App이란

Claude Desktop App은 Anthropic(앤스로픽)이 개발한 데스크톱용 AI 어시스턴트입니다. 웹 브라우저를 열 필요 없이, 컴퓨터 화면에서 바로 Claude AI와 대화할 수 있는 프로그램입니다. 마치 메신저 앱을 사용하듯 채팅창에 질문을 입력하면 Claude가 답변을 줍니다.

Claude.ai 웹 버전과의 차이

Claude는 웹 브라우저에서도 사용할 수 있습니다(claude.ai). Claude Desktop App은 웹 버전보다 몇 가지 중요한 장점이 있습니다:

  • 로컬 파일 접근 — 컴퓨터에 저장된 파일을 Claude가 직접 읽고 분석할 수 있습니다. 예를 들어 PDF 문서, 코드 파일, 텍스트 파일을 드래그 앤 드롭으로 넘기면 Claude가 내용을 이해하고 답변해 줍니다.
  • 프로젝트 기능 — 관련된 대화들을 하나의 프로젝트로 묶어 관리할 수 있습니다. 특정 주제에 맞춘 설정을 프로젝트마다 다르게 지정할 수도 있습니다.
  • 안정성과 속도 — 별도 앱으로 실행되므로 브라우저 탭 관리가 필요 없고, 인터넷 연결이 조금 불안정해도 대화 내용이 잘 유지됩니다.
  • 단축키 지원 — 키보드 단축키로 빠르게 새 대화를 시작하거나, 이전 대화를 불러올 수 있습니다.

Claude Code CLI와의 차이

Claude Code CLI는 터미널(명령어 창)에서 사용하는 Claude 도구입니다. 프로그래머가 코드를 작성하고 수정할 때 직접 파일을 조작할 수 있는 강력한 기능을 제공합니다. 하지만 명령어를 입력해야 하므로 초보자에게는 진입 장벽이 높을 수 있습니다.

Claude Code CLI는 이 핸드북의 별첨 B에서 자세히 다룹니다. CLI(Command Line Interface)란 마우스 대신 키보드 명령어로 프로그램을 조작하는 방식을 말합니다. 터미널 창(Windows의 PowerShell, MacOS의 Terminal 등)에서 claude 명령어로 실행합니다.

이 핸드북에서는 Claude Desktop App을 기본 도구로 사용합니다. 초보자도 쉽게 시작할 수 있고, Claude의 핵심 기능을 모두 경험할 수 있기 때문입니다. 고급 사용자가 되면 Claude Code CLI(별첨 B)로 넘어가면 됩니다.

MacOS 설치

MacOS에서는 두 가지 방법으로 Claude Desktop App을 설치할 수 있습니다.

방법 1: App Store에서 설치 (권장)

  1. Mac의 App Store 앱을 엽니다.
  2. 검색창에 Claude를 입력합니다.
  3. "Anthropic Claude" 앱을 찾아 다운로드 버튼을 누릅니다.
  4. 설치가 완료되면 응용 프로그램 폴더에서 Claude를 실행합니다.

방법 2: 웹사이트에서 다운로드

  1. 브라우저에서 claude.ai/download에 접속합니다.
  2. "Download for Mac" 버튼을 클릭합니다.
  3. 다운로드된 .dmg 파일을 열고, Claude 아이콘을 응용 프로그램 폴더로 드래그합니다.
  4. 처음 실행 시 "이 응용 프로그램을 열 수 없습니다" 메시지가 나오면, 시스템 환경설정 > 보안 및 개인정보에서 "열기"를 누르세요.
Windows 설치

Windows에서도 두 가지 방법으로 설치할 수 있습니다.

방법 1: 웹사이트에서 다운로드 (권장)

  1. 브라우저에서 claude.ai/download에 접속합니다.
  2. "Download for Windows" 버튼을 클릭합니다.
  3. 다운로드된 .exe 설치 파일을 실행합니다.
  4. 설치 마법사 안내에 따라 "Next"를 눌러 설치를 완료합니다.
  5. 바탕화면에 생성된 Claude 바로가기를 더블클릭하여 실행합니다.

방법 2: winget (Windows 패키지 관리자) 사용

명령어 창(PowerShell)에서 다음 명령어를 입력하면 설치할 수 있습니다:

winget install Anthropic.Claude

winget은 Windows에 내장된 패키지 관리자로, 명령어 한 줄로 프로그램을 설치/업데이트할 수 있는 도구입니다.

Linux 설치

Linux 환경에서는 패키지 형식에 따라 두 가지 설치 방법이 있습니다.

방법 1: .deb 패키지 (Debian / Ubuntu)

# 1. 다운로드 페이지에서 .deb 파일을 다운로드합니다
# claude.ai/download 에서 Claude-linux.deb 를 받습니다

# 2. 터미널에서 설치합니다
sudo dpkg -i Claude-linux.deb

# 3. 의존성 문제가 발생하면 아래 명령어로 해결합니다
sudo apt-get install -f

방법 2: .tar.gz 아카이브 (기타 Linux)

# 1. 다운로드 페이지에서 .tar.gz 파일을 받습니다
# claude.ai/download 에서 Claude-linux.tar.gz 를 받습니다

# 2. 압축을 해제합니다
tar xzf Claude-linux.tar.gz

# 3. Claude 바이너리를 실행합니다
./claude
Linux의 .tar.gz 방식은 Claude 바이너리를 원하는 위치에 수동으로 배치합니다. /opt/claude와 같은 디렉토리에 두고 PATH에 추가하면 터미널 어디서든 실행할 수 있습니다.

처음 시작하시는 분은 Claude Pro로 먼저 체험해 보세요. 사용량이 많아져 Pro로 부족하다고 느낄 때 Max로 업그레이드하면 됩니다. 구독은 언제든 변경 가능합니다.

구독 시작 방법

  1. claude.ai에 접속하여 Anthropic 계정을 만듭니다 (Google 또는 Apple 계정으로도 가입 가능).
  2. 로그인 후 화면 왼쪽 하단의 프로필 아이콘을 클릭합니다.

  4. 결제 정보를 입력하고 구독을 완료합니다.
구독 관리는 claude.ai/subscribe에서 할 수 있습니다. 플랜 변경, 결제 수단 변경, 구독 취소 모두 이 페이지에서 처리할 수 있습니다.

첫 대화 시작하기

Claude Desktop App을 설치하고 구독을 완료했다면, 이제 Claude와 대화를 시작해 보겠습니다.

Claude Desktop App 실행

데스크톱이나 응용 프로그램 폴더에서 Claude 아이콘을 클릭하여 앱을 실행합니다. 처음 실행하면 Anthropic 계정으로 로그인하라는 화면이 나옵니다. 이 핸드북의 1장에서 만든 계정(또는 새로 만든 계정)으로 로그인하세요.

화면 구성 요소

위 다이어그램에서 볼 수 있듯, Claude Desktop App의 화면은 크게 세 부분으로 나뉩니다:

  • 사이드바 (왼쪽) — 이전 대화 목록이 표시됩니다. 특정 대화를 클릭하면 해당 대화를 이어서 계속할 수 있습니다. 하단의 "+ 새 대화" 버튼으로 새로운 대화를 시작합니다.
  • 채팅 영역 (가운데) — Claude와의 대화가 표시됩니다. 내가 보낸 메시지와 Claude의 답변이 순서대로 나타납니다.
  • Artifacts 패널 (오른쪽) — Claude가 생성한 코드, 문서, 다이어그램 등을 별도로 볼 수 있는 패널입니다. (자세한 내용은 "Artifacts" 섹션 참조)

첫 메시지 보내기

채팅 영역 하단에 있는 텍스트 입력 박스에 메시지를 입력하고 Enter 키(또는 전송 버튼)를 누르면 Claude가 답변합니다. 다음 예시를 그대로 입력해 보세요:

아래 메시지를 Claude에게 보내 보세요:
안녕하세요, 저는 AI를 처음 배우는 초보자입니다. AI 에이전트 팀이 뭔지 쉽게 설명해주세요

Claude는 AI 에이전트 팀이 무엇인지 초보자도 이해할 수 있는 쉬운 언어로 설명해 줄 것입니다. 답변을 읽고, 궁금한 점이 있으면 추가 질문을 해 보세요. 예를 들어:

  • "그러면 AI 에이전트 팀은 회사의 부서와 비슷한 건가요?"
  • "초보자도 AI 에이전트 팀을 만들 수 있나요?"
  • "이 핸드북에서 뭘 배울 수 있나요?"

Claude와의 대화는 이전 대화의 맥락을 기억합니다. 따라서 follow-up 질문을 할 때 이전 내용을 반복할 필요가 없습니다. 마치 사람과 대화하듯 자연스럽게 이어가면 됩니다.

프로젝트 기능

프로젝트란?

프로젝트(Project)는 Claude Desktop App에서 관련된 대화들을 하나로 묶어 관리하는 기능입니다. 일반적인 대화는 Claude가 이전 대화 내용을 어느 정도까지만 기억하지만, 프로젝트를 사용하면 해당 프로젝트의 모든 대화가 하나의 컨텍스트(맥락)로 유지 관리됩니다.

예를 들어, "AI 학습"이라는 주제로 Claude와 대화하면서 여러 날에 걸쳐 질문하고 답변을 받을 때, 매번 새 대화를 시작하면 이전에 배운 내용을 Claude가 잊어버릴 수 있습니다. 하지만 프로젝트에 넣어두면 Claude가 해당 프로젝트의 모든 대화를 참고하여 일관된 답변을 줍니다.

프로젝트의 핵심 기능

  • 프로젝트 지식 (Project Knowledge) — 프로젝트에 관련 파일(PDF, 코드, 텍스트)을 첨부하면 Claude가 해당 파일의 내용을 기반으로 답변합니다. 예를 들어 강의 자료 PDF를 첨부하면 Claude가 그 자료를 읽고 질문에 답할 수 있습니다.
  • 사용자 지정 안내 (Custom Instructions) — 프로젝트마다 Claude에게 지시사항을 설정할 수 있습니다. 예: "항상 한국어로 대답해주세요", "초보자에게 맞춰 설명해주세요", "답변은 3문장 이내로 짧게 해주세요".
  • 대화 그룹화 — 한 프로젝트 안에서 여러 대화를 만들 수 있고, 각 대화는 프로젝트의 컨텍스트를 공유합니다.

Artifacts

Artifacts란?

Artifacts(아티팩트)는 Claude가 대화 중에 생성한 코드, 문서, 시각화 자료 등을 대화창 밖의 별도 패널에서 보여주는 기능입니다. 일반적인 대화에서 Claude가 코드를 작성하면 대화창 안에 텍스트로 표시되지만, Artifacts를 사용하면 독립된 패널에서 코드를 보고 직접 실행해 볼 수 있습니다.

예를 들어, Claude에게 "간단한 계산기 웹페이지를 만들어달라"고 요청하면 Claude가 HTML, CSS, JavaScript 코드를 작성합니다. Artifacts가 활성화되면 이 코드가:

  • 대화창 옆의 Artifacts 패널에 표시됩니다
  • 코드 미리보기를 통해 웹페이지가 실제로 어떻게 보이는지 확인할 수 있습니다
  • 코드를 복사하여 파일로 저장할 수 있습니다

Artifacts 사용해 보기

Claude에게 다음과 같이 요청해 보세요:

Artifacts 기능을 체험해 보려면 아래 메시지를 보내세요:
간단한 계산기 웹페이지를 만들어주세요. 더하기, 빼기, 곱하기, 나누기 기능이 있으면 됩니다.

Claude가 코드를 작성하면 화면 오른쪽에 Artifacts 패널이 열리고, 계산기 웹페이지의 실시간 미리보기가 표시됩니다. 미리보기 화면에서 실제로 버튼을 눌러 계산을 해 볼 수 있습니다.

Artifacts에서 할 수 있는 것

유형 설명 예시
코드 (Code) HTML, CSS, JavaScript, Python 등 프로그래밍 코드 웹페이지, 계산기, 애니메이션
문서 (Document) 구조화된 텍스트 문서 (Markdown 형식) 요약문, 분석 보고서, 체크리스트
React 컴포넌트 인터랙티브 UI 요소 (React로 작성) 차트, 퀴즈, 인터랙티브 폼
SVG 시각화 벡터 그래픽 다이어그램 흐름도, 구조도, 차트
Artifacts에서 생성된 코드는 바로 실행해 볼 수 있어 코딩을 배울 때 매우 유용합니다. Claude에게 "이 코드에서 이 부분은 뭔가요?"라고 물어보면, 코드의 각 부분이 어떤 역할을 하는지 자세히 설명해 줍니다. 코드를 수정해 달라고 요청하면 Claude가 즉시 수정하고 미리보기에 반영됩니다.

초보자 팁

Claude Desktop App을 더 효과적으로 사용하기 위한 실용적인 팁들을 소개합니다.

좋은 프롬프트 작성법

프롬프트(Prompt)란 Claude에게 보내는 메시지, 즉 질문이나 요청을 말합니다. 좋은 프롬프트를 작성하면 Claude의 답변 품질이 크게 향상됩니다.

아쉬운 프롬프트

  • "AI에 대해 알려줘"
  • "코드 짜줘"
  • "이거 어떻게 해?"

좋은 프롬프트

  • "AI 에이전트 팀이란 무엇인지, 초보자도 이해할 수 있게 3문장으로 설명해줘"
  • "Python으로 간단한 할 일 목록(to-do list) 프로그램을 작성해줘. 추가, 삭제, 목록 보기 기능이 필요해"
  • "Claude Desktop App에서 프로젝트를 만드는 방법을 단계별로 알려줘"

좋은 프롬프트의 핵심은 구체적이고 명확하게 요청하는 것입니다:

  • 배경 설명 — "저는 초보자입니다", "프로그래밍 경험이 없습니다"처럼 본인의 수준을 알려주세요
  • 명확한 목표 — 어떤 결과를 원하는지 구체적으로 말씀하세요
  • 형식 지정 — "3문장으로", "단계별로", "테이블 형식으로"처럼 원하는 답변 형태를 알려주세요
  • 예시 제공 — 원하는 결과의 예시를 보여주면 Claude가 더 정확히 이해합니다

대화를 나누어서 하기

복잡한 요청은 한 번에 모두 물어보기보다 단계별로 나누어 질문하세요. Claude와의 대화는 이전 맥락을 기억하므로, 작은 단위로 나누어도 전체 맥락이 유지됩니다.

예시: AI 에이전트 팀을 배울 때
1차: "AI 에이전트 팀이 뭔지 간단히 설명해줘"
2차: "그럼 에이전트 하나가 담당하는 역할은 어떤 것들이 있어?"
3차: "초보자도 에이전트 팀을 구성할 수 있어? 어떻게 시작하면 돼?"
4차: "Claude Desktop App으로 에이전트 팀을 구성하는 예시를 보여줘"

한국어 설정

Claude는 한국어를 포함한 다양한 언어를 지원합니다. 대화 초반에 다음과 같이 설정해 두면 Claude가 항상 한국어로 답변합니다:

대화 시작 시 아래와 같이 설정해 두세요:
앞으로 모든 대화는 한국어로 대답해주세요.

또는 프로젝트의 Custom Instructions에 "한국어로 대답해주세요"를 적어두면(앞서 "프로젝트 기능" 섹션에서 설명) 매번 말할 필요가 없습니다.

Claude Code CLI로 넘어가기

Claude Desktop App에 익숙해지고, 터미널 환경에서 더 강력한 기능이 필요해지면 Claude Code CLI를 사용해 보세요. Claude Code CLI는 Claude가 직접 파일을 생성, 수정, 실행할 수 있어 프로그래밍 작업에 훨씬 효율적입니다.

Claude Code CLI의 설치와 사용법은 이 핸드북의 별첨 B를 참조하세요. Claude Desktop App으로 기본기를 충분히 익힌 후 별첨 B를 읽어보시는 것을 권장합니다.

로컬 모델 저비용 백엔드

Claude Pro 구독 외에도, 로컬 컴퓨터에서 실행되는 AI 모델을 사용하면 인터넷 요금 없이도 AI를 활용할 수 있습니다. Ollama, LM Studio 같은 도구를 사용하면 컴퓨터에 직접 AI 모델을 설치하여 Claude처럼 대화할 수 있습니다.

로컬 모델 백엔드의 설치와 활용법은 이 핸드북의 별첨 C를 참조하세요. Claude Desktop App과 로컬 모델을 함께 사용하면 비용을 절감하면서도 강력한 AI 환경을 구축할 수 있습니다.

기타 유용한 팁

  • 대화 내보내기 — 중요한 대화는 Claude Desktop App의 메뉴에서 내보내기(Export) 기능으로 텍스트 파일로 저장할 수 있습니다. 학습 노트로 활용하세요.
  • 단축키 — Ctrl+N(Windows) 또는 Cmd+N(MacOS)로 새 대화를 시작할 수 있습니다. Ctrl+Shift+N으로 새 프로젝트를 만들 수 있습니다.
  • 답변 재생성 — Claude의 답변이 마음에 들지 않으면 답변 하단의 "Regenerate" 버튼을 눌러 다른 답변을 받을 수 있습니다.
  • 대화 분기 — 특정 답변에서 "Edit message"를 사용해 내 질문을 수정하면, Claude가 수정된 질문에 맞춰 새로운 답변 분기를 만듭니다. 이렇게 하면 하나의 대화에서 여러 방향으로 탐색할 수 있습니다.
Claude에게 "내가 방금 한 질문이나 요청이 모호했다면, 어떻게 고치면 좋을지 알려줘"라고 물어보세요. Claude가 스스로 어떤 정보가 더 필요한지, 어떻게 질문을 다듬으면 좋을지 조언해 줍니다. 이것만으로도 프롬프트 작성 실력이 크게 향상됩니다.
