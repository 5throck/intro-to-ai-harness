Chapter 2

Getting Started with Claude Desktop App

In this chapter you will install Claude Desktop App — the primary tool for this handbook — and learn how to use it. Claude Desktop App is the easiest way to converse with AI using nothing but mouse clicks, with no terminal commands required.

What This Chapter Covers
  • Features and advantages of Claude Desktop App
  • Installation methods for MacOS, Windows, and Linux
  • A guide to choosing a subscription plan
  • Hands-on with your first conversation, Projects, and Artifacts
  • Practical tips for beginners

What is Claude Desktop App

Claude Desktop App is a desktop AI assistant developed by Anthropic. It is a program that lets you talk to the Claude AI right on your computer screen, without opening a web browser. Much like using a messenger app, you type a question into the chat window and Claude gives you an answer.

Differences from the Claude.ai Web Version

Claude is also available in a web browser (claude.ai). Claude Desktop App has several important advantages over the web version:

  • Local file access — Claude can directly read and analyze files stored on your computer. For example, drag and drop a PDF document, a code file, or a text file and Claude will understand its contents and answer.
  • Projects feature — You can group related conversations together and manage them as one project. You can also configure topic-specific settings differently for each project.
  • Stability and speed — Because it runs as a standalone app, there is no browser tab management to worry about, and even a slightly unstable internet connection won't lose your conversation history.
  • Keyboard shortcuts — Keyboard shortcuts let you quickly start new conversations or bring up previous ones.

Differences from the Claude Code CLI

The Claude Code CLI is a Claude tool used in a terminal (command window). It offers powerful capabilities for programmers to manipulate files directly while writing and modifying code. However, because it requires typing commands, it can be a high barrier to entry for beginners.

Claude Code CLI is covered in detail in Appendix B of this handbook. CLI (Command Line Interface) means operating a program with keyboard commands instead of the mouse. You run it with the claude command in a terminal window (PowerShell on Windows, Terminal on MacOS, etc.).

This handbook uses Claude Desktop App as its primary tool. Beginners can get started easily, and it covers all of Claude's core features. Once you become an advanced user, you can move on to the Claude Code CLI (Appendix B).

Installation

Claude Desktop App supports all three operating systems: MacOS, Windows, and Linux. Follow the installation method that matches your computer's operating system.

System Requirements

Item Minimum Recommended
Operating system macOS 12+, Windows 10 64-bit, Ubuntu 20.04+ macOS 14+, Windows 11, Ubuntu 22.04+
RAM (memory) 4GB 8GB or more
Disk space 500MB 1GB or more
Internet Required (Claude runs in the cloud) A stable broadband connection
Using Claude Desktop App requires a Claude Pro or Max subscription. With the free plan (Free tier) you can only use the Claude.ai web version; Desktop App login is restricted. For how to subscribe, see the "Subscription Plans" section below.
Installing on MacOS

On MacOS there are two ways to install Claude Desktop App.

Method 1: Install from the App Store (Recommended)

  1. Open the App Store app on your Mac.
  2. Type Claude into the search field.
  3. Find the "Anthropic Claude" app and press the Download button.
  4. Once installation completes, launch Claude from your Applications folder.

Method 2: Download from the Website

  1. In your browser, visit claude.ai/download.
  2. Click the "Download for Mac" button.
  3. Open the downloaded .dmg file and drag the Claude icon into your Applications folder.
  4. If you see a "this application can't be opened" message the first time you run it, go to System Preferences > Security & Privacy and press "Open".
Installing on Windows

There are also two ways to install on Windows.

Method 1: Download from the Website (Recommended)

  1. In your browser, visit claude.ai/download.
  2. Click the "Download for Windows" button.
  3. Run the downloaded .exe installer.
  4. Follow the installer wizard, pressing "Next" to complete the installation.
  5. Double-click the Claude shortcut created on your desktop to launch it.

Method 2: Use winget (the Windows Package Manager)

You can install it by entering the following command in a command window (PowerShell):

winget install Anthropic.Claude

winget is the package manager built into Windows — a tool that installs and updates programs with a single command.

Installing on Linux

On Linux there are two installation methods depending on the package format.

Method 1: .deb Package (Debian / Ubuntu)

# 1. Download the .deb file from the download page
# Get Claude-linux.deb from claude.ai/download

# 2. Install it from the terminal
sudo dpkg -i Claude-linux.deb

# 3. If dependency problems occur, fix them with the command below
sudo apt-get install -f

Method 2: .tar.gz Archive (Other Linux)

# 1. Get the .tar.gz file from the download page
# Get Claude-linux.tar.gz from claude.ai/download

# 2. Extract the archive
tar xzf Claude-linux.tar.gz

# 3. Run the Claude binary
./claude
The Linux .tar.gz method places the Claude binary manually wherever you like. Put it in a directory such as /opt/claude and add it to PATH, and you can run it from anywhere in the terminal.

Which Plan Should You Choose?

To follow along with this handbook, Claude Pro ($20/month) is plenty. Claude Pro offers every core feature of Claude Desktop App and supports more than enough usage for a beginner to learn and practice with Claude.

If you're just getting started, try Claude Pro first. When your usage grows and Pro starts to feel limiting, you can upgrade to Max. Subscriptions can be changed at any time.

Getting Your Subscription Started

  2. After logging in, click the profile icon at the bottom-left of the screen.

Starting Your First Conversation

Now that Claude Desktop App is installed and your subscription is complete, let's start a conversation with Claude.

Launching Claude Desktop App

Click the Claude icon on your desktop or in your Applications folder to launch the app. The first time you run it, a screen will ask you to log in with your Anthropic account. Log in with the account you created in Chapter 1 of this handbook (or a newly created one).

Screen Components

As you can see in the diagram above, the Claude Desktop App screen is divided into three main parts:

  • Sidebar (left) — Shows your list of past conversations. Click a specific conversation to continue where it left off. Use the "+ New Chat" button at the bottom to start a new conversation.
  • Chat area (center) — Where your conversation with Claude appears. Your sent messages and Claude's replies appear in order.
  • Artifacts panel (right) — A separate panel where you can view the code, documents, diagrams, and other content Claude generates. (See the "Artifacts" section for details.)

Sending Your First Message

Type a message into the text input box at the bottom of the chat area and press the Enter key (or the send button), and Claude will answer. Try entering the following example exactly:

Send the following message to Claude:
Hello, I'm a beginner just starting to learn AI. Please explain what an AI agent team is in simple terms

Claude will explain what an AI agent team is in easy language that even a beginner can understand. Read the answer, and if anything is unclear, try asking follow-up questions. For example:

  • "So is an AI agent team similar to departments in a company?"
  • "Can a beginner build an AI agent team too?"
  • "What will I learn in this handbook?"

A conversation with Claude remembers the context of previous messages. So when you ask follow-up questions, you don't need to repeat earlier content. Just continue naturally, as if talking with a person.

Projects Feature

What Is a Project?

A project is a feature in Claude Desktop App that groups related conversations together and manages them as one. In an ordinary conversation Claude remembers previous exchanges only up to a point, but when you use a project, all conversations within that project are maintained as a single context.

For example, suppose you talk with Claude over several days about the topic of "learning AI," asking questions and receiving answers. If you start a new conversation each time, Claude may forget what you learned before. But if you keep everything inside a project, Claude refers to all the conversations in that project and gives consistent answers.

Key Project Features

  • Project Knowledge — Attach relevant files (PDF, code, text) to a project and Claude will answer based on their contents. For example, attach a lecture PDF and Claude can read it and answer questions about it.
  • Custom Instructions — You can set instructions for Claude per project. Example: "Please always answer in English", "Explain things for beginners", "Keep answers short, within 3 sentences".
  • Conversation grouping — Within one project you can create multiple conversations, and each conversation shares the project's context.

Practice: Creating an "AI Study" Project

Create the project
At the top of the sidebar in Claude Desktop App, click the icon next to the "+ New Chat" button and select "Create Project".
Set the project name
Enter "AI Study" as the project name. In the description field you can write something like "A project for learning about AI agent teams and how to use Claude".
Enter custom instructions
In the Custom Instructions area, enter the following: 
Please answer in English.
Please give easy explanations suited to beginners.
Whenever an unfamiliar term appears, be sure to explain it.
Add files to the project (optional)
If you downloaded the earlier part of this handbook (PDF, etc.), you can click the "Add files" button to add it to the project. Once added, Claude refers to the file's contents.
Start the first conversation
Start a new conversation inside the project and send the following message: 
I want to learn about Claude Desktop App and
AI agent teams in this project.
What would be the best thing to learn first?

Once you've set up a project like this, you can continue all the questions covered in later chapters inside it. Claude will provide deeper answers based on the earlier conversations.

Artifacts

What Are Artifacts?

Artifacts is a feature that displays code, documents, visualizations, and other content generated by Claude during a conversation in a separate panel outside the chat window. Normally when Claude writes code it appears as text inside the chat window, but with Artifacts you can view the code in an independent panel and even run it yourself.

For example, if you ask Claude to "make a simple calculator web page," Claude writes HTML, CSS, and JavaScript code. When Artifacts is enabled, this code:

  • Is displayed in the Artifacts panel next to the chat window
  • Lets you check what the web page actually looks like through a code preview
  • Can be copied and saved as a file

Trying Out Artifacts

Try asking Claude the following:

To experience the Artifacts feature, send the message below:
Please make a simple calculator web page. All it needs is addition, subtraction, multiplication, and division.

When Claude writes the code, the Artifacts panel opens on the right side of the screen showing a live preview of the calculator web page. In the preview you can actually press the buttons and try doing calculations.

What You Can Do with Artifacts

Type Description Examples
Code Programming code such as HTML, CSS, JavaScript, Python Web pages, calculators, animations
Document Structured text documents (Markdown format) Summaries, analysis reports, checklists
React component Interactive UI elements (written in React) Charts, quizzes, interactive forms
SVG visualization Vector graphics diagrams Flowcharts, structure diagrams, charts
Code generated in Artifacts can be run immediately, which makes it extremely useful for learning to code. Ask Claude "What does this part of the code do?" and it will explain in detail what role each part plays. Ask it to modify the code and Claude updates it instantly, reflected right in the preview.

Tips for Beginners

Here are practical tips for using Claude Desktop App more effectively.

Writing Good Prompts

A prompt is the message you send to Claude — a question or request. Writing good prompts dramatically improves the quality of Claude's answers.

Weak Prompts

  • "Tell me about AI"
  • "Write me some code"
  • "How do I do this?"

Good Prompts

  • "Explain what an AI agent team is in 3 sentences a beginner can understand"
  • "Write a simple to-do list program in Python. It needs add, delete, and view-list features"
  • "Walk me through how to create a project in Claude Desktop App, step by step"

The key to a good prompt is making your request specific and clear:

  • Give background — Tell Claude your level, e.g., "I'm a beginner" or "I have no programming experience"
  • Clear goals — State specifically what result you want
  • Specify the format — Tell Claude what shape you want the answer in, e.g., "in 3 sentences", "step by step", "as a table"
  • Provide examples — Showing an example of the result you want helps Claude understand more precisely

Breaking Conversations into Steps

For complex requests, rather than asking everything at once, split your questions into steps. Conversations with Claude remember prior context, so even small units keep the overall context intact.

Example: Learning about AI agent teams
Round 1: "Briefly explain what an AI agent team is"
Round 2: "Then what kinds of roles does each agent take on?"
Round 3: "Can a beginner put together an agent team too? How do I start?"
Round 4: "Show me an example of assembling an agent team with Claude Desktop App"

Language Settings

Claude supports many languages, including Korean. If you set things up like the following early in a conversation, Claude will always answer in Korean:

When starting a conversation, set it up like below:
From now on, please answer all conversations in Korean.

Alternatively, if you write "Please answer in Korean" in the project's Custom Instructions (explained earlier in the "Projects Feature" section), you won't need to say it every time.

Moving On to the Claude Code CLI

Once you're comfortable with Claude Desktop App and find yourself needing more powerful features in a terminal environment, try the Claude Code CLI. With Claude Code CLI, Claude can create, modify, and execute files directly, making it far more efficient for programming work.

For installing and using the Claude Code CLI, refer to Appendix B of this handbook. After you've thoroughly learned the fundamentals with Claude Desktop App, we recommend reading Appendix B.

Local Models as a Low-Cost Backend

Beyond a Claude Pro subscription, you can make use of AI without internet charges by using AI models running on your own computer. With tools like Ollama and LM Studio you can install AI models directly on your computer and converse with them just like Claude.

For installing and using local model backends, refer to Appendix C of this handbook. Using local models alongside Claude Desktop App lets you cut costs while still building a powerful AI environment.

Other Useful Tips

  • Exporting conversations — You can save important conversations as text files using the Export feature in the Claude Desktop App menu. Use them as study notes.
  • Shortcuts — Ctrl+N (Windows) or Cmd+N (MacOS) starts a new conversation. Ctrl+Shift+N creates a new project.
  • Regenerating answers — If you don't like Claude's answer, press the "Regenerate" button below it to get a different answer.
  • Branching conversations — If you use "Edit message" on a particular answer to revise your question, Claude creates a new branch of answers tailored to the revised question. This lets you explore multiple directions within a single conversation.
Try asking Claude, "If my question or request just now was ambiguous, tell me how I could improve it." Claude will advise what additional information it needed and how the question could be refined. This alone will sharpen your prompt-writing skills considerably.
