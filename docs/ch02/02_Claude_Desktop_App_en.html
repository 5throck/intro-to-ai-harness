Getting Started with Claude Desktop App

Install and learn to use Claude Desktop App — the primary tool for this handbook. Claude Desktop App is the easiest way to chat with AI using just mouse clicks, without any terminal commands.

What This Chapter Covers
  • Features and advantages of Claude Desktop App
  • Installation on MacOS, Windows, and Linux
  • Subscription plan selection guide
  • Your first conversation, projects, and Artifacts
  • Practical tips for beginners

What is Claude Desktop App

Claude Desktop App is a dedicated desktop application built by Anthropic, the company behind the Claude AI model. It provides a native, standalone window on your computer where you can converse with Claude, attach local files, manage projects, and use advanced features like Artifacts — all without opening a web browser.

Throughout this handbook, Claude Desktop App serves as the primary interface for interacting with AI. Even when we later explore multi-agent teams and command-line tools, the Desktop App remains your go-to environment for everyday AI conversations.

Three Ways to Use Claude

Anthropic offers several ways to interact with Claude. Understanding the differences helps you pick the right tool for each situation.

Figure 2-1: Comparison of the three Claude interfaces. Claude Desktop App (center) is the primary tool used throughout this handbook.

Why Claude Desktop App Over the Web Version?

Claude.ai (Web)

  • Accessible from any browser
  • No installation required
  • Can only read files you upload manually
  • No project-level custom instructions
  • Session resets on page refresh

Claude Desktop App

  • Runs as a native application
  • Can read files and folders on your computer
  • Supports project-level context and custom instructions
  • More stable connection and faster responses
  • Persistent conversation history
Claude Code CLI is a terminal-based tool for developers who want AI to read, edit, and run code directly from the command line. It is covered in Appendix B. For most beginners, Claude Desktop App is the recommended starting point.

Installation

Claude Desktop App is available for MacOS, Windows, and Linux. Follow the instructions for your operating system below.

MacOS
  1. Open the App Store on your Mac and search for "Claude", or visit claude.ai/download in your browser.
  2. Click Get (App Store) or Download for Mac (website) to download the installer.
  3. Open the downloaded .dmg file and drag Claude to your Applications folder.
  4. Launch Claude from your Applications folder or Spotlight (Cmd + Space, type "Claude").

Supported: MacOS 12 (Monterey) or later. Apple Silicon (M1/M2/M3/M4) and Intel Macs are both supported.

Windows
  1. Visit claude.ai/download in your browser, or use winget from a terminal:
winget install Anthropic.Claude
  1. Run the downloaded .exe installer and follow the on-screen prompts.
  2. Launch Claude from the Start Menu or desktop shortcut.

Supported: Windows 10 (64-bit) or later.

Linux

Anthropic provides packages for Debian/Ubuntu-based distributions. For other distros, a generic .tar.gz archive is available.

Debian / Ubuntu (.deb):

# Download the latest .deb package
wget https://claude.ai/download/linux/deb -O claude-desktop.deb

# Install
sudo dpkg -i claude-desktop.deb

# Fix any missing dependencies
sudo apt-get install -f

Generic Linux (.tar.gz):

# Download and extract
tar -xzf claude-desktop-linux.tar.gz

# Run
./claude-desktop

Supported: Ubuntu 20.04+ / Debian 11+ (64-bit). Other distributions may work with the tar.gz build.

Starting Your First Conversation

Once Claude Desktop App is installed and you have logged in with your Anthropic account, you will see the main conversation screen. Let's walk through what you see and start your very first chat.

Figure 2-2: Claude Desktop App screen layout. The sidebar (left) shows recent chats and projects, the chat area (center) is where you converse, and the Artifacts panel (right) displays generated content like code or documents.

Understanding the Interface

  • Sidebar (left) — Shows your recent conversations and projects. Click + New Chat to start a fresh conversation.
  • Chat Area (center) — This is where your conversation with Claude appears. Your messages appear on one side, and Claude's responses appear on the other.
  • Artifacts Panel (right) — When Claude generates code, documents, or visual content, it appears here in a separate panel. You can expand or collapse this panel.
  • Input Bar (bottom) — Type your message here and press Enter (or click the send button) to send it to Claude. You can also attach files by clicking the paperclip icon.

Try Your First Conversation

Start a new chat and try typing one of these beginner-friendly prompts:

Conversation Starter Ideas
"Hello! I'm new to Claude and AI in general. Can you explain what you can help me with in simple terms?"
For Work and Productivity
"I need to write a professional email declining a meeting invitation politely. The meeting is about a project I'm no longer involved in."
For Learning
"Can you explain the difference between machine learning and deep learning? Use simple analogies that a non-technical person would understand."
Claude remembers the context within a single conversation. If you ask follow-up questions, Claude will remember what you discussed earlier in the same chat. However, each new chat starts with a clean slate — Claude does not carry over information from previous conversations unless you use the Projects feature (see next section).

Projects Feature

Projects are one of the most powerful features in Claude Desktop App. A project lets you group related conversations together and provide Claude with custom instructions and context files that persist across all chats within that project.

What Can Projects Do?

  • Custom Instructions — Define how Claude should respond in this project (e.g., "Always respond in Korean," "You are a coding tutor," "Keep explanations at a beginner level").
  • Context Files — Upload reference documents, code files, or notes that Claude can automatically refer to when answering questions in this project.
  • Organized Conversations — Keep all chats related to a specific topic or task in one place, instead of scattered across your history.

Creating a Project

Open the Projects panel — In the Claude Desktop App sidebar, find the Projects section and click the Create Project button (or the + icon next to Projects).
Name your project — Give it a clear, descriptive name. For example: "AI Study Notes", "Work Reports", or "Coding Practice".
Write custom instructions — In the Project Instructions text box, write a brief description of how Claude should behave in this project. For example:
"You are a helpful tutor for AI beginners. Explain concepts simply, use analogies, and always provide examples. When showing code, explain each line."
Add context files (optional) — Click Add Files to upload documents, text files, or code that Claude should reference. You can add up to the plan's file limit.
Start chatting — Click Create to finalize. Now every new conversation you start within this project will automatically use your custom instructions and have access to your context files.
Pro tip: Create a dedicated project for following this handbook. Name it something like "AI Handbook Study" and add a custom instruction: "You are a study assistant helping me learn about Claude Desktop App and multi-agent AI systems. Reference the handbook concepts and explain things step by step."

Artifacts

Artifacts are a unique Claude feature that lets Claude generate standalone pieces of content — such as web pages, documents, code, diagrams, and interactive tools — and display them in a dedicated panel next to your conversation.

Instead of just describing a web page in text, Claude can build the actual page and show it to you right inside Claude Desktop App. You can see the result immediately, test it, iterate on it, and even copy the code.

What Can Artifacts Create?

  • Web Pages — HTML/CSS/JS mini-apps (calculators, quizzes, dashboards)
  • Documents — formatted text with structure (reports, letters, guides)
  • Code — syntax-highlighted code snippets with copy button
  • Diagrams — SVG flowcharts, architecture diagrams, and visual explanations
  • Interactive Tools — working prototypes with buttons, forms, and logic

Example: Creating a Simple Calculator

Try this prompt in Claude Desktop App:

Artifact Prompt
"Please make a simple calculator web page. It should have buttons for digits 0-9, basic operations (+, -, ×, ÷), a display showing the current input and result, and a clear button. Style it nicely with a clean, modern look."

Claude will generate the calculator as an Artifact. You should see it appear in the Artifacts panel on the right side of the screen. You can:

  • Use it — Click the buttons and test the calculator right there in the panel.
  • Copy the code — Click the code icon to view and copy the full HTML/CSS/JS source.
  • Iterate — Ask Claude to modify it: "Add a percentage button" or "Change the background color to light blue."
  • Download — Copy the code and save it as an .html file on your computer to open in any browser.
Artifacts are an excellent way to learn to code interactively. Ask Claude to build something step by step — start with a simple version, then add features one at a time. You learn by seeing how each change affects the result. This "build-and-iterate" approach is much more effective than reading about code in a textbook. Try creating a to-do list app, a quiz, or a simple game!

Tips for Beginners

Getting good results from Claude is a skill that improves with practice. Here are practical tips to help you communicate more effectively from day one.

Write Clear Prompts

The quality of Claude's response depends heavily on how you phrase your request. Here are some principles:

Principle Instead of this... Try this...
Be specific "Help me with email" "Write a polite email to my manager requesting next Friday off for a personal matter"
Provide context "Explain Python" "I'm a complete beginner with no programming experience. Explain what Python is and what it's used for."
Specify format "Summarize this article" "Summarize this article in 3 bullet points, each under 20 words"
Give examples "Write a recipe" "Write a recipe for a simple pasta dish, like the one you'd find in an Italian cookbook for beginners"

Break Down Complex Requests

If you have a complex task, do not try to cram everything into one giant prompt. Instead, break it into smaller, sequential steps. Claude handles focused requests much better than overloaded ones.

Overloaded Prompt

"Write a 10-page business plan for a coffee shop, including market analysis, financial projections for 3 years, marketing strategy, competitor analysis, and a daily operations schedule."

Step-by-Step Approach

Step 1: "I want to open a coffee shop. Help me brainstorm 5 unique selling points that would differentiate it from chain coffee shops."

Step 2: "Based on those selling points, help me create a market analysis outline."

Step 3: "Now help me build a simple 3-year revenue projection."

Think of Claude as a knowledgeable colleague, not a search engine. Have a conversation rather than firing off a single query. Start broad, then ask follow-up questions to drill into specifics.

Set Your Language Preference

Claude works in many languages. If you prefer responses in a specific language, simply tell Claude at the start of a conversation:

Language Setting Prompt
"From now on, please respond to all my messages in Korean. If I ask about English content, explain it in Korean."

Alternatively, set a Project-level instruction (see the Projects section above) so that every conversation in that project automatically uses your preferred language.

Use Claude for Learning, Not Just Answers

  • Ask for explanations, not just solutions. Instead of "What is the answer to X?", try "How would you approach solving X? Walk me through your reasoning."
  • Ask Claude to quiz you. "I just learned about neural networks. Can you quiz me with 5 questions to test my understanding?"
  • Request analogies. "Explain API integrations using a restaurant kitchen analogy."
  • Build practice exercises. "Create 3 beginner Python exercises about loops, starting from easy to challenging."

Common Beginner Mistakes to Avoid

Avoid these common pitfalls:
  • Assuming Claude is always right. Claude can make mistakes or "hallucinate" information. Always verify important facts, especially for medical, legal, or financial topics.
  • Sharing sensitive information. Do not paste passwords, API keys, Social Security numbers, or other sensitive data into Claude. Anthropic may use conversation data to improve models (depending on your privacy settings).
  • Expecting real-time data. Claude's knowledge has a cutoff date and it does not browse the web in real time (unless a specific tool or integration is enabled). For current events or live data, verify with web searches.
  • Giving up after one try. If Claude's first response is not what you wanted, refine your prompt and try again. Iteration is part of the process.

Next Steps

Congratulations on learning the basics of Claude Desktop App! Here is what to do next:

  1. Practice: Spend 15–30 minutes chatting with Claude about any topic. Try the calculator Artifact example above.
  2. Create a Project: Make a project for this handbook with custom instructions.
  3. Explore: Try attaching a file (a text document, a code snippet) and asking Claude to summarize or explain it.
  4. Move to Chapter 3: Set up your development lab for multi-agent work.
Looking ahead: In later chapters, we will use Claude Desktop App as the gateway to multi-agent systems. Claude Desktop App will connect to agent orchestrators, code editors, and other tools that let you experience real AI agent teamwork.
