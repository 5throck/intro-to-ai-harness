Comenzando con Claude Desktop App

Instala y aprende a usar Claude Desktop App, la herramienta principal de este manual. Claude Desktop App es la forma más sencilla de conversar con la IA solo con clics del ratón, sin ningún comando de terminal.

Lo que cubre este capítulo
  • Características y ventajas de Claude Desktop App
  • Instalación en MacOS, Windows y Linux
  • Guía para elegir el plan de suscripción
  • Primera conversación, proyectos y prueba de la función Artifacts
  • Consejos prácticos para principiantes

¿Qué es Claude Desktop App

Claude Desktop App es un asistente de IA para el escritorio desarrollado por Anthropic. Es un programa que te permite conversar con la IA de Claude directamente en la pantalla de tu computadora, sin necesidad de abrir un navegador web. Igual que una app de mensajería, escribes tu pregunta en la ventana de chat y Claude te da una respuesta.

Diferencias con la versión web de Claude.ai

También puedes usar Claude desde el navegador web (claude.ai). Claude Desktop App tiene varias ventajas importantes frente a la versión web:

  • Acceso a archivos locales — Claude puede leer y analizar directamente los archivos guardados en tu computadora. Por ejemplo, si arrastras y sueltas un documento PDF, un archivo de código o un archivo de texto, Claude entenderá su contenido y te responderá.
  • Función de Proyectos — Puedes agrupar conversaciones relacionadas en un solo proyecto y gestionarlas juntas. También puedes configurar ajustes específicos de forma distinta en cada proyecto.
  • Estabilidad y velocidad — Al ejecutarse como aplicación independiente, no hace falta gestionar pestañas del navegador, y aunque la conexión a internet sea algo inestable, la conversación se conserva bien.
  • Atajos de teclado — Con atajos de teclado puedes iniciar una conversación nueva al instante o recuperar una conversación anterior.

Diferencias con Claude Code CLI

Claude Code CLI es una herramienta de Claude que se usa en la terminal (ventana de comandos). Ofrece una potencia enorme para manipular archivos directamente cuando un programador escribe o modifica código. Sin embargo, como hay que introducir comandos, la barrera de entrada puede ser alta para principiantes.

Claude Code CLI se cubre en detalle en el Apéndice B de este manual. CLI (Command Line Interface) es la forma de manejar programas mediante comandos de teclado en lugar del ratón. Se ejecuta con el comando claude en una ventana de terminal (PowerShell en Windows, Terminal en MacOS, etc.).

En este manual usamos Claude Desktop App como herramienta principal. Los principiantes pueden empezar con facilidad y experimentar todas las funciones esenciales de Claude. Cuando te conviertas en usuario avanzado, podrás pasarte a Claude Code CLI (Apéndice B).

Instalación

Claude Desktop App es compatible con los tres sistemas operativos: MacOS, Windows y Linux. Sigue el método de instalación que corresponda al sistema operativo de tu computadora.

Requisitos del sistema

Elemento Requisito mínimo Recomendado
Sistema operativo macOS 12+, Windows 10 de 64 bits, Ubuntu 20.04+ macOS 14+, Windows 11, Ubuntu 22.04+
RAM (memoria) 4GB 8GB o más
Espacio en disco 500MB 1GB o más
Internet Obligatorio (Claude funciona en la nube) Conexión de banda ancha estable
Para usar Claude Desktop App se necesita una suscripción a Claude Pro o Max. Con el plan gratuito (Free tier) solo puedes usar la versión web de Claude.ai, y el inicio de sesión en Desktop App está restringido. Consulta la sección "Planes de suscripción" más abajo.
Instalación en MacOS

En MacOS hay dos formas de instalar Claude Desktop App.

Método 1: Instalar desde la App Store (recomendado)

  1. Abre la app App Store de tu Mac.
  2. Escribe Claude en el buscador.
  3. Encuentra la app "Anthropic Claude" y pulsa el botón Descargar.
  4. Cuando termine la instalación, ejecuta Claude desde la carpeta Aplicaciones.

Método 2: Descargar desde el sitio web

  1. Accede a claude.ai/download desde tu navegador.
  2. Haz clic en el botón "Download for Mac".
  3. Abre el archivo .dmg descargado y arrastra el icono de Claude a la carpeta Aplicaciones.
  4. Si al abrirlo por primera vez aparece el mensaje "No se puede abrir esta aplicación", ve a Configuración del Sistema > Privacidad y seguridad y pulsa "Abrir".
Instalación en Windows

En Windows también hay dos formas de instalarlo.

Método 1: Descargar desde el sitio web (recomendado)

  1. Accede a claude.ai/download desde tu navegador.
  2. Haz clic en el botón "Download for Windows".
  3. Ejecuta el archivo de instalación .exe descargado.
  4. Sigue las instrucciones del asistente de instalación y pulsa "Next" para completarla.
  5. Haz doble clic en el acceso directo de Claude creado en el escritorio para ejecutarlo.

Método 2: Usar winget (el gestor de paquetes de Windows)

Puedes instalarlo introduciendo el siguiente comando en la ventana de comandos (PowerShell):

winget install Anthropic.Claude

winget es el gestor de paquetes integrado en Windows; permite instalar y actualizar programas con una sola línea de comando.

Instalación en Linux

En Linux hay dos métodos de instalación según el formato del paquete.

Método 1: Paquete .deb (Debian / Ubuntu)

# 1. Descarga el archivo .deb desde la página de descargas
# obtén Claude-linux.deb desde claude.ai/download

# 2. Instálalo desde la terminal
sudo dpkg -i Claude-linux.deb

# 3. Si surge algún problema de dependencias, resuélvelo con este comando
sudo apt-get install -f

Método 2: Archivo .tar.gz (otras distribuciones Linux)

# 1. Descarga el archivo .tar.gz desde la página de descargas
# obtén Claude-linux.tar.gz desde claude.ai/download

# 2. Descomprime el archivo
tar xzf Claude-linux.tar.gz

# 3. Ejecuta el binario de Claude
./claude
El método .tar.gz de Linux coloca el binario de Claude manualmente en la ubicación que prefieras. Si lo dejas en un directorio como /opt/claude y lo añades al PATH, podrás ejecutarlo desde cualquier punto de la terminal.

¿Qué plan deberías elegir?

Para seguir las prácticas de este manual, Claude Pro ($20/mes) es suficiente. Claude Pro ofrece todas las funciones esenciales de Claude Desktop App y un volumen de conversación adecuado para que un principiante aprenda y practique con Claude.

Si estás empezando, prueba primero con Claude Pro. Cuando notes que el uso crece y Pro se queda corto, puedes actualizar a Max. La suscripción se puede cambiar en cualquier momento.

Cómo iniciar la suscripción

  1. Accede a claude.ai y crea una cuenta de Anthropic (también puedes registrarte con una cuenta de Google o Apple).
  2. Tras iniciar sesión, haz clic en el icono de perfil de la parte inferior izquierda de la pantalla.
  3. Haz clic en el botón "Upgrade to Pro" o "Upgrade to Max".
  4. Introduce los datos de pago y completa la suscripción.
La suscripción se gestiona en claude.ai/subscribe. El cambio de plan, el cambio de método de pago y la cancelación de la suscripción se realizan todos en esa página.

Tu primera conversación

Una vez instalado Claude Desktop App y completada la suscripción, empecemos a conversar con Claude.

Ejecutar Claude Desktop App

Haz clic en el icono de Claude del escritorio o de la carpeta Aplicaciones para ejecutar la app. Al abrirla por primera vez aparecerá una pantalla que te pedirá iniciar sesión con tu cuenta de Anthropic. Inicia sesión con la cuenta creada en el capítulo 1 de este manual (o con una cuenta nueva).

Componentes de la pantalla

Como se ve en el diagrama anterior, la pantalla de Claude Desktop App se divide en tres partes principales:

  • Barra lateral (izquierda) — Muestra la lista de conversaciones anteriores. Al hacer clic en una conversación concreta puedes continuarla donde quedó. Con el botón "+ Nueva conversación" de la parte inferior inicias una conversación nueva.
  • Área de chat (centro) — Muestra la conversación con Claude. Tus mensajes y las respuestas de Claude aparecen en orden.
  • Panel de Artifacts (derecha) — Panel donde ver aparte el código, los documentos y los diagramas que genera Claude. (Para más detalles, ver la sección "Artifacts")

Enviar el primer mensaje

Escribe un mensaje en el cuadro de entrada de texto situado en la parte inferior del área de chat y pulsa la tecla Enter (o el botón de envío); Claude responderá. Introduce tal cual el siguiente ejemplo:

Envía a Claude el siguiente mensaje:
Hola, soy un principiante que está empezando a aprender IA. Explícame de forma sencilla qué es un equipo de agentes de IA

Claude explicará qué es un equipo de agentes de IA en un lenguaje fácil de entender incluso para principiantes. Lee la respuesta y, si te queda alguna duda, lanza preguntas adicionales. Por ejemplo:

  • "Entonces, ¿un equipo de agentes de IA es parecido a los departamentos de una empresa?"
  • "¿Un principiante también puede crear un equipo de agentes de IA?"
  • "¿Qué puedo aprender con este manual?"

La conversación con Claude recuerda el contexto de los mensajes anteriores. Por eso, al hacer preguntas de seguimiento no hace falta repetir lo dicho antes. Continúa con naturalidad, como si conversaras con una persona.

Función de Proyectos

¿Qué es un proyecto?

Un proyecto (Project) es una función de Claude Desktop App que agrupa y gestiona como una sola unidad las conversaciones relacionadas. En una conversación normal, Claude solo recuerda el contenido anterior hasta cierto punto; en cambio, al usar un proyecto, todas las conversaciones de ese proyecto se mantienen bajo un mismo contexto.

Por ejemplo, si conversas con Claude sobre el tema "Aprendizaje de IA" a lo largo de varios días haciendo preguntas y recibiendo respuestas, cada vez que empieces una conversación nueva Claude puede olvidar lo aprendido antes. Pero si lo guardas dentro de un proyecto, Claude consultará todas las conversaciones de ese proyecto y dará respuestas coherentes.

Funciones clave de los proyectos

  • Conocimiento del proyecto (Project Knowledge) — Si adjuntas archivos relacionados (PDF, código, texto) al proyecto, Claude responderá basándose en su contenido. Por ejemplo, si adjuntas el PDF del material de un curso, Claude podrá leer ese material y responder preguntas sobre él.
  • Instrucciones personalizadas (Custom Instructions) — Puedes establecer indicaciones para Claude en cada proyecto. Ej.: "Responde siempre en español", "Adapta las explicaciones a principiantes", "Mantén las respuestas en menos de 3 frases".
  • Agrupación de conversaciones — Dentro de un proyecto puedes crear varias conversaciones, y cada una comparte el contexto del proyecto.

Práctica: crear el proyecto "Aprendizaje de IA"

Crear el proyecto
En la parte superior de la barra lateral de Claude Desktop App, haz clic en el icono situado junto al botón "+ Nueva conversación" y elige "Create Project".
Poner nombre al proyecto
Escribe como nombre del proyecto "Aprendizaje de IA". En el campo de descripción puedes poner "Proyecto para aprender sobre los equipos de agentes de IA y el uso de Claude".
Escribir las instrucciones personalizadas
En el área de Custom Instructions introduce lo siguiente: 
Responde en español.
Dame explicaciones sencillas para principiantes.
Si aparece un término desconocido, explícalo siempre.
Añadir archivos al proyecto (opcional)
Si descargaste las primeras partes de este manual (PDF, etc.), puedes pulsar el botón "Add files" para añadirlas al proyecto. Al añadir archivos, Claude tendrá en cuenta su contenido.
Iniciar la primera conversación
Inicia una conversación nueva dentro del proyecto y envía el siguiente mensaje: 
En este proyecto quiero aprender sobre
Claude Desktop App y los equipos de agentes de IA.
¿Con qué sería mejor empezar?

Creando así el proyecto, podrás continuar dentro de él todas las preguntas que vayas aprendiendo en los capítulos siguientes. Claude ofrecerá respuestas más profundas basándose en las conversaciones anteriores.

Artifacts

¿Qué son los Artifacts?

Los Artifacts son una función que muestra en un panel separado, fuera de la ventana de conversación, el código, los documentos y el material visual que Claude genera durante la conversación. En una conversación normal, cuando Claude escribe código este aparece como texto dentro del chat; con Artifacts, en cambio, puedes ver el código en un panel independiente y ejecutarlo directamente.

Por ejemplo, si pides a Claude "créame una página web de calculadora sencilla", Claude escribirá el código HTML, CSS y JavaScript. Cuando Artifacts está activado, ese código:

  • Se muestra en el panel de Artifacts, junto a la ventana de conversación
  • Puede comprobarse mediante una vista previa de cómo se ve realmente la página web
  • Puede copiarse y guardarse como archivo

Prueba los Artifacts

Pide a Claude lo siguiente:

Para probar la función Artifacts, envía el siguiente mensaje:
Créame una página web de calculadora sencilla. Basta con que tenga funciones de sumar, restar, multiplicar y dividir.

Cuando Claude escriba el código, se abrirá el panel de Artifacts a la derecha de la pantalla y mostrará una vista previa en tiempo real de la página web de la calculadora. En la vista previa puedes pulsar los botones y hacer cálculos de verdad.

Qué puedes hacer con los Artifacts

Tipo Descripción Ejemplos
Código (Code) Código de programación: HTML, CSS, JavaScript, Python, etc. Páginas web, calculadoras, animaciones
Documentos (Document) Documentos de texto estructurados (formato Markdown) Resúmenes, informes de análisis, listas de comprobación
Componentes React Elementos de UI interactivos (escritos en React) Gráficos, cuestionarios, formularios interactivos
Visualizaciones SVG Diagramas de gráficos vectoriales Diagramas de flujo, esquemas de estructura, gráficos
El código generado en Artifacts puede ejecutarse al instante, lo cual es muy útil para aprender a programar. Si le preguntas "¿qué hace esta parte del código?", Claude te explicará en detalle qué papel cumple cada fragmento. Si le pides modificarlo, Claude lo corrige al momento y lo refleja en la vista previa.

Consejos para principiantes

Aquí tienes consejos prácticos para usar Claude Desktop App con mayor eficacia.

Cómo escribir buenos prompts

Un prompt es el mensaje que envías a Claude, es decir, la pregunta o la petición. Escribir buenos prompts mejora enormemente la calidad de las respuestas de Claude.

Prompts mejorables

  • "Háblame de la IA"
  • "Escríbeme código"
  • "¿Cómo se hace esto?"

Buenos prompts

  • "Explícame qué es un equipo de agentes de IA en 3 frases que un principiante pueda entender"
  • "Escríbeme en Python un programa sencillo de lista de tareas pendientes (to-do list). Necesita funciones para añadir, borrar y ver la lista"
  • "Explícame paso a paso cómo crear un proyecto en Claude Desktop App"

La clave de un buen prompt es pedir las cosas de forma concreta y clara:

  • Explica el contexto — Indica tu nivel: "Soy principiante", "No tengo experiencia en programación"
  • Objetivo claro — Di concretamente qué resultado esperas obtener
  • Especifica el formato — Indica la forma de la respuesta deseada: "en 3 frases", "paso a paso", "en formato de tabla"
  • Aporta ejemplos — Si muestras un ejemplo del resultado deseado, Claude lo entenderá con mayor precisión

Dividir la conversación en partes

Antes que preguntarlo todo de una sola vez, plantéate las peticiones complejas dividiéndolas en pasos. Como la conversación con Claude recuerda el contexto previo, aunque la dividas en unidades pequeñas se mantiene el contexto general.

Ejemplo: al aprender los equipos de agentes de IA
1ª: "Explícame brevemente qué es un equipo de agentes de IA"
2ª: "¿Qué roles puede asumir cada agente?"
3ª: "¿Un principiante también puede montar un equipo de agentes? ¿Cómo empiezo?"
4ª: "Muéstrame un ejemplo de cómo montar un equipo de agentes con Claude Desktop App"

Configuración del idioma

Claude admite muchos idiomas, entre ellos el español. Si al comienzo de la conversación lo dejas configurado así, Claude responderá siempre en español:

Al iniciar la conversación, deja configurado lo siguiente:
A partir de ahora, responde a todas mis conversaciones en español.

Otra opción es dejar escrito "Responde en español" en las Custom Instructions del proyecto (explicado en la sección "Función de Proyectos" anterior); así no tendrás que decirlo cada vez.

Pasarse a Claude Code CLI

Cuando te familiarices con Claude Desktop App y necesites funciones más potentes en un entorno de terminal, prueba Claude Code CLI. Claude Code CLI permite que Claude genere, modifique y ejecute archivos directamente, por lo que es mucho más eficiente para trabajos de programación.

Para la instalación y el uso de Claude Code CLI, consulta el Apéndice B de este manual. Se recomienda leerlo después de adquirir con solidez los fundamentos con Claude Desktop App.

Backends locales de bajo costo

Además de la suscripción a Claude Pro, si usas modelos de IA que se ejecutan en tu propia computadora podrás aprovechar la IA sin coste de suscripción. Con herramientas como Ollama o LM Studio puedes instalar modelos de IA directamente en la computadora y conversar igual que con Claude.

Para la instalación y el aprovechamiento de los backends de modelos locales, consulta el Apéndice C de este manual. Combinando Claude Desktop App con modelos locales puedes construir un entorno de IA potente reduciendo costes.

Otros consejos útiles

  • Exportar conversaciones — Las conversaciones importantes pueden guardarse como archivo de texto con la función Exportar (Export) del menú de Claude Desktop App. Aprovéchalas como notas de estudio.
  • Atajos de teclado — Con Ctrl+N (Windows) o Cmd+N (MacOS) puedes iniciar una conversación nueva. Con Ctrl+Shift+N puedes crear un proyecto nuevo.
  • Regenerar la respuesta — Si la respuesta de Claude no te convence, pulsa el botón "Regenerate" de la parte inferior de la respuesta para obtener otra distinta.
  • Ramificar la conversación — Si en una respuesta determinada usas "Edit message" para corregir tu pregunta, Claude creará una rama de respuestas nueva acorde a la pregunta modificada. Así puedes explorar varios caminos dentro de una misma conversación.
Pregunta a Claude: "si mi pregunta o petición ha sido ambigua, dime cómo podría corregirla". Claude te aconsejará qué información le falta y cómo afinar la pregunta. Solo con eso mejorarás notablemente tu habilidad para escribir prompts.
