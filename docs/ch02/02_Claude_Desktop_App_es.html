Comenzando con Claude Desktop App

Instala y aprende a usar Claude Desktop App — la herramienta principal de este manual. Claude Desktop App es la forma más fácil de chatear con IA usando solo clics del ratón, sin ningún comando de terminal.

Lo que cubre este capítulo
  • Características y ventajas de Claude Desktop App
  • Instalación en MacOS, Windows y Linux
  • Guía de selección de plan de suscripción
  • Tu primera conversación, proyectos y Artifacts
  • Consejos prácticos para principiantes

¿Qué es Claude Desktop App

Claude Desktop App es una aplicación de escritorio dedicada creada por Anthropic, la empresa detrás del modelo de IA Claude. Proporciona una ventana nativa e independiente en tu computadora donde puedes conversar con Claude, adjuntar archivos locales, gestionar proyectos y usar funciones avanzadas como Artifacts — todo sin abrir un navegador web.

A lo largo de este manual, Claude Desktop App sirve como la interfaz principal para interactuar con la IA. Incluso cuando más adelante exploremos equipos multi-agente y herramientas de línea de comandos, la Desktop App sigue siendo tu entorno predilecto para las conversaciones cotidianas con IA.

Tres formas de usar Claude

Anthropic ofrece varias formas de interactuar con Claude. Comprender las diferencias te ayuda a elegir la herramienta adecuada para cada situación.

Figura 2-1: Comparación de las tres interfaces de Claude. Claude Desktop App (centro) es la herramienta principal utilizada en este manual.

¿Por qué Claude Desktop App en lugar de la versión web?

Claude.ai (Web)

  • Accesible desde cualquier navegador
  • No requiere instalación
  • Solo puede leer archivos que subas manualmente
  • Sin instrucciones personalizadas a nivel de proyecto
  • La sesión se reinicia al actualizar la página

Claude Desktop App

  • Funciona como aplicación nativa
  • Puede leer archivos y carpetas en tu computadora
  • Soporta contexto e instrucciones personalizadas a nivel de proyecto
  • Conexión más estable y respuestas más rápidas
  • Historial de conversación persistente
Claude Code CLI es una herramienta basada en terminal para desarrolladores que quieren que la IA lea, edite y ejecute código directamente desde la línea de comandos. Se cubre en el Apéndice B. Para la mayoría de los principiantes, Claude Desktop App es el punto de partida recomendado.

Instalación

Claude Desktop App está disponible para MacOS, Windows y Linux. Sigue las instrucciones para tu sistema operativo a continuación.

MacOS
  1. Abre la App Store en tu Mac y busca "Claude", o visita claude.ai/download en tu navegador.
  2. Haz clic en Get (App Store) o Download for Mac (sitio web) para descargar el instalador.
  3. Abre el archivo .dmg descargado y arrastra Claude a tu carpeta de Aplicaciones.
  4. Lanza Claude desde tu carpeta de Aplicaciones o Spotlight (Cmd + Espacio, escribe "Claude").

Compatible con: MacOS 12 (Monterey) o posterior. Apple Silicon (M1/M2/M3/M4) y Macs Intel son ambos compatibles.

Windows
  1. Visita claude.ai/download en tu navegador, o usa winget desde una terminal:
winget install Anthropic.Claude
  1. Ejecuta el instalador .exe descargado y sigue las instrucciones en pantalla.
  2. Lanza Claude desde el Menú Inicio o el acceso directo del escritorio.

Compatible con: Windows 10 (64 bits) o posterior.

Linux

Anthropic proporciona paquetes para distribuciones basadas en Debian/Ubuntu. Para otras distribuciones, hay un archivo .tar.gz genérico disponible.

Debian / Ubuntu (.deb):

# Descargar el último paquete .deb
wget https://claude.ai/download/linux/deb -O claude-desktop.deb

# Instalar
sudo dpkg -i claude-desktop.deb

# Corregir cualquier dependencia faltante
sudo apt-get install -f

Linux genérico (.tar.gz):

# Descargar y extraer
tar -xzf claude-desktop-linux.tar.gz

# Ejecutar
./claude-desktop

Compatible con: Ubuntu 20.04+ / Debian 11+ (64 bits). Otras distribuciones pueden funcionar con la versión tar.gz.

Tu primera conversación

Una vez que Claude Desktop App esté instalado y hayas iniciado sesión con tu cuenta de Anthropic, verás la pantalla principal de conversación. Repasemos lo que ves y comencemos tu primer chat.

Figura 2-2: Disposición de la pantalla de Claude Desktop App. La barra lateral (izquierda) muestra chats recientes y proyectos, el área de chat (centro) es donde conversas, y el panel de Artifacts (derecha) muestra contenido generado como código o documentos.

Comprendiendo la interfaz

  • Barra lateral (izquierda) — Muestra tus conversaciones recientes y proyectos. Haz clic en + Nuevo chat para iniciar una conversación nueva.
  • Área de chat (centro) — Aquí aparece tu conversación con Claude. Tus mensajes aparecen de un lado y las respuestas de Claude del otro.
  • Panel de Artifacts (derecha) — Cuando Claude genera código, documentos o contenido visual, aparece aquí en un panel separado. Puedes expandir o colapsar este panel.
  • Barra de entrada (abajo) — Escribe tu mensaje aquí y presiona Enter (o haz clic en el botón de envío) para enviarlo a Claude. También puedes adjuntar archivos haciendo clic en el icono del clip.

Prueba tu primera conversación

Inicia un nuevo chat y prueba escribir uno de estos prompts para principiantes:

Ideas para iniciar conversación
"¡Hola! Soy nuevo en Claude y en la IA en general. ¿Puedes explicarme qué puedes ayudarme a hacer en términos simples?"
Para el trabajo y la productividad
"Necesito escribir un correo profesional rechazando cortésmente una invitación a una reunión. La reunión trata de un proyecto en el que ya no estoy involucrado."
Para el aprendizaje
"¿Puedes explicarme la diferencia entre el aprendizaje automático y el aprendizaje profundo? Usa analogías simples que una persona no técnica entendería."
Claude recuerda el contexto dentro de una sola conversación. Si haces preguntas de seguimiento, Claude recordará lo que discutiste antes en el mismo chat. Sin embargo, cada nuevo chat comienza con una pizarra limpia — Claude no transfiere información de conversaciones anteriores a menos que uses la función de Proyectos (ver la siguiente sección).

Función de Proyectos

Proyectos son una de las funciones más poderosas de Claude Desktop App. Un proyecto te permite agrupar conversaciones relacionadas y proporcionar a Claude instrucciones personalizadas y archivos de contexto que persisten en todos los chats dentro de ese proyecto.

¿Qué pueden hacer los Proyectos?

  • Instrucciones personalizadas — Define cómo Claude debe responder en este proyecto (por ejemplo, "Siempre responde en español", "Eres un tutor de programación", "Mantén las explicaciones a nivel de principiante").
  • Archivos de contexto — Sube documentos de referencia, archivos de código o notas a los que Claude pueda referirse automáticamente al responder preguntas en este proyecto.
  • Conversaciones organizadas — Mantén todos los chats relacionados con un tema o tarea específicos en un solo lugar, en lugar de dispersos en tu historial.

Creando un Proyecto

Abre el panel de Proyectos — En la barra lateral de Claude Desktop App, encuentra la sección Proyectos y haz clic en el botón Crear Proyecto (o el icono + junto a Proyectos).
Nombra tu proyecto — Dale un nombre claro y descriptivo. Por ejemplo: "Notas de estudio de IA", "Informes de trabajo" o "Práctica de código".
Escribe instrucciones personalizadas — En el cuadro de texto Instrucciones del Proyecto, escribe una breve descripción de cómo Claude debe comportarse en este proyecto. Por ejemplo:
"Eres un tutor útil para principiantes en IA. Explica los conceptos de forma simple, usa analogías y siempre proporciona ejemplos. Al mostrar código, explica cada línea."
Añade archivos de contexto (opcional) — Haz clic en Añadir archivos para subir documentos, archivos de texto o código que Claude deba consultar. Puedes añadir hasta el límite de archivos de tu plan.
Comienza a chatear — Haz clic en Crear para finalizar. Ahora cada nueva conversación que inicies dentro de este proyecto usará automáticamente tus instrucciones personalizadas y tendrá acceso a tus archivos de contexto.
Consejo profesional: Crea un proyecto dedicado para seguir este manual. Nómbralo algo como "Estudio del manual de IA" y añade una instrucción personalizada: "Eres un asistente de estudio que me ayuda a aprender sobre Claude Desktop App y los sistemas de IA multi-agente. Referencia los conceptos del manual y explica las cosas paso a paso."

Artifacts

Artifacts son una función única de Claude que permite a Claude generar piezas de contenido independientes — como páginas web, documentos, código, diagramas y herramientas interactivas — y mostrarlas en un panel dedicado junto a tu conversación.

En lugar de solo describir una página web en texto, Claude puede construir la página real y mostrarla directamente dentro de Claude Desktop App. Puedes ver el resultado inmediatamente, probarlo, iterar sobre él e incluso copiar el código.

¿Qué pueden crear los Artifacts?

  • Páginas web — Mini-aplicaciones HTML/CSS/JS (calculadoras, cuestionarios, paneles)
  • Documentos — Texto formateado con estructura (informes, cartas, guías)
  • Código — Fragmentos de código con resaltado de sintaxis y botón de copiar
  • Diagramas — Diagramas de flujo SVG, diagramas de arquitectura y explicaciones visuales
  • Herramientas interactivas — Prototipos funcionales con botones, formularios y lógica

Ejemplo: Creando una calculadora simple

Prueba este prompt en Claude Desktop App:

Prompt de Artifact
"Por favor, haz una página web de calculadora simple. Debe tener botones para los dígitos 0-9, operaciones básicas (+, -, ×, ÷), una pantalla que muestre la entrada actual y el resultado, y un botón de borrar. Estílala con un aspecto limpio y moderno."

Claude generará la calculadora como un Artifact. Deberías verla aparecer en el panel de Artifacts en el lado derecho de la pantalla. Puedes:

  • Usarla — Haz clic en los botones y prueba la calculadora directamente en el panel.
  • Copiar el código — Haz clic en el icono de código para ver y copiar el código fuente HTML/CSS/JS completo.
  • Iterar — Pide a Claude que la modifique: "Añade un botón de porcentaje" o "Cambia el color de fondo a azul claro".
  • Descargar — Copia el código y guárdalo como un archivo .html en tu computadora para abrirlo en cualquier navegador.
Los Artifacts son una excelente manera de aprender a programar de forma interactiva. Pide a Claude que construya algo paso a paso — comienza con una versión simple, luego añade funciones una a la vez. Aprendes viendo cómo cada cambio afecta el resultado. Este enfoque de "construir e iterar" es mucho más efectivo que leer sobre código en un libro de texto. ¡Intenta crear una aplicación de lista de tareas, un cuestionario o un juego simple!

Consejos para principiantes

Obtener buenos resultados de Claude es una habilidad que mejora con la práctica. Aquí hay consejos prácticos para ayudarte a comunicarte más eficazmente desde el primer día.

Escribe prompts claros

La calidad de la respuesta de Claude depende en gran medida de cómo formules tu solicitud. Aquí hay algunos principios:

Principio En lugar de esto... Prueba esto...
Sé específico "Ayúdame con un correo" "Escribe un correo educado a mi gerente solicitando el próximo viernes libre por un asunto personal"
Proporciona contexto "Explica Python" "Soy un principiante absoluto sin experiencia en programación. Explica qué es Python y para qué se usa."
Especifica el formato "Resume este artículo" "Resume este artículo en 3 viñetas, cada una con menos de 20 palabras"
Da ejemplos "Escribe una receta" "Escribe una receta para un plato de pasta simple, como el que encontrarías en un libro de cocina italiano para principiantes"

Descompón solicitudes complejas

Si tienes una tarea compleja, no intentes meter todo en un solo prompt gigante. En su lugar, divídela en pasos secuenciales más pequeños. Claude maneja solicitudes enfocadas mucho mejor que las sobrecargadas.

Prompt sobrecargado

"Escribe un plan de negocio de 10 páginas para una cafetería, incluyendo análisis de mercado, proyecciones financieras para 3 años, estrategia de marketing, análisis de competidores y un horario de operaciones diarias."

Enfoque paso a paso

Paso 1: "Quiero abrir una cafetería. Ayúdame a lluvia de ideas 5 puntos de venta únicos que la diferenciarían de las cafeterías de cadena."

Paso 2: "Basándote en esos puntos de venta, ayúdame a crear un esquema de análisis de mercado."

Paso 3: "Ahora ayúdame a construir una proyección de ingresos simple para 3 años."

Piensa en Claude como un colega conocedor, no como un buscador. Ten una conversación en lugar de disparar una sola consulta. Comienza de manera amplia y luego haz preguntas de seguimiento para profundizar en los detalles.

Establece tu preferencia de idioma

Claude funciona en muchos idiomas. Si prefieres respuestas en un idioma específico, simplemente dile a Claude al inicio de una conversación:

Prompt de configuración de idioma
"A partir de ahora, por favor responde a todos mis mensajes en español. Si pregunto sobre contenido en inglés, explícalo en español."

Alternativamente, establece una instrucción a nivel de Proyecto (ve la sección de Proyectos arriba) para que cada conversación en ese proyecto use automáticamente tu idioma preferido.

Usa Claude para aprender, no solo para obtener respuestas

  • Pide explicaciones, no solo soluciones. En lugar de "¿Cuál es la respuesta a X?", prueba "¿Cómo abordarías la resolución de X? Guíame a través de tu razonamiento."
  • Pide a Claude que te examine. "Acabo de aprender sobre redes neuronales. ¿Puedes examinarme con 5 preguntas para probar mi comprensión?"
  • Solicita analogías. "Explica las integraciones de API usando una analogía de cocina de restaurante."
  • Construye ejercicios de práctica. "Crea 3 ejercicios de Python para principiantes sobre bucles, desde fácil hasta desafiante."

Errores comunes de principiantes a evitar

Evita estos errores comunes:
  • Asumir que Claude siempre tiene razón. Claude puede cometer errores o "alucinar" información. Siempre verifica los hechos importantes, especialmente para temas médicos, legales o financieros.
  • Compartir información sensible. No pegues contraseñas, claves API, números de Seguro Social u otros datos sensibles en Claude. Anthropic puede usar datos de conversación para mejorar modelos (dependiendo de tu configuración de privacidad).
  • Esperar datos en tiempo real. El conocimiento de Claude tiene una fecha límite y no navega por la web en tiempo real (a menos que una herramienta o integración específica esté habilitada). Para eventos actuales o datos en vivo, verifica con búsquedas web.
  • Rendirse después de un intento. Si la primera respuesta de Claude no es lo que querías, refina tu prompt e intenta de nuevo. La iteración es parte del proceso.

Siguientes pasos

¡Felicidades por aprender los conceptos básicos de Claude Desktop App! Aquí está lo que debes hacer a continuación:

  1. Practicar: Dedica 15–30 minutos a chatear con Claude sobre cualquier tema. Prueba el ejemplo de la calculadora Artifact arriba.
  2. Crear un Proyecto: Haz un proyecto para este manual con instrucciones personalizadas.
  3. Explorar: Prueba adjuntar un archivo (un documento de texto, un fragmento de código) y pide a Claude que lo resuma o lo explique.
  4. Pasar al Capítulo 3: Configura tu laboratorio de desarrollo para el trabajo multi-agente.
Mirando hacia adelante: En capítulos posteriores, usaremos Claude Desktop App como puerta de entrada a los sistemas multi-agente. Claude Desktop App se conectará a orquestadores de agentes, editores de código y otras herramientas que te permitirán experimentar el trabajo en equipo real de AI agent. Para los entusiastas de la línea de comandos, el Apéndice B cubre Claude Code CLI en detalle, y el Apéndice C explora backends de modelos locales de bajo costo.
