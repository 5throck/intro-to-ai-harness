Claude Desktop Appの使い始め方

このハンドブックの基本ツールであるClaude Desktop Appをインストールし、使い方を身につけましょう。Claude Desktop Appは、ターミナルコマンドを使わず、マウスクリックだけでAIと対話できる最も簡単な方法です。

本章で扱うこと
  • Claude Desktop Appの特徴と利点
  • MacOS、Windows、Linuxごとのインストール方法
  • サブスクリプションプラン選択ガイド
  • 最初の会話、プロジェクト、Artifacts機能の体験
  • 初心者のための実践ヒント

Claude Desktop Appとは

Claude Desktop Appは、Anthropicが開発したデスクトップ向けAIアシスタントです。ウェブブラウザを開く必要なく、コンピュータの画面上で直接Claude AIと対話できるアプリケーションです。メッセンジャーアプリを使うようにチャット欄に質問を入力すると、Claudeが回答を返してくれます。

Claude.aiウェブ版との違い

Claudeはウェブブラウザからも利用できます（claude.ai）。Claude Desktop Appには、ウェブ版にはない重要なメリットがいくつかあります：

  • ローカルファイルへのアクセス — コンピュータに保存されたファイルをClaudeが直接読み取って分析できます。例えばPDFドキュメント、コードファイル、テキストファイルをドラッグ＆ドロップで渡すと、Claudeが内容を理解して回答してくれます。
  • プロジェクト機能 — 関連する会話を一つのプロジェクトにまとめて管理できます。特定のテーマに合わせた設定を、プロジェクトごとに変えることもできます。
  • 安定性と速度 — 専用アプリとして動作するためブラウザのタブ管理が不要で、ネット接続が少し不安定でも会話の内容がしっかり保持されます。
  • ショートカットキー対応 — キーボードショートカットで素早く新しい会話を始めたり、過去の会話を呼び出したりできます。

Claude Code CLIとの違い

Claude Code CLIは、ターミナル（コマンド画面）で使うClaudeツールです。プログラマがコードを書いたり修正したりするときに、ファイルを直接操作できる強力な機能を提供します。ただしコマンドを入力する必要があるため、初心者には敷居が高い場合があります。

Claude Code CLIについては、このハンドブックの付録Bで詳しく扱います。CLI（Command Line Interface）とは、マウスの代わりにキーボードのコマンドでプログラムを操作する方式のことです。ターミナル画面（WindowsのPowerShell、MacOSのTerminalなど）でclaudeコマンドで実行します。

このハンドブックではClaude Desktop Appを基本ツールとして使用します。初心者でも簡単に始められて、Claudeの主要機能をすべて体験できるためです。上級者になったら、Claude Code CLI（付録B）に進めばOKです。

インストール方法

Claude Desktop AppはMacOS、Windows、Linuxの三つのオペレーティングシステムすべてに対応しています。お使いのコンピュータのOSに合ったインストール方法に従ってください。

システム要件

項目 最小スペック 推奨スペック
オペレーティングシステム macOS 12以上、Windows 10 64ビット、Ubuntu 20.04以上 macOS 14以上、Windows 11、Ubuntu 22.04以上
RAM（メモリ） 4GB 8GB以上
ディスク容量 500MB 1GB以上
インターネット 必須（Claudeはクラウドで動作します） 安定した帯域幅の接続
Claude Desktop Appを使うにはClaude ProまたはMaxのサブスクリプションが必要です。無料プラン（Free tier）ではClaude.aiのウェブ版しか使えず、Desktop Appへのログインは制限されます。登録方法は下記の「サブスクリプションプラン」セクションを参照してください。
MacOSへのインストール

MacOSでは、二つの方法でClaude Desktop Appをインストールできます。

方法1：App Storeからインストール（推奨）

  1. MacのApp Storeアプリを開きます。
  2. 検索欄にClaudeと入力します。
  3. "Anthropic Claude"アプリを見つけてダウンロードボタンを押します。
  4. インストールが完了したら、アプリケーションフォルダからClaudeを起動します。

方法2：ウェブサイトからダウンロード

  1. ブラウザでclaude.ai/downloadにアクセスします。
  2. "Download for Mac"ボタンをクリックします。
  3. ダウンロードした.dmgファイルを開き、Claudeアイコンをアプリケーションフォルダへドラッグします。
  4. 初回起動時に「このアプリケーションは開けません」というメッセージが表示されたら、システム環境設定 > セキュリティとプライバシーで「開く」を押してください。
Windowsへのインストール

Windowsでも、二つの方法でインストールできます。

方法1：ウェブサイトからダウンロード（推奨）

  1. ブラウザでclaude.ai/downloadにアクセスします。
  2. "Download for Windows"ボタンをクリックします。
  3. ダウンロードした.exeインストーラーを実行します。
  4. セットアップウィザードの案内に従って"Next"を押し、インストールを完了させます。
  5. デスクトップに作成されたClaudeショートカットをダブルクリックして起動します。

方法2：winget（Windowsパッケージマネージャー）を使う

コマンド画面（PowerShell）で次のコマンドを入力するとインストールできます：

winget install Anthropic.Claude

wingetはWindowsに内蔵されたパッケージマネージャーで、コマンド一行でプログラムをインストール／更新できるツールです。

Linuxへのインストール

Linux環境では、パッケージ形式に応じて二つのインストール方法があります。

方法1：.debパッケージ（Debian / Ubuntu）

# 1. ダウンロードページから .deb ファイルをダウンロードします
# claude.ai/download から Claude-linux.deb を入手します

# 2. ターミナルでインストールします
sudo dpkg -i Claude-linux.deb

# 3. 依存関係の問題が発生したら、次のコマンドで解決します
sudo apt-get install -f

方法2：.tar.gzアーカイブ（その他のLinux）

# 1. ダウンロードページから .tar.gz ファイルを入手します
# claude.ai/download から Claude-linux.tar.gz を受け取ります

# 2. 圧縮を展開します
tar xzf Claude-linux.tar.gz

# 3. Claudeバイナリを実行します
./claude
Linuxの.tar.gz方式は、Claudeバイナリを好きな場所に手動で配置する方法です。/opt/claudeのようなディレクトリに置いてPATHに追加すれば、ターミナルのどこからでも実行できます。

最初の会話を始める

Claude Desktop Appのインストールと登録が済んだら、いよいよClaudeとの会話を始めてみましょう。

Claude Desktop Appの起動

デスクトップまたはアプリケーションフォルダでClaudeアイコンをクリックしてアプリを起動します。初回起動時にはAnthropicアカウントでのログインを求められます。このハンドブックの第1章で作成したアカウント（または新しく作成したアカウント）でログインしてください。

画面構成要素

上のダイアグラムのように、Claude Desktop Appの画面は大きく三つの部分に分かれています：

  • サイドバー（左） — 過去の会話リストが表示されます。特定の会話をクリックすれば、その会話を続けることができます。下部の「+ 新しい会話」ボタンで新しい会話を始めます。
  • チャットエリア（中央） — Claudeとの会話が表示されます。自分が送ったメッセージとClaudeの回答が順番に現れます。
  • Artifactsパネル（右） — Claudeが生成したコード、ドキュメント、ダイアグラムなどを別枠で確認できるパネルです（詳しくは「Artifacts」セクションを参照）。

最初のメッセージを送る

チャットエリア下部にあるテキスト入力ボックスにメッセージを入力し、Enterキー（または送信ボタン）を押すと、Claudeが回答してくれます。次の例をそのまま入力してみてください：

次のメッセージをClaudeに送ってみましょう：
こんにちは、私はAIを学び始めたばかりの初心者です。AIエージェントチームが何か、やさしく説明してください

Claudeは、AIエージェントチームが何であるかを初心者にも理解できる平易な言葉で説明してくれるでしょう。回答を読んで、気になる点があれば追加の質問をしてみてください。例えば：

  • "では、AIエージェントチームは会社の部署のようなものですか？"
  • "初心者でもAIエージェントチームを作れますか？"
  • "このハンドブックでは何が学べますか？"

Claudeとの会話は以前の会話の文脈を記憶します。そのため、フォローアップの質問をするときに前の内容を繰り返す必要はありません。人と会話するように、自然に続ければ大丈夫です。

プロジェクト機能

プロジェクトとは？

プロジェクト（Project）は、Claude Desktop Appで関連する会話をひとまとめに管理できる機能です。通常の会話では、Claudeは前の会話の内容をある程度までしか覚えていませんが、プロジェクトを使うと、そのプロジェクトのすべての会話が一つのコンテキスト（文脈）として維持・管理されます。

例えば、「AI学習」というテーマでClaudeと会話しながら数日かけて質問と回答を重ねるとき、毎回新しい会話を始めると、Claudeは前に学んだ内容を忘れてしまうことがあります。しかしプロジェクトに入れておけば、Claudeはそのプロジェクトのすべての会話を参照して、一貫性のある回答をしてくれます。

プロジェクトの主な機能

  • プロジェクトナレッジ（Project Knowledge） — プロジェクトに関連ファイル（PDF、コード、テキスト）を添付すると、Claudeがそのファイルの内容に基づいて回答します。例えば講義資料のPDFを添付すれば、Claudeがその資料を読んで質問に答えてくれます。
  • カスタム指示（Custom Instructions） — プロジェクトごとにClaudeへの指示を設定できます。例：「常に日本語でお答えください」「初心者向けの説明をしてください」「回答は3文以内で短くしてください」。
  • 会話のグループ化 — 一つのプロジェクトの中で複数の会話を作れます。各会話はプロジェクトのコンテキストを共有します。

実践：「AI学習」プロジェクトを作る

プロジェクトを作成 — Claude Desktop Appのサイドバー上部にある「+ 新しい会話」ボタンの横のアイコンをクリックし、"Create Project"を選択します。
プロジェクト名を設定 — プロジェクト名を「AI学習」と入力します。説明欄には「AIエージェントチームとClaudeの使い方を学ぶプロジェクト」と書いてもOKです。
カスタム指示を入力 — Custom Instructions欄に次のように入力します： 
日本語でお答えください。
初心者向けのわかりやすい説明をお願いします。
知らない用語が出てきたら、必ず説明してください。
プロジェクトにファイルを追加（任意） — このハンドブックの前半部分（PDFなど）をダウンロードしていれば、"Add files"ボタンを押してプロジェクトに追加できます。ファイルを追加すると、Claudeがそのファイルの内容を参考にしてくれます。
最初の会話を始める — プロジェクト内で新しい会話を始めて、次のメッセージを送ってみましょう： 
このプロジェクトで、Claude Desktop Appと
AIエージェントチームについて学びたいです。
何から学ぶのが良いでしょうか？

このようにプロジェクトを作っておけば、以降の章で学ぶ質問をすべてこのプロジェクトの中で続けられます。Claudeは過去の会話をもとに、より深い回答を提供してくれるでしょう。

Artifacts（アーティファクト）

Artifactsとは？

Artifacts（アーティファクト）は、Claudeが会話の中で生成したコード、ドキュメント、可視化資料などを、会話ウィンドウの外側にある専用パネルに表示してくれる機能です。通常の会話でClaudeがコードを書くと会話欄の中にテキストとして表示されますが、Artifactsを使えば独立したパネルでコードを見て、実際に実行してみることができます。

例えば、Claudeに「簡単な計算機Webページを作って」と頼むと、ClaudeがHTML、CSS、JavaScriptのコードを書きます。Artifactsが有効になると、このコードは：

  • 会話欄の横にあるArtifactsパネルに表示されます
  • コードプレビューで、Webページが実際にどう見えるかを確認できます
  • コードをコピーしてファイルとして保存できます

Artifactsを使ってみよう

Claudeに次のように依頼してみてください：

Artifacts機能を体験したいときは、次のメッセージを送りましょう：
簡単な計算機Webページを作成してください。足し算、引き算、掛け算、割り算の機能があれば大丈夫です。

Claudeがコードを書くと、画面の右側にArtifactsパネルが開き、計算機Webページのリアルタイムプレビューが表示されます。プレビュー画面で、実際にボタンを押して計算を試せます。

Artifactsでできること

種類 説明 例
コード（Code） HTML、CSS、JavaScript、Pythonなどのプログラミングコード Webページ、計算機、アニメーション
ドキュメント（Document） 構造化されたテキスト文書（Markdown形式） 要約文、分析レポート、チェックリスト
Reactコンポーネント インタラクティブなUI要素（Reactで記述） チャート、クイズ、インタラクティブフォーム
SVG可視化 ベクターグラフィックスのダイアグラム フローチャート、構造図、チャート
Artifactsで生成されたコードはすぐに実行して試せるので、コーディングを学ぶときにとても便利です。「このコードのこの部分は何ですか？」と聞けば、コードの各部分がどんな役割を果たしているのか詳しく説明してくれます。修正をお願いすればClaudeが即座に修正し、プレビューに反映されます。

初心者のためのヒント

Claude Desktop Appをもっと効果的に使うための、実用的なヒントを紹介します。

良いプロンプトの書き方

プロンプト（Prompt）とは、Claudeに送るメッセージ、つまり質問や依頼のことです。良いプロンプトを書くと、Claudeの回答品質が大きく向上します。

今ひとつなプロンプト

  • "AIについて教えて"
  • "コードを書いて"
  • "これ、どうやるの？"

良いプロンプト

  • "AIエージェントチームとは何か、初心者にもわかるように3文で説明して"
  • "Pythonで簡単なToDoリスト（to-do list）プログラムを書いて。追加、削除、一覧表示の機能が必要"
  • "Claude Desktop Appでプロジェクトを作る方法を、ステップごとに教えて"

良いプロンプトの鍵は、具体的かつ明確に依頼することです：

  • 背景の説明 — 「私は初心者です」「プログラミング経験がありません」のように、自分のレベルを伝えましょう
  • 明確な目標 — どんな結果が欲しいのか、具体的に伝えましょう
  • 形式の指定 — 「3文で」「段階的に」「表形式で」のように、希望する回答の形を伝えましょう
  • 例示 — 欲しい結果の例を見せると、Claudeはより正確に理解します

会話を分けて進める

複雑な依頼は、一度に全部聞くのではなく段階的に分けて質問しましょう。Claudeとの会話は前の文脈を記憶しているので、小さな単位に分けても全体の文脈は保たれます。

例：AIエージェントチームを学ぶとき
1回目："AIエージェントチームが何か、簡単に説明して"
2回目："じゃあ、エージェント一つが担当する役割にはどんなものがあるの？"
3回目："初心者でもエージェントチームは組める？どう始めればいい？"
4回目："Claude Desktop Appでエージェントチームを構成する例を見せて"

日本語設定

Claudeは日本語を含むさまざまな言語に対応しています。会話の序盤で次のように設定しておけば、Claudeは常に日本語で答えてくれます：

会話を始めるときに、次のように設定しておきましょう：
今後のすべての会話は、日本語でお答えください。

または、プロジェクトのCustom Instructionsに「日本語でお答えください」と書いておけば（前述の「プロジェクト機能」セクションを参照）、いちいち伝える必要がありません。

Claude Code CLIへ進む

Claude Desktop Appに慣れてきて、ターミナル環境でさらに強力な機能が必要になったら、Claude Code CLIを使ってみましょう。Claude Code CLIではClaudeが直接ファイルを生成・修正・実行できるため、プログラミング作業がぐっと効率的になります。

Claude Code CLIのインストールと使い方は、このハンドブックの付録Bを参照してください。Claude Desktop Appで基礎を十分に身につけてから、付録Bを読むことをおすすめします。

ローカルモデルによる低コストバックエンド

Claude Proのサブスクリプション以外にも、ローカルコンピュータで動くAIモデルを使えば、追加の料金をかけずにAIを活用できます。OllamaやLM Studioのようなツールを使えば、コンピュータに直接AIモデルをインストールして、Claudeのように会話できます。

ローカルモデルバックエンドのインストールと活用法は、このハンドブックの付録Cを参照してください。Claude Desktop Appとローカルモデルを併用すれば、コストを抑えながら強力なAI環境を構築できます。

その他の便利なヒント

  • 会話のエクスポート — 重要な会話は、Claude Desktop Appのメニューからエクスポート（Export）機能でテキストファイルとして保存できます。学習ノートとして活用しましょう。
  • ショートカットキー — Ctrl+N（Windows）またはCmd+N（MacOS）で新しい会話を始められます。Ctrl+Shift+Nで新しいプロジェクトを作成できます。
  • 回答の再生成 — Claudeの回答が気に入らなければ、回答下部の"Regenerate"ボタンを押して別の回答を受け取れます。
  • 会話の分岐 — 特定の回答で"Edit message"を使って自分の質問を修正すると、Claudeが修正後の質問に合わせて新しい回答分岐を作ります。これで一つの会話から複数の方向へ探索できます。
Claudeに「私が今した質問や依頼が曖昧だったとしたら、どう直せばいいか教えて」と聞いてみましょう。Claude自身が、どんな情報が足りないのか、質問をどう磨けばいいのか助言してくれます。これだけでプロンプト作成スキルが大きく向上します。
