Claude Desktop Appの使い始め方

Claude Desktop Appをインストールして使い方を学びましょう — このハンドブックの主要ツールです。Claude Desktop Appは、ターミナルコマンドを使わず、マウスクリックだけでAIとチャットできる最も簡単な方法です。

本章の内容
  • Claude Desktop Appの機能と利点
  • MacOS、Windows、Linuxへのインストール
  • サブスクリプションプラン選択ガイド
  • 最初の会話、プロジェクト、アーティファクト
  • 初心者向けの実践的なヒント

Claude Desktop Appとは

Claude Desktop Appは、Claude AIモデルを開発したAnthropic社が構築した専用デスクトップアプリケーションです。ウェブブラウザを開くことなく、Claudeと会話したり、ローカルファイルを添付したり、プロジェクトを管理したり、アーティファクトのような高度な機能を使用できるネイティブなスタンドアロンウィンドウを提供します。

このハンドブック全体を通じて、Claude Desktop AppはAIとの対話のための主要なインターフェースとして機能します。後でマルチエージェントチームやコマンドラインツールを探索する際でも、Desktop Appは日常的なAI会話のための基本的な環境として機能し続けます。

Claudeを利用する3つの方法

AnthropicはClaudeとやり取りするための複数の方法を提供しています。違いを理解することで、各状況に適したツールを選択できます。

図2-1：3つのClaudeインターフェースの比較。Claude Desktop App（中央）はこのハンドブック全体で使用する主要ツールです。

なぜウェブ版ではなくClaude Desktop Appなのか？

Claude.ai（ウェブ）

  • 任意のブラウザからアクセス可能
  • インストール不要
  • 手動でアップロードしたファイルのみ読み取り可能
  • プロジェクトレベルのカスタム指示がない
  • ページリロードでセッションがリセット

Claude Desktop App

  • ネイティブアプリケーションとして動作
  • コンピュータ上のファイルやフォルダを読み取り可能
  • プロジェクトレベルのコンテキストとカスタム指示をサポート
  • より安定した接続と速いレスポンス
  • 永続的な会話履歴
Claude Code CLIは、AIにコマンドラインから直接コードの読み取り、編集、実行させたい開発者向けのターミナルベースツールです。付録Bで説明しています。ほとんどの初心者には、Claude Desktop Appが推奨される出発点です。

インストール

Claude Desktop AppはMacOS、Windows、Linuxで利用可能です。以下のオペレーティングシステムごとの手順に従ってください。

MacOS
  1. MacでApp Storeを開き、「Claude」を検索するか、ブラウザで claude.ai/download にアクセスしてください。
  2. Get（App Store）またはDownload for Mac（ウェブサイト）をクリックしてインストーラーをダウンロードします。
  3. ダウンロードした.dmgファイルを開き、Claudeをアプリケーションフォルダにドラッグします。
  4. アプリケーションフォルダまたはSpotlight（Cmd + Space、「Claude」と入力）からClaudeを起動します。

対応：MacOS 12（Monterey）以降。Apple Silicon（M1/M2/M3/M4）とIntel Macの両方に対応。

Windows
  1. ブラウザで claude.ai/download にアクセスするか、ターミナルからwingetを使用します：
winget install Anthropic.Claude
  1. ダウンロードした.exeインストーラーを実行し、画面の指示に従います。
  2. スタートメニューまたはデスクトップショートカットからClaudeを起動します。

対応：Windows 10（64ビット）以降。

Linux

AnthropicはDebian/Ubuntu系ディストリビューション向けのパッケージを提供しています。その他のディストリビューションでは、汎用の.tar.gzアーカイブが利用可能です。

Debian / Ubuntu (.deb):

# 最新の.debパッケージをダウンロード
wget https://claude.ai/download/linux/deb -O claude-desktop.deb

# インストール
sudo dpkg -i claude-desktop.deb

# 不足している依存関係を修正
sudo apt-get install -f

汎用Linux (.tar.gz):

# ダウンロードして展開
tar -xzf claude-desktop-linux.tar.gz

# 実行
./claude-desktop

対応：Ubuntu 20.04+ / Debian 11+（64ビット）。その他のディストリビューションはtar.gzビルドで動作する場合があります。

最初の会話を始める

Claude Desktop Appがインストールされ、Anthropicアカウントでログインすると、メインの会話画面が表示されます。画面に表示される内容を見ていき、最初のチャットを始めましょう。

図2-2：Claude Desktop Appの画面レイアウト。サイドバー（左）には最近のチャットとプロジェクトが表示され、チャットエリア（中央）で会話を行い、アーティファクトパネル（右）にはコードやドキュメントなどの生成されたコンテンツが表示されます。

インターフェースの理解

  • サイドバー（左） — 最近の会話とプロジェクトを表示します。+ 新しいチャットをクリックして新しい会話を開始します。
  • チャットエリア（中央） — Claudeとの会話が表示される場所です。あなたのメッセージが片側に、Claudeの応答がもう片側に表示されます。
  • アーティファクトパネル（右） — Claudeがコード、ドキュメント、視覚コンテンツを生成すると、別のパネルに表示されます。このパネルは展開・折りたたみが可能です。
  • 入力バー（下部） — ここにメッセージを入力し、Enterキー（または送信ボタン）を押してClaudeに送信します。クリップアイコンをクリックしてファイルを添付することもできます。

最初の会話を試す

新しいチャットを開始し、以下の初心者向けプロンプトを試してみてください：

会話のスターター例
"こんにちは！ClaudeもAIも初心者です。あなたがどんなことを手伝ってくれるか、簡単に説明してもらえますか？"
仕事と生産性向け
"会議の招待を丁寧に断るプロフェッショナルなメールを書いてください。その会議は、もう関わっていないプロジェクトのものです。"
学習向け
"機械学習とディープラーニングの違いを説明してください。技術的なバックグラウンドがない人にもわかるような簡単な例えを使ってください。"
Claudeは単一会話内のコンテキストを記憶します。フォローアップの質問をすると、Claudeは同じチャットで以前に議論した内容を覚えています。ただし、各新しいチャットは白紙から始まります — プロジェクト機能を使用しない限り、Claudeは以前の会話の情報を引き継ぎません（次のセクションを参照）。

プロジェクト機能

プロジェクトはClaude Desktop Appで最も強力な機能の一つです。プロジェクトを使うと、関連する会話をグループ化し、Claudeにそのプロジェクト内のすべてのチャットで永続的なカスタム指示とコンテキストファイルを提供できます。

プロジェクトでできること

  • カスタム指示 — Claudeがこのプロジェクトでどのように応答すべきかを定義します（例：「常に韓国語で応答する」「あなたはコーディングのチューター」「初心者レベルの説明を心がける」）。
  • コンテキストファイル — Claudeがこのプロジェクトで質問に答える際に自動的に参照できる参照ドキュメント、コードファイル、メモをアップロードします。
  • 整理された会話 — 特定のトピックやタスクに関連するすべてのチャットを一つの場所にまとめます。

プロジェクトの作成

プロジェクトパネルを開く — Claude Desktop Appのサイドバーでプロジェクトセクションを見つけ、プロジェクトを作成ボタン（またはプロジェクト横の+アイコン）をクリックします。
プロジェクトに名前をつける — 明確で説明的な名前を付けます。例："AI学習ノート"、"作業レポート"、"コーディング練習"。
カスタム指示を書く — プロジェクト指示テキストボックスに、Claudeがこのプロジェクトでどのように動作すべきかの簡単な説明を書きます。例：
"あなたはAI初心者のための役立つチューターです。概念を簡単に説明し、例えを使い、常に例を提供してください。コードを表示する場合は、各行を説明してください。"
コンテキストファイルを追加（任意） — ファイルを追加をクリックして、Claudeが参照すべきドキュメント、テキストファイル、コードをアップロードします。プランのファイル制限まで追加できます。
チャットを開始 — 作成をクリックして完了します。このプロジェクト内で開始する新しい会話はすべて、自動的にカスタム指示を使用し、コンテキストファイルにアクセスできます。
プロのヒント：このハンドブックを進めるための専用プロジェクトを作成しましょう。"AIハンドブック学習"のような名前を付け、カスタム指示を追加します："あなたはClaude Desktop AppとマルチエージェントAIシステムについて学ぶのを手伝う学習アシスタントです。ハンドブックの概念を参照し、ステップバイステップで説明してください。"

アーティファクト

アーティファクトはClaudeのユニークな機能で、ウェブページ、ドキュメント、コード、図解、インタラクティブツールなどのスタンドアロンのコンテンツを生成し、会話の横にある専用パネルに表示できます。

ウェブページをテキストで説明するだけでなく、Claudeは実際のページを構築して、Claude Desktop App内であなたに直接表示できます。結果を即座に確認し、テストし、改良し、コードをコピーすることもできます。

アーティファクトで作成できるもの

  • ウェブページ — HTML/CSS/JSミニアプリ（計算機、クイズ、ダッシュボード）
  • ドキュメント — 構造化されたフォーマットテキスト（レポート、手紙、ガイド）
  • コード — コピー機能付きのシンタックスハイライトされたコードスニペット
  • 図解 — SVGフローチャート、アーキテクチャ図、視覚的な説明
  • インタラクティブツール — ボタン、フォーム、ロジックを備えた動作するプロトタイプ

例：シンプルな計算機を作成する

Claude Desktop Appでこのプロンプトを試してみてください：

アーティファクトプロンプト
"シンプルな計算機ウェブページを作ってください。数字0〜9のボタン、基本的な演算（+、-、×、÷）、現在の入力と結果を表示するディスプレイ、クリアボタンを備えてください。クリーンでモダンなデザインでスタイリングしてください。"

Claudeは計算機をアーティファクトとして生成します。画面右側のアーティファクトパネルに表示されるはずです。以下のことができます：

  • 使う — ボタンをクリックしてパネル内で直接計算機をテストします。
  • コードをコピー — コードアイコンをクリックして完全なHTML/CSS/JSソースを表示・コピーします。
  • 改良する — Claudeに変更を依頼します：「パーセンテージボタンを追加して」「背景色を薄い青に変更して」。
  • ダウンロード — コードをコピーして.htmlファイルとして保存し、任意のブラウザで開きます。
アーティファクトはインタラクティブにコードを学ぶのに最適な方法です。Claudeにステップバイステップで何かを構築してもらってください — シンプルなバージョンから始め、機能を一つずつ追加します。各変更が結果にどう影響するかを見ることで学べます。この「構築して改良する」アプローチは、教科書でコードを読むよりもはるかに効果的です。ToDoリストアプリ、クイズ、シンプルなゲームの作成に挑戦してみてください！

図2-3：アーティファクトのワークフローループ。あなたが求めるものを説明し、Claudeがライブアーティファクトとして生成し、あなたが確認して、満足するまで変更を依頼します。

初心者のためのヒント

Claudeから良い結果を得ることは、練習で上達するスキルです。最初の日からより効果的にコミュニケーションするための実践的なヒントをいくつか紹介します。

明確なプロンプトを書く

Claudeの応答の品質は、リクエストの表現方法に大きく依存します。いくつかの原則を以下に示します：

原則 これではなく... これを試してください
具体的にする "メールを手伝って" "来週の金曜日に個人の用事で休みを取るよう、マネージャーに丁寧に依頼するメールを書いてください"
コンテキストを提供 "Pythonを説明して" "プログラミング経験が全くない完全な初心者です。Pythonとは何か、何に使われるのかを説明してください。"
フォーマットを指定 "この記事を要約して" "この記事を3つの箇条書きで要約してください。各箇条書きは20語以内"
例を与える "レシピを書いて" "初心者向けのイタリア料理の本に載っているような、シンプルなパスタ料理のレシピを書いてください"

複雑なリクエストを分割する

複雑なタスクがある場合、すべてを一つの巨大なプロンプトに詰め込まないでください。代わりに、小さな連続したステップに分割してください。Claudeは過負荷のリクエストよりも、集中したリクエストをうまく処理できます。

過負荷なプロンプト

"コーヒーショップの10ページのビジネスプランを作成してください。市場分析、3年間の財務予測、マーケティング戦略、競合分析、日常業務スケジュールを含めること。"

ステップバイステップのアプローチ

ステップ1："コーヒーショップを開きたいと思います。チェーン店と差別化できる5つの独自のセールスポイントをブレインストーミングしてください。"

ステップ2："それらのセールスポイントに基づいて、市場分析のアウトラインを作成してください。"

ステップ3："次に、シンプルな3年間の売上予測を作成してください。"

Claudeを検索エンジンではなく、知識豊富な同僚だと思ってください。単一のクエリを投げるのではなく、会話を持ちましょう。広く始めてから、フォローアップの質問で具体的な点に掘り下げていきます。

言語設定をする

Claudeは多くの言語で動作します。特定の言語で応答を希望する場合は、会話の最初にClaudeに伝えてください：

言語設定プロンプト
"これからは、すべてのメッセージを日本語で応答してください。英語の内容について尋ねた場合は、日本語で説明してください。"

または、プロジェクトレベルの指示を設定すると（上記のプロジェクトセクションを参照）、そのプロジェクトのすべての会話で自動的に希望の言語が使用されます。

学習にClaudeを使う

  • 解決策だけでなく説明を求める。「Xの答えは何？」ではなく、「Xを解決するにはどうアプローチしますか？推論のプロセスを説明してください」と試してみてください。
  • Claudeにクイズを出させる。 "ニューラルネットワークについて学びました。理解度をテストするために5つの質問を出してください。"
  • 例えを求める。 "レストランのキッチンの例えを使ってAPI統合を説明してください。"
  • 練習問題を作る。 "ループに関する初心者向けのPython練習問題を3つ作成してください。簡単なものから難しいものへ。"

初心者が避けるべきよくある間違い

これらのよくある落とし穴を避けてください：
  • Claudeが常に正しいと想定する。 Claudeは間違いをしたり、情報を「ハルシネーション」することがあります。重要な事実は常に確認してください。特に医療、法律、金融のトピックについては。
  • 機密情報を共有する。 パスワード、APIキー、社会保障番号、その他の機密データをClaudeに貼り付けないでください。Anthropicは会話データをモデルの改善に使用する場合があります（プライバシー設定に依存）。
  • リアルタイムデータを期待する。 Claudeの知識にはカットオフ日があり、リアルタイムでウェブを閲覧しません（特定のツールや統合が有効でない限り）。最新のイベントやライブデータについては、ウェブ検索で確認してください。
  • 一度試して諦める。 Claudeの最初の応答が希望通りでなかった場合、プロンプトを改良してもう一度試してください。反復はプロセスの一部です。

次のステップ

Claude Desktop Appの基本を学習おめでとうございます！次にすることは以下の通りです：

  1. 練習： 15〜30分間、任意のトピックについてClaudeとチャットしてください。上の計算機アーティファクトの例を試してみてください。
  2. プロジェクトを作成： カスタム指示を設定して、このハンドブック用のプロジェクトを作成してください。
  3. 探索： ファイル（テキストドキュメントやコードスニペット）を添付して、Claudeに要約や説明を依頼してみてください。
  4. 第3章へ進む： マルチエージェント作業のための開発ラボをセットアップします。
今後の展望：後の章では、Claude Desktop Appをマルチエージェントシステムへのゲートウェイとして使用します。Claude Desktop Appはエージェントオーケストレーター、コードエディター、その他のツールに接続し、実際のAIエージェントチームワークを体験できます。コマンドライン愛好家向けには、付録BでClaude Code CLIの詳細を、付録Cで低コストのローカルモデルバックエンドを説明しています。
