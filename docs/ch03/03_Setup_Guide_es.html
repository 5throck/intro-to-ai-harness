Capítulo 3

Configurando tu laboratorio

To use sistema multi-agentes like co-consult and co-deck, you need a few additional tools. Este capítulo te guía a través de installing everything at once and verifying it works.

Lo que cubre este capítulo
  • Pre-flight checklist (subscriptions, accounts, system requirements)
  • Preparing the C:\git\project\setup folder
  • OS-specific installation (MacOS, Windows, Linux)
  • Verification and troubleshooting

Lista de verificación previa al vuelo

Antes de instalar cualquier cosa, asegúrate de que los siguientes elementos estén listos. Todos ellos son requeridos para usar el harness multi-agente.

Required Subscriptions

The harness multi-agente is built on Claude Code, and using Claude Code requires a Claude Pro or Claude Max subscription.

Item Descripción Cómo verificar
Claude Pro / Max Subscription Paid subscription for Claude Desktop App and Claude Code Check at claude.ai/subscribe
GitHub Account Requerido para acceder a repositorios de código abierto y usar GitHub CLI Sign up at github.com (free)
Anthropic Account Required for Claude Desktop App login and Claude Code authentication Sign up at claude.ai
Una cuenta gratuita de Claude no funcionará con Claude Desktop App. Necesitas una suscripción Pro. Si aún no estás suscrito, regístrate para Claude Pro ($20/mes) en claude.ai/subscribe.

Requisitos del sistema

Para ejecutar el harness multi-agente, tu computadora debe cumplir con las siguientes especificaciones mínimas.

Componente Mínimo Recomendado
RAM (Memory) 8 GB 16 GB or more
Free Disk Space 10 GB 20 GB or more
Internet Connection Stable broadband 5 Mbps or more
Operating System Windows 10, macOS 12, Ubuntu 20.04 Latest version recommended

8 GB de RAM es la memoria mínima necesaria para ejecutar Claude Desktop App junto con otras herramientas (Git, Bun, etc.). Si planeas ejecutar múltiples agentes simultáneamente o mantener un navegador abierto, se recomienda 16 GB o más.

10 GB de espacio en disco proporciona espacio para las instalaciones de herramientas y los archivos del proyecto. Si planeas trabajar en múltiples proyectos, es posible que necesites más espacio con el tiempo.

If you are using a remote access environment (e.g., cloud desktop, SSH server), see Apéndice A: Configuración de entorno de acceso remoto.

Configurando la carpeta

Crearemos una carpeta dedicada para almacenar los scripts y archivos de configuración utilizados durante la instalación. Esta carpeta servirá como base principal para todos los futuros ejercicios prácticos.

Creating the Folder

Ejecuta el comando a continuación para tu sistema operativo. La carpeta setup debe crearse en el directorio donde almacenas tus proyectos de Git.

Windows
mkdir C:\git\project\setup
MacOS / Linux
mkdir -p ~/git/project/setup

This folder will store installation verification scripts, configuration files, and project templates going forward. You can change the folder location at any time, but este manual uses the paths above as the reference standard.

Folder Structure

The setup folder will have the following structure. Right now it is empty, but each item will be populated as you progress through the installation.

Avoid spaces or non-English characters in folder paths. Paths like C:\My Documents\project can cause errors with some tools. Stick to English-only paths like C:\git\project or ~/git/project to stay safe.

Instalación en MacOS

On MacOS, Homebrew makes it easy to install all the required tools. Homebrew is the most widely used open-source package manager for MacOS.

Check if Homebrew is installed — Open Terminal.app and run the following command. 
brew --version
If a version number appears, Homebrew is already installed — skip to the next step.
If you see command not found, you need to install Homebrew first.
Install Homebrew (only if needed) — Run the official installation script from Homebrew's website. Copy and paste this command into your terminal. 
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
Once installation completes, close and reopen the terminal.
Install Git — Git is a version control system. It tracks changes to your code and integrates with GitHub for project management. Git is a foundational tool for Claude Code and the sistema multi-agente. 
brew install git
Install GitHub CLI — GitHub CLI (gh) lets you use GitHub directly from the terminal. Claude Code uses it to create and manage GitHub repositories. 
brew install gh
Install Bun — Bun is a JavaScript/TypeScript runtime. It serves as an alternative to Node.js and is required to run the harness multi-agente's automation scripts and configuration validation tools. It is known for being fast and easy to install. 
brew install oven-sh/bun/bun
Authenticate GitHub CLI — Link your GitHub account to gh. This step is required before Claude Code can use GitHub features. 
gh auth login
Follow the prompts to select GitHub.com. When your browser opens, log in with your GitHub account to complete authentication.
Claude Desktop App is assumed to be already installed from Capítulo 2. If you have not installed it yet, complete Capítulo 2 first.

Instalación en Windows

On Windows, each tool is installed individually. Use PowerShell or Command Prompt (CMD) to proceed.

On Windows, you may need to run PowerShell as an administrator. Right-click PowerShell in the Start Menu and select "Run as Administrator".
Install Git for Windows — Git is a version control system, essential for Claude Code and GitHub integration.

Option 1: Install with winget (Windows 10+) 
winget install --id Git.Git -e --source winget
Option 2: Download directly
Download the installer from git-scm.com/download/win and run it. Default installation options are fine.
Install GitHub CLI — This tool lets you use GitHub from the terminal.

Option 1: Install with winget 
winget install --id GitHub.cli -e --source winget
Option 2: Download directly
Download the Windows installer from cli.github.com.
Install Bun — Run the following command in PowerShell to install Bun. 
powershell -c "irm bun.sh/install.ps1 | iex"
After installation, you must restart PowerShell for the bun command to be recognized.
Authenticate GitHub CLI — Link your GitHub account to gh. 
gh auth login
Follow the prompts to select GitHub.com. When your browser opens, log in with your GitHub account to complete authentication.
Windows-Specific Tips
  • PowerShell vs CMD: Claude Code and Bun run more reliably in PowerShell. We recommend setting PowerShell as your default terminal.
  • Environment Variable PATH: If a command is not recognized after installation, restart the terminal. If the problem persists, verify that the installation path was added to the system PATH environment variable.
  • Git Bash: Installing Git for Windows also installs Git Bash, a terminal that provides a Linux/Mac-like command environment. If you are comfortable with it, feel free to use Git Bash instead.

Instalación en Linux

On Linux (Ubuntu/Debian-based), use the apt package manager and official installation scripts.

For other Linux distributions (Fedora, Arch, etc.), adjust the package manager commands accordingly. For example, use dnf on Fedora or pacman on Arch.
Update system packages — Before installing anything, update your system packages to the latest versions. 
sudo apt update && sudo apt upgrade -y
Install Git — Git is pre-installed on most Ubuntu/Debian systems, but verify and install if needed. 
sudo apt install -y git
Install GitHub CLI — Add the official GitHub repository and install gh. 
(type -p wget >/dev/null || (sudo apt update && sudo apt-get install wget -y)) \
&& sudo mkdir -p -m 755 /etc/apt/keyrings \
&& out=$(mktemp) && wget -nv -O$out https://cli.github.com/packages/githubcli-archive-keyring.gpg \
&& cat $out | sudo tee /etc/apt/keyrings/githubcli-archive-keyring.gpg > /dev/null \
&& sudo chmod go+r /etc/apt/keyrings/githubcli-archive-keyring.gpg \
&& echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/githubcli-archive-keyring.gpg] https://cli.github.com/packages stable main" | sudo tee /etc/apt/sources.list.d/github-cli.list > /dev/null \
&& sudo apt update \
&& sudo apt install gh -y
Install Bun — Use the official installation script to install Bun. 
curl -fsSL https://bun.sh/install | bash
After installation completes, restart the terminal or apply the PATH update with: 
source ~/.bashrc
Authenticate GitHub CLI — Link your GitHub account to gh. 
gh auth login
Follow the prompts to select GitHub.com. When your browser opens, log in with your GitHub account to complete authentication.

Verificación de instalación

Now let's confirm that all tools were installed correctly. Open a terminal and run the following commands in order.

Version Check

Verify that each tool displays a version number. If a version number appears, the installation was successful.

git --version

Expected result: git version 2.45.0 (version number may vary)

gh --version

Expected result: gh version 2.62.0 (version number may vary)

bun --version

Expected result: 1.1.30 (version number may vary)

Run the Verification Script

The verification script in the setup folder checks the installation status of all tools at once.

git clone https://github.com/5throck/setup.git
cd setup
bun setup-common.ts       # Run the installation verification script

El script de verificación comprueba si Git, GitHub CLI y Bun están instalados, muestra sus versiones y verifica tu estado de autenticación de GitHub.

Sample Verification Results

Cuando todas las herramientas estén instaladas correctamente, verás una salida como esta:

Verification Checklist
  • Does git --version display a version number?
  • Does gh --version display a version number?
  • Does bun --version display a version number?
  • Does gh auth status show your logged-in account?
Si todos los elementos están verificados, ¡tu instalación está completa!

Solución de problemas

Aquí están los problemas de instalación más comunes y sus soluciones. Si algo sale mal, busca tu problema en la siguiente lista.

Bun Installation Failed: command not found: bun

Causa: Bun se instaló, pero es posible que no haya sido añadido a la variable PATH del sistema.

Solución:

Close the terminal completely and reopen it.
Si bun todavía no es reconocido, añade manualmente la ruta de instalación de Bun a PATH.
MacOS / Linux
echo 'export PATH="$HOME/.bun/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
Windows (PowerShell)
$env:Path += ";$env:USERPROFILE\.bun\bin"
To apply this permanently, add %USERPROFILE%\.bun\bin to the PATH variable in the System Environment Variables editor.

GitHub CLI Authentication Error: gh auth status fails

Cause: The GitHub CLI browser authentication did not complete, or the authentication token has expired.

Solución:

Re-run the authentication process from the beginning. 
gh auth logout
gh auth login
After running gh auth login, select the following options:
  • What account? → GitHub.com
  • Preferred protocol? → HTTPS
  • Authenticate Git? → Yes
Si el navegador no se abre automáticamente, copia el código único que aparece en la terminal e introdúcelo manualmente en github.com/login/device.

Claude Desktop Ap Connection Error

Cause: Internet connectivity issues, Anthropic server outage, or an expired authentication token.

Solución:

Verifica que tu conexión a internet esté funcionando. Intenta visitar otro sitio web (por ejemplo, claude.ai) en tu navegador.
Cierra la sesión de Claude Desktop App y vuelve a iniciarla. Desde el menú, selecciona File → Sign Out y luego inicia sesión nuevamente con tu cuenta de Anthropic.
Cierra Claude Desktop App por completo y vuelve a ejecutarlo. En MacOS, presiona Cmd+Q. En Windows, haz clic derecho en el icono de la bandeja del sistema y selecciona Quit.
Si el problema persiste, consulta la página de estado de Anthropic en status.anthropic.com para ver si hay una interrupción del servicio conocida.

Git Installed but git Command Not Recognized

Causa: Git se instaló, pero su ruta no fue añadida a la variable PATH del sistema.

Solución:

Windows: Verifica que la ruta de instalación de Git (generalmente C:\Program Files\Git\cmd) esté incluida en la variable de entorno PATH del sistema. Busca "environment variables" en la barra de búsqueda de Windows y abre "Edit the system environment variables".
MacOS / Linux: Reinicia la terminal. Si el problema persiste, verifica el PATH con: 
echo $PATH
Check whether the Git installation path (usually /usr/local/bin or /usr/bin) is included.

Other Issues

Síntoma Causa posible Solución
brew command errors Homebrew installation is corrupted Run brew doctor and follow the instructions
winget command not found Windows App Installer not installed Install "App Installer" from Microsoft Store
Script execution errors Bun version is outdated Run bun upgrade
Network timeout Firewall or proxy blocking Contact your network administrator to check proxy settings
If you need a remote access environment (SSH, cloud desktop, WSL, etc.), see Apéndice A: Configuración de entorno de acceso remoto. Installation instructions for WSL (Windows Subsystem for Linux) are also included in that appendix.
