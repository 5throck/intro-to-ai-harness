실습에서 만든 결과물을 일관되고 이해하기 쉽게 다듬는 디자인 원칙을 배웁니다.

디자인은 왜 시스템인가

색·글꼴·간격·컴포넌트를 매번 새로 정하면 결과가 흔들립니다. 공통 규칙은 사람과 AI가 같은 기준으로 결과를 만들게 합니다.

핵심 원칙

일관성, 정보 위계, 접근성, 사용자 맥락을 먼저 확인합니다. 장식보다 과업 완료를 우선합니다.

표준 컴포넌트와 화면

버튼·폼·카드·내비게이션에는 목적과 상태를 분명히 둡니다. 목록·상세·로딩·빈 상태·오류 상태도 처음부터 설계합니다.

AI 결과물 검토

산출물이 토큰과 컴포넌트 규칙을 지키는지, 텍스트가 읽히는지, 오류와 빈 상태가 빠지지 않았는지 검토합니다.
