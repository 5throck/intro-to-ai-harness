Design Foundations and Standard UI Patterns

Learn design principles that make practice outputs consistent and easy to understand.

In this chapter

Why design is a system

Reinventing colors, type, spacing, and components for every task makes results drift. Shared rules give people and AI one standard.

Core principles

Check consistency, information hierarchy, accessibility, and user context first. Prefer task completion over decoration.

Standard components and screens

Give buttons, forms, cards, and navigation a clear purpose and state. Design list, detail, loading, empty, and error states from the start.

Reviewing AI output

Check that output follows token and component rules, text remains readable, and empty or error states are not omitted.

Practice: Record the decision, assign an owner, and verify the result before the next pipeline stage.
