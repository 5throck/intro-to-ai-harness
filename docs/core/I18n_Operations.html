i18n 설계와 콘텐츠 품질

다국어 콘텐츠와 UI를 처음부터 설계하고, 번역 품질을 검증하는 방법을 배웁니다.

In this chapter
  • 언어와 국가는 다릅니다
  • 번역 가능한 구조
  • 레이아웃도 검증합니다
  • Parity 검사

언어와 국가는 다릅니다

locale은 표시 언어를, 국가 프로필은 법규·데이터·업무 맥락을 다룹니다. 둘을 같은 설정으로 취급하지 않습니다.

번역 가능한 구조

문장을 코드와 분리하고, 날짜·숫자·통화·단위·고유명사를 지역화 가능한 값으로 둡니다.

레이아웃도 검증합니다

번역문 길이, 줄바꿈 방향, 날짜 표기와 단위 때문에 UI가 깨질 수 있습니다. 모든 지원 언어에서 주요 화면을 확인합니다.

Parity 검사

원문과 번역본의 제목, 링크, 표, 코드, 숫자 토큰이 동등한지 검사합니다. 번역 변경도 다른 변경과 같이 검토하고 PR로 반영합니다.

Practice: Record the decision, assign an owner, and verify the result before the next pipeline stage.
