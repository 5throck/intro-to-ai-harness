Core chapter

i18n Design and Content Quality

Learn to design multilingual content and UI from the start and verify translation quality.

In this chapter
  • Language is not country
  • Translatable structure
  • Verify the layout too
  • Parity checks

Language is not country

A locale controls display language; a country profile covers law, data, and work context. Do not treat them as one setting.

Translatable structure

Separate sentences from code. Keep dates, numbers, currencies, units, and proper nouns as localizable values.

Verify the layout too

Translation length, line direction, date formats, and units can break UI. Check key screens in every supported language.

Parity checks

Check that headings, links, tables, code, and numeric tokens match between source and translations. Review and land translation changes through a PR.

Practice: Record the decision, assign an owner, and verify the result before the next pipeline stage.
