Claude Code와 멀티 에이전트 하네스 입문

프롬프트 하나에서 팀 하나로. Claude Desktop App을 기본 도구로, AI 에이전트 팀의 개념부터 직접 만들어 쓰는 방법까지 배우는 하루짜리 실전 입문 과정.

이 과정은 무엇인가? "AI에게 일을 시키는 것"을 넘어, 여러 AI 에이전트가 역할을 나누어 협력하는 팀을 구성하고 활용하는 방법을 배운다. 설치와 구독부터 에이전트·스킬·팀 생성까지 13개 장 + 3개 별첨을 따라 하면서, 자기 업무에 적용할 수 있는 실전 경험을 쌓는다.

기본 도구는 코딩 경험이 없어도 되는 Claude Desktop App이다. 원격 접속, Claude Code CLI, 저비용 백엔드(DeepSeek/GLM)는 별첨으로 분리해 필요한 사람만 심화 학습한다.

🎯학습 목표

이 과정을 수료한 참가자는 다음을 할 수 있다.

LO-1
설명단일 AI와 멀티 에이전트 팀의 차이를 컨텍스트·역할·병렬성 관점에서 설명하고, 하네스(harness) 개념을 이해한다.
LO-2
설치Claude Desktop App을 MacOS/Windows/Linux에 설치하고, 구독 플랜을 선택하며, 프로젝트와 첫 대화를 시작한다.
LO-3
구성실습 환경을 OS별 설치 스크립트로 구축하고 설치를 검증한다.
LO-4
개념에이전트·스킬·워크플로우, PM 오케스트레이션, 3-Tier 전략, PM Gateway, 디스패치 흐름 등 멀티 에이전트 하네스의 핵심 아키텍처를 설명한다.
LO-5
실행co-consult로 시장 분석 보고서를, co-deck으로 발표자료를 만들어보고, 두 시스템을 연동한 통합 파이프라인을 실행한다.
LO-6
창작자신의 업무에 맞는 에이전트(agent)와 스킬(skill)을 만들고 등록·검증하며, team-builder로 커스텀 에이전트 팀을 구성한다.
LO-7
자동화/sync 명령, Git/GitHub PR 자동화, Hook, CI/CD, dev-sync.ts 동작 원리를 이해하고 자동화 워크플로우를 활용한다.
LO-8
확장원격 접속 환경을 구성하고, Claude Code CLI로 같은 프로젝트를 실행하며, 저비용 백엔드(DeepSeek/GLM) API 키를 환경 변수로 설정해 연결한다.

👥대상자

이 과정은 AI 초보자를 주요 대상으로 한다. 코딩 경험이 없어도, 컴퓨터 기본 조작만 가능하면 따라올 수 있다.

  • AI를 업무에 활용하고 싶은 실무자. Claude.ai, ChatGPT 등을 쓰고 있지만 "여러 AI를 팀처럼 쓰는 것"이 낯선 분
  • AI 도구 도입을 고민하는 팀 리더·기획자. 팀에 AI 에이전트를 어떻게 배치할지 감을 잡고 싶은 분
  • AI 교육·컨설팅을 준비하는 강사·컨설턴트. 멀티 에이전트 하네스를 교육 자료로 다루는 분
  • 코딩을 배우고 싶지만 장벽을 느끼는 분. Claude Desktop App으로 자연어만으로 프로그램을 만들어보고 싶은 분
참고: 이 핸드북은 Claude Desktop App을 기본 도구로 사용한다. 터미널/CLI가 익숙한 사용자는 별첨 B(Claude Code CLI)와 별첨 C(저비용 백엔드)로 심화할 수 있다. 원격으로 실습 환경에 접속해야 한다면 별첨 A를 먼저 본다.

실습 환경

전원이 Claude Desktop App으로 동일한 실습을 진행한다. 모든 명령어는 복사 버튼으로 그대로 사용할 수 있으며, MacOS/Windows/Linux 명령어를 나란히 제공해 어떤 환경에서도 따라올 수 있다.
