Introduction to Claude Code & Multi-Agent Harness

From a single prompt to a whole team. Using Claude Desktop App as the default tool, learn how to build and use AI agent teams — from the basic concepts to hands-on creation — in a one-day practical course.

What is this course? Go beyond "asking an AI to do a task." Learn how multiple AI agents collaborate as a team that divides roles — and how to build and use one. Following 13 chapters + 3 appendices, from installation and subscription to creating agents, skills, and teams, you build real experience you can apply to your own work.

The default tool is the Claude Desktop App, which requires no coding experience. Remote access, the Claude Code CLI, and low-cost backends (DeepSeek/GLM) are separated into appendices so you can go deeper only if you need them.

🎯Learning Objectives

After completing this course, participants will be able to:

LO-1
Explainthe difference between a single AI and a multi-agent team from context, role, and parallelism perspectives, and understand the harness concept.
LO-2
InstallClaude Desktop App on macOS/Windows/Linux, choose a subscription plan, and start a project with your first conversation.
LO-3
Set upthe lab environment using OS-specific setup scripts and verify the installation.
LO-4
Describethe core architecture of a multi-agent harness: agents, skills, workflows, PM orchestration, the 3-Tier strategy, PM Gateway, and dispatch flow.
LO-5
Runa market analysis report with co-consult, a presentation deck with co-deck, and an integrated pipeline that combines both.
LO-6
Createagents and skills tailored to your own work — register and validate them — and use team-builder to compose a custom agent team.
LO-7
Automatewith /sync, Git/GitHub PR automation, hooks, CI/CD basics, and understand how dev-sync.ts works.
LO-8
Extendyour learning through the appendices: remote access, Claude Code CLI, and low-cost backend integration.

👥Audience

This course primarily targets AI beginners. No coding experience is required — basic computer skills are enough.

  • Professionals who want to use AI at work. You use Claude.ai or ChatGPT but are unfamiliar with "using multiple AIs as a team."
  • Team leaders and planners considering AI adoption. You want a sense of how to deploy AI agents across your team.
  • Instructors and consultants preparing AI education. You plan to teach the multi-agent harness as course material.
  • Anyone who wants to build software but feels a barrier to coding. You want to create programs using natural language with Claude Desktop App.
Note: This handbook uses the Claude Desktop App as its default tool. Terminal/CLI-savvy users can go deeper with Appendix B (Claude Code CLI) and Appendix C (low-cost backends). If you need to access the lab remotely, start with Appendix A.
