Introduction to Claude Code & Multi-Agent Harness

De un unico prompt a un equipo completo. Utilizando Claude Desktop App como herramienta predeterminada, aprende como construir y usar equipos de agentes de IA —desde los conceptos basicos hasta la creacion practica— en un curso practico de un dia.

De que trata este curso? Ve mas alla de "pedirle a una IA que haga una tarea." Aprende como multiples agentes de IA colaboran como un equipo que divide roles —y como construir y usar uno. Siguiendo 13 capitulos + 3 apendices, desde la instalacion y suscripcion hasta la creacion de agentes, habilidades y equipos, adquiriras una experiencia real que puedes aplicar a tu propio trabajo.

La herramienta predeterminada es la Claude Desktop App, que no requiere experiencia en codificacion. El acceso remoto, Claude Code CLI y los backends de bajo costo (DeepSeek/GLM) estan separados en apendices para que puedas profundizar solo si lo necesitas.

🎯Learning Objectives

Al completar este curso, los participantes podran:

LO-1
Explicarla diferencia entre una IA unica y un equipo multiagente desde las perspectivas de contexto, rol y paralelismo, y comprender el concepto de harness.
LO-2
InstalarClaude Desktop App en macOS/Windows/Linux, elegir un plan de suscripcion y comenzar un proyecto con su primera conversacion.
LO-3
Configurarel entorno de laboratorio utilizando scripts de configuracion especificos del SO y verificar la instalacion.
LO-4
Describethe core architecture of a harness multi-agente: agents, skills, workflows, PM orchestration, the 3-Tier strategy, PM Gateway, and dispatch flow.
LO-5
Ejecutarun informe de analisis de mercado con co-consult, una presentacion con co-deck y un pipeline integrado que combina ambos.
LO-6
Crearagentes y habilidades adaptados a tu propio trabajo —registrarlos y validarlos— y usar team-builder para componer un equipo de agentes personalizado.
LO-7
Automatewith /sync, Git/GitHub PR automation, hooks, CI/CD basics, and understand how dev-sync.ts works.
LO-8
Configurarun entorno de acceso remoto, ejecutar el mismo proyecto con Claude Code CLI y conectar un backend de bajo costo (DeepSeek/GLM) utilizando claves API almacenadas como variables de entorno.

👥Audience

This course primarily targets AI beginners. No coding experience is required — basic computer skills are enough.

  • Profesionales que quieren usar IA en el trabajo. Usas Claude.ai o ChatGPT, pero no estas familiarizado con "usar multiples IAs como un equipo."
  • Lideres y planificadores de equipo considerando la adopcion de IA. Quieres saber como desplegar agentes de IA en tu equipo.
  • Instructors and consultants preparing AI education. You plan to teach the harness multi-agente as course material.
  • Cualquiera que quiera construir software pero sienta una barrera para la codificacion. Quieres crear programas utilizando lenguaje natural con Claude Desktop App.
Nota: Este manual utiliza la Claude Desktop App como su herramienta predeterminada. Los usuarios con conocimientos de Terminal/CLI pueden profundizar con Apéndice B (Claude Code CLI) y Apéndice C (backends de bajo costo). Si necesitas acceder al laboratorio de forma remota, comienza con Apéndice A.

OKLo que ganaras al completar el curso
