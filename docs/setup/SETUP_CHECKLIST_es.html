Workshop Lista de verificación previa a la instalación

Completa esta lista de verificación antes de ejecutar el script de instalación. Los siguientes elementos no se pueden automatizar y requieren una acción manual.

1. Verify Subscription (Top Priority)

Las herramientas utilizadas en las sesiones prácticas del taller requieren una suscripción válida.

ToolRequired Plan
Claude Code CLI (claude)Claude Pro or Max
Claude Desktop AppClaude Pro or higher
Antigravity CLI (agy)Gemini Advanced
Antigravity Desktop AppGemini Advanced
Sobre las claves API: Las claves API solo son necesarias para integraciones fuera de tu plan de suscripción. Las sesiones prácticas del taller están completamente cubiertas por el modelo de suscripción, así que solo emita una clave API si es verdaderamente necesario.

2. Account Preparation

  • Google Account — required to use Antigravity / Gemini Advanced
  • GitHub Account — required for gh auth login and PR exercises
  • Si no tienes uno, regístrate por adelantado en github.com/signup

3. Requisitos del sistema

  • OS: Windows 11 (Intel) / macOS Sequoia 15 or later on Apple Silicon (M series) / Ubuntu 24.04 or later
  • Free disk space: 5 GB o más
  • Administrator / sudo privileges
  • Windows: Inicio → buscar "PowerShell" → clic derecho → "Ejecutar como administrador" (o Win + X → "Terminal (Admin)"), luego haz clic en "Sí" en el cuadro de diálogo de confirmación de UAC
  • macOS / Linux: prefix the command with sudo
  • Stable internet connection (total download size approx. 1–2 GB)

4. Git User Setup

Después de instalar git, registra tu información de usuario con los siguientes comandos.

git config --global user.name  "Jane Doe"
git config --global user.email "you@example.com"
  • git config --global user.name configured
  • git config --global user.email configured

5. GitHub Authentication

gh auth login

Sigue las indicaciones para completar la autenticación en tu navegador.

  • Confirma que se muestra "Logged in" al ejecutar gh auth status

6. Project Environment Setup (after cloning the repository)

Al usar las variantes prácticas co-consult o co-deck:

cp .env.sample .env
# Abre el archivo .env y completa los valores requeridos
  • Created .env from .env.sample
  • Entered required API keys / configuration values

For Python-based exercises — use uv (required):

uv sync          # Install dependencies based on pyproject.toml
# Or, if using requirements.txt:
uv pip install -r requirements.txt
  • Confirmed uv is installed and available (uv --version)
  • Installed Python dependencies via uv
Docker es opcional. Instálalo solo si el facilitador te lo indica específicamente. Agrega la bandera --docker en macOS/Linux o la bandera -Docker en Windows al script de instalación.
  • (Optional) Confirma que Docker está instalado y el daemon se está ejecutando

7. Verificación Final del Entorno (debe ejecutarse antes del taller)

Ejecuta el siguiente comando desde dentro de la carpeta clonada setup/. (Si aún no lo has clonado, consulta Guía de Configuración Paso 0.)

bun setup-common.ts

Estás listo una vez que cada elemento de la tabla de salida muestre ✅.

Para preguntas, por favor contacta al facilitador antes de que comience el taller.
