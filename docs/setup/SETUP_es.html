Workshop Environment Setup Guide

Completa la instalación antes de que comience el taller — el objetivo es estar listo para pasar directamente a la práctica guiada cuando comience la sesión, sin ninguna configuración adicional del entorno.

Setup Flow

1. OS updates
   └─ Windows: winget upgrade --all
   └─ macOS:   brew update && brew upgrade
   └─ Linux:   apt update && apt upgrade

2. Foundational tools
   └─ Windows: PowerShell 7+, Windows Terminal, Git (+ Git Bash)
   └─ macOS / Linux: curl, git

3. Runtimes
   └─ bun  (default runtime & package manager)
   └─ python3
   └─ uv   (Python package manager)

4. CLI tools
   └─ gh  (GitHub CLI)
   └─ claude  (Claude Code CLI)
   └─ agy  (Antigravity CLI)

5. Desktop apps
   └─ Google Chrome
   └─ Claude Desktop app
   └─ Antigravity Desktop app
   └─ Mark  (Markdown viewer)

6. Final verification ✅
   └─ bun setup-common.ts

Step 0 — Clone the Setup Scripts Repo

Los scripts de instalación del taller se mantienen en un repositorio separado (5throck/setup). Clónalo con el siguiente comando y luego ejecuta cada comando subsiguiente desde dentro de la carpeta clonada setup/.

git clone https://github.com/5throck/setup.git
cd setup

Step 1 — Complete the Checklist

Before running the script, first read and complete the Lista de verificación previa a la instalación.

Key items to confirm

  • Suscripción activa a Claude Pro/Max y Gemini Advanced (un plan de suscripción, no una clave API)
  • A GitHub account created, ready for gh auth login
  • Al menos 5 GB de espacio libre en disco y confirmado administrator/sudo privileges

Step 2 — Run the OS-Specific Script

Abre una terminal con privilegios de administrador / sudo y ejecuta el script para tu sistema operativo.

macOS

bash setup-mac.sh
# Optional: also install WezTerm (GPU-accelerated terminal)
bash setup-mac.sh --wezterm
# Optional: also install Docker Desktop
bash setup-mac.sh --docker
# Both:
bash setup-mac.sh --wezterm --docker

Linux (Ubuntu / Debian)

bash setup-linux.sh
# Optional: also install WezTerm
bash setup-linux.sh --wezterm
# Optional: also install Docker
bash setup-linux.sh --docker
# Both:
bash setup-linux.sh --wezterm --docker

Windows

Ejecuta PowerShell como Administrador, luego ingresa el siguiente comando.

# Default run (the script sets the Execution Policy automatically)
.\setup-windows.ps1

# Options:
.\setup-windows.ps1 -WSL2             # Also install WSL2 (restart required)
.\setup-windows.ps1 -WezTerm          # Also install WezTerm
.\setup-windows.ps1 -Docker           # Also install Docker Desktop
.\setup-windows.ps1 -Force            # Reinstala todas las herramientas, incluso aquellas ya instaladas
.\setup-windows.ps1 -WSL2 -WezTerm -Docker  # Install all optional extras
After running: cierra y vuelve a abrir tu terminal para aplicar los cambios del PATH.

Solución de problemas

bun: command not found después de la instalación

Reinicia tu terminal. En Windows, bun se registra automáticamente en las variables de entorno del usuario. macOS/Linux:

export PATH="$HOME/.bun/bin:$PATH"

claude: command not found después de bun install -g

El script intenta automáticamente con un respaldo de npm si bun falla. Si el problema persiste, verifica la ruta con bun pm ls -g y agrégala a tu PATH.

agy: command not found después de la instalación

El instalador CLI de Antigravity coloca el binario en ~/.local/bin o /usr/local/bin. Ejecuta source ~/.bashrc o reinicia tu terminal.

Windows: "running scripts is disabled on this system"

El script establece esto automáticamente en RemoteSigned. Para cambiarlo manualmente:

Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
Windows: se ejecuta sin privilegios de administrador — el script muestra una advertencia pero continúa. Algunas instalaciones, como winget, pueden fallar, por lo que se recomienda volver a ejecutar PowerShell como Administrador.

Checking installation logs

Windows script run logs are automatically saved to %USERPROFILE%\workshop-setup-logs\.

Ejecuta bun setup-common.ts, y una vez que cada elemento muestre ✅, el entorno del taller estará listo.
